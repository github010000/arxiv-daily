## [1/10] OmniAct: One Policy, One Million Embodiments

- **저자**: Xiang Fan, Yuheng Wang, Jiayuan Yan
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33158v1

**요약**

OmniAct는 로봇의 kinematic graph(관절 위치, 운동 축, 연결 구조)를 시각 관찰과 결합해 조건으로 입력받는 cross-embodiment manipulation policy로, 기존 shared action representation 방식이 놓치던 형태(morphology) 차이에 따른 조작 전략 변화를 반영합니다. 각 노드의 relative joint motion을 예측하는 flow-matching policy를 사용해 서로 다른 DoF와 kinematic 구성을 가진 로봇을 하나의 정책으로 제어합니다.

학습을 위해 물리적으로 실현 가능한 100만 개의 robot embodiment를 procedural하게 설계·필터링하고, 모든 embodiment에 대해 시뮬레이션 궤적 생성 알고리즘을 개발하여 다양한 manipulation task로 대규모 학습을 수행합니다.

embodiment와 scene을 held-out한 2,000개 평가 에피소드에서 성공률 63.0%를 기록해 pi 0.5(17.8%)와 최강 baseline(57.9%)을 앞섰고, GPT-6 Astra 대비로도 64.7% 대 41.1%로 우수합니다. 처음 보는 실제 로봇에서도 차선 방법인 MolmoAct2의 약 2배 성공률을 보였으며, 형태별 강점과 제약에 맞춘 서로 다른 조작 전략을 학습함을 확인했습니다.

## [2/10] DiaCap: Jointly Learning Who Speaks When for Audiovisual Dialogue Captioning

- **저자**: Binfei Ji, Zhiwen Cao, Anqi Yang
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33153v1

**요약**

DiaCap은 영상 속 모든 발화에 대해 transcript, timestamp, 화자의 시각적 묘사를 함께 생성하는 audiovisual LLM으로, 발화 타이밍과 audiovisual diarization이 밀접하게 결합되어 있다는 점에 착안해 단일 모델로 통합한 dialogue captioning 방식입니다.
학습은 두 단계로 진행되며, 먼저 225K개의 curated clip과 모든 발화를 상세히 라벨링한 synthetic caption으로 학습한 뒤, 2.9K개의 human-corrected clip에서 utterance timing, speaker grouping, speaker binding을 직접 평가하는 fine-grained feedback 기반 reinforcement learning으로 추가 개선합니다.
utterance-level timestamp와 subtitle redaction으로 확장한 DiaDemBench에서 DiaCap과 end-to-end 변형인 DiaCap-E2E 모두 강력한 성능을 보였고, audiovisual diarization은 Gemini 4 Argon과 대등하면서 timestamp 정확도는 크게 앞서며(TIME 76.59 vs. 42.76), 다국어 및 분 단위 장편 영상과 audiovisual question answering으로의 transfer도 확인되었습니다.

## [3/10] BioLoom: Scaling Biomedical Vision-Language Models by Learning from the Structure of Scientific Articles

- **저자**: Yuwei Yang, Xiaoxiao Sun, Alejandro Lozano
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33151v1

**요약**

BioLoom은 과학 논문의 figure, panel, caption, 본문 문단 간 구조적 관계를 contrastive image-text pretraining의 추가 supervision으로 활용하는 biomedical VLM입니다. 정확히 일치하는 image-text pair는 유지하면서 sibling panel의 caption 같은 관련 pair에는 weak positive supervision을 주고, 같은 content type의 cross-article negative에는 upweighting을 적용해 세밀한 구분 능력을 높입니다.

panel 설명을 시각적 내용, 원본 figure caption, mentioning paragraph로 enrich하고, 이를 panel 및 전체 figure-caption과 짝지어 과학 chart와 biomedical image를 아우르는 5,240만 개 규모의 Loom52M dataset을 구축했습니다.

BioLoom(DFN-2B)은 10개 도메인 43개 dataset의 67개 zero-shot classification task에서 domain-balanced 평균 정확도 56.82%를 기록해 MedPMC-CLIP(48.77%)을 크게 상회했고, BioLoomBench와 BioMedFlickr의 bidirectional mean Recall@1에서도 각각 63.20%, 10.59%로 최강 baseline(BiomedCLIP 46.37%, MedPMC-CLIP 7.55%)을 능가했습니다. code, dataset, benchmark, model이 모두 공개되어 있습니다.

## [4/10] CoT-Proxy: Cross-Format Transfer for Distilling Long-Horizon Policies

- **저자**: Dawid J. Kopiczko, Tijmen Blankevoort, Yuki M. Asano
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33148v1

**요약**

CoT-Proxy는 teacher의 hidden chain-of-thought 없이 행동(action) 궤적만으로 long-horizon policy를 distillation하는 방법으로, student의 reasoning block을 비운 채 fine-tuning하고 replay buffer에 담은 자체 생성물에 KL loss를 적용해 초기 모델로부터의 drift를 억제한다. 이렇게 학습한 policy가 thinking을 켠 추론 환경에서도 그대로 이어지는 cross-format transfer 현상을 발견했으며, 이때 student는 자신만의 방식으로 reasoning하면서 teacher처럼 행동한다.
teacher 추론을 짧게 요약해 빈 reasoning block 뒤에 붙이는 CoT-proxy를 도입해 성능을 더 높였다. Qwen3.6-27B의 action distillation으로 AppWorld 성공률이 Qwen3-4B는 7%→18%, Qwen3-32B는 12%→25%로 올랐고, CoT-proxy를 더하면 Qwen3-4B가 35%까지 향상되었다.
actions와 CoT-proxy 모두 hidden CoT가 필요 없어 closed teacher에도 그대로 적용할 수 있으며, GPT-5.6 Luna의 visible output과 API가 제공하는 reasoning summary만으로 Qwen3-4B를 AppWorld 7%→48%, SWE-bench Verified 3%→28%로 끌어올려 API 기반 closed model에서도 agent distillation이 실용적임을 보였다.

## [5/10] iWAM: Efficient Action Prediction from World Models without Explicit Future Prediction

- **저자**: Vansh Kapoor, Max Sobol Mark, Sreyas Venkataraman
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33141v1

**요약**

iWAM은 사전학습된 video-generation 모델 기반 World-action model(WAM)이 미래 장면을 전부 denoising하느라 추론 비용이 큰 문제를 겨냥하며, 미래 프레임 생성 없이 video backbone의 중간 feature만으로 action policy를 conditioning하는 방식을 제안합니다. 핵심 아이디어는 행동 결정에 필요한 것이 고해상도 프레임이 아니라 가능한 미래들을 구분할 수 있는 정보라는 점입니다.

핵심 기법으로는 flow-matching 모델의 reversible dynamics를 활용해 학습용 미래 프레임을 latent noise vector로 inversion하고, 단일 velocity evaluation만으로는 정보량이 부족한 문제를 해결하기 위해 미래 생성 연산을 amortize하는 bidirectional flow map을 학습합니다. 추론 시에는 prior에서 latent noise를 샘플링하고 video backbone을 한 번만 forward pass하여 policy를 conditioning합니다.

시뮬레이션 벤치마크와 실제 로봇 실험에서 WAM의 generalization 이점을 유지하면서 inference cost를 크게 줄였으며, 실시간 제어가 필요한 로봇 환경에서 video-generation 기반 policy를 실용적으로 적용할 수 있게 하는 기여가 있습니다.

## [6/10] BriConstrain: Geometrically Constrained Decoding for Autoregressive Brick Assembly Generation

- **저자**: Nadav Magar, Amir Hertz, Ariel Shamir
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33135v1

**요약**

BriConstrain은 사전학습된 language model이 LEGO 조립체를 생성할 때 충돌하거나 어디에도 연결되지 않는 부품을 배치하는 문제를 해결하기 위한 constrained decoding 방법입니다. 빌드 상태에 따라 유효성이 달라져 고정 grammar로 컴파일할 수 없으므로, 샘플링 전에 next-token 확률을 동적으로 제한하여 유효한 배치로 유도합니다.
핵심 아이디어는 어떤 부품끼리 연결되는지가 아니라 부품이 어떻게 attach되는지를 제약하는 것으로, 모델이 예측한 현재 부품과 부모 부품에 대해 사전 계산된 geometric oracle로 가능한 attachment 후보를 생성하고 충돌 후보를 걸러낸 뒤, 남은 유효 후보 쪽으로 token 분포를 bias합니다.
명시적 연결 정보를 가진 BrickNet과 암묵적 연결을 쓰는 새로운 Implicit Connectivity LDraw Format(ICLF)에서 평가한 결과, collision-free 빌드 비율이 BrickNet에서 31%→91%, ICLF에서 15%→65%로 향상되었고, rejection sampling보다 약 60%의 decoding 비용으로 더 좋은 성능을 보였습니다.

## [7/10] A Bias in Disguise: Tiny Gradient Edits Stop a Small Language Model's Thinking Loops and Complement a Frontier Model's Weight Edit

- **저자**: Hussamuddin Syed
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33133v1

**요약**

Qwen3.5-0.8B는 thinking mode에서 4k 토큰 예산 내에 추론을 거의 끝내지 못해(MATH-500 정확도 15.4%) 문제가 되는데, 모델 자신의 정답 응답으로 gradient가 가장 큰 140~139,750개 weight만 fine-tuning하면 단 2~9분(단일 GPU), 50개 예제만으로 39.0~45.5%까지 오르며 랜덤 위치 선택(16.3%)보다 월등합니다. 이 edit은 초기 3개 layer에서 거의 상수인 channel에 집중되며, bias term이 없는 모델에서 residual stream에 상수 vector를 더하는 효과와 같아 고정 vector 3개를 원본 모델에 더하는 것만으로 동일한 정확도를 재현합니다.

GPT-6 Astra의 gradient-free weight edit(131,072개 weight)에 대한 누락된 gradient baseline을 제공한 것으로, Astra 프로토콜(32k 토큰, presence penalty 1.5)에서 Astra edit은 52.1%, 본 방법의 full-strength edit은 45.6~45.7%로 낮지만 16k 토큰 이하 모든 budget에서 앞서며 4k에서는 39.5% 대 6.7%를 기록합니다.

두 edit은 상호 보완적이어서, Astra edit에 139,750-weight edit을 절반 강도로 결합하면 32k에서 62.2%로 Astra 단독보다 10%p 높고(p = 3e-9) 토큰 사용량은 절반입니다. 이는 소형 모델의 thinking loop 문제를 저비용 gradient edit으로 해결할 수 있고 frontier 모델의 edit과도 결합 가능함을 보여주는 실용적 기여입니다.

## [8/10] Exploratory Midtraining for Robot Policies

- **저자**: Kshitiz, Zheyuan Hu, Robyn Wu
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33130v1

**요약**

로봇 policy가 사람이 수집한 숙련된 시연 데이터에 주로 의존해 저수준 행동(low-level behavior)의 coverage가 부족하다는 문제를 다루며, 어려운 상태에서 진행 가능한 상태로 이어지는 "connected behavioral coverage"를 확보하는 midtraining 방식을 제안합니다. 핵심은 사람 adversary가 환경을 가역적으로 교란하고 operator는 reset 없이 작업을 이어가는 adversarial teleoperation으로 수집한 β-Data이며, 궤적 segment에 자연어 local outcome 라벨을 relabeling하고 최근 action history에 조건화된 pretrained policy를 finetuning합니다.
시뮬레이션과 3개의 실제 로봇 플랫폼의 manipulation 과제에서 표준 시연 학습 대비 더 유리한 data scaling law, 향상된 zero-shot generalization, 추가 rollout 시간의 더 효과적인 활용을 보였으며, 학습된 policy는 더 다양한 저수준 행동을 지속적으로 사용합니다.
온라인 finetuning 시 성공 경험 수집에 필요한 rollout 수가 줄고 최종 성공률도 높아, midtraining이 더 견고한 과제 수행뿐 아니라 로봇의 지속적인 자율 개선(autonomous improvement)을 위한 기반이 될 수 있음을 실용적으로 보여줍니다.

## [9/10] SAG-Mem-1.0 Technical Report

- **저자**: Yuchao Wu, XingCheng Liang, Xuanze Wang
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33124v1

**요약**

SAG-Mem은 대화 메시지 전체를 겹치지 않는 chunk 단위로 보존하고 lexical index만 사용하는 long-term conversational memory 프레임워크로, 구축 단계에서 LLM 기반 extraction, summarization, semantic relation construction 없이 모델 추론이 전혀 필요하지 않습니다. 쿼리 시점에는 BM25로 초기 후보를 검색하고, evidence evaluator가 유용한 chunk를 선별한 뒤, 선택된 증거의 lexical cue로 추가 retrieval round를 수행하여 질문과 유사도가 낮은 중간 증거까지 찾아냅니다. 또한 상대적 시간 표현에 원문과 시간 granularity를 유지한 채 calendar interpretation을 주석으로 덧붙입니다.

임베딩 기반 candidate scoring으로 evidence scoring을 대체한 SAG-Mem-Lite는 두 벤치마크 모두에서 Full Context 및 모든 memory 기반 baseline보다 낮은 운영 비용과 짧은 query latency를 달성합니다.

SAG-Mem은 LoCoMo 83.08, LongMemEval 80.20으로 평가 대상 방법 중 두 벤치마크 모두 최고 점수를 기록했으며, LongMemEval에서는 가장 강력한 baseline을 7.20점 앞섭니다. SAG-Mem-Lite는 각각 77.09, 77.20을 기록해, 대화 원문 보존과 evidence-guided retrieval expansion이 효과적인 memory 설계임을 보여줍니다.

## [10/10] MetaFORGE: A Meta-Learning Framework for Harness Optimization in Automated Code Generation for Parallel Computing

- **저자**: Scott Piersall, Yang Gao, Shenyang Liu
- **공개일**: 2026-11-25
- **링크**: https://arxiv.org/abs/2611.33119v1

**요약**

MetaFORGE는 MPI C 코드 생성을 안내하는 persistent natural-language skill specification을 반복적으로 최적화하는 execution-grounded meta-learning 프레임워크로, correctness testing, compiler diagnostics, static-analysis findings, runtime, rank-level load-imbalance profile을 하나의 scalar reward로 통합해 textual-gradient refinement를 수행하고, external memory가 reward로 검증된 최적화 지식을 추출·검색합니다.
6개 MPI 태스크와 3개 workload 크기에서 zero-shot 생성 대비 static-analysis 품질, runtime, load balance가 향상되었고 TextGrad 반복 baseline도 대체로 능가했으며, refinement 모델을 gpt-4o로 낮춘 model-matched ablation에서도 우위가 유지되었습니다.
18개 태스크-workload 구성 전반의 retrieval ablation에서 검색된 컨텍스트가 runtime에 일관된 이점을 주었고, leakage-controlled held-out 및 zero-update 실험을 통해 최적화 지식이 transferred skill과 external memory 양쪽에 persist함을 보여, 병렬 컴퓨팅 코드 생성용 harness를 재사용 가능한 형태로 자동 최적화할 수 있는 실용적 가능성을 제시합니다.
