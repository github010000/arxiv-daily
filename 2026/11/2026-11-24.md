## [1/10] Optimal Linear Regression Without a Variance

- **저자**: Artin Tajdini, Jasper C. H. Lee, Jonathan Scarlett
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27983v1

**요약**

이 논문은 noise가 유한한 conditional α-moment(α∈(1,2))만 갖는 infinite variance 환경에서의 high-probability linear regression을 다루며, empirical residual pruning에 기반한 black-box reduction을 제안합니다. 이 방법은 유한 분산용 회귀 알고리즘(sub-Gaussian rate 달성)을 weak-moment 환경으로 변환하고, α, noise scale ν, 공분산, design moment를 몰라도 동작하며, 서브루틴이 효율적이면 계산 효율성도 유지됩니다.
공변량의 4차 moment 조건 하에서 표본 수가 임계값을 넘으면 확률 1-δ로 ‖θ̂-θ*‖_Σ ≲ ν^{1/α}((d+log(1/δ))/n)^{(α-1)/α}의 오차율을 달성하며, 동일 조건에서 이와 일치하는 minimax lower bound도 증명해 최적성을 보입니다.
추가로 response의 raw α-moment가 유한하다는 가정만으로 성립하는 distribution-free prediction guarantee와, α-agnostic한 mean estimation reduction도 제시하여 heavy-tailed 통계 추정 전반에 실용적으로 적용할 수 있는 기반을 제공합니다.

RMSE, MAPE, Pearson correlation을 N=30 독립 replicate 평균으로 측정하여 정확도, replicate 간 안정성, 아키텍처 depth 민감도를 평가합니다.

## [3/10] MemOnce: A Scalable Memory Architecture for Large Language Models

- **저자**: Chang Nie, Chaoyou Fu, Songlin Liu
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27973v1

**요약**

MemOnce는 장기 연속 상호작용을 위한 확장 가능한 memory 아키텍처로, 최종 레이어 hidden state 중 일부만 compact memory representation으로 저장하고 이를 attention 레이어용 KV cache로 동적으로 decoding하는 Memory encoder-decoder를 사용합니다. 여기에 입력마다 관련 memory를 적응적으로 검색하며 sparse index를 전 레이어에서 한 번만 계산하는 Memory sparse attention을 결합하여, Transformer의 선형 GPU 메모리 증가와 이차 연산 복잡도 문제 및 linear-time 모델의 세부 정보 손실 문제를 동시에 완화합니다.

다양한 모델 크기, 컨텍스트 길이, 학습 방식(pretraining 및 post-training adaptation)에서 Transformer와 다른 아키텍처보다 우수한 성능을 보였습니다. 특히 Qwen3.5-4B에 적용 시 1M context에서 memory state cache를 1313배, prefill latency를 6.9배 줄이고 throughput은 3.5배, 전체 memory 성능은 +5.77% 향상시켰습니다.

실용적으로는 기존 사전학습 모델을 adaptation만으로 전환할 수 있어 장문맥 및 continual 환경에서 GPU 메모리와 지연 시간 부담을 크게 낮춥니다. 또한 downstream representation task에서 zero-shot으로 특화 모델과 견줄 만한 결과를 내어 범용성도 확인했습니다.

## [5/10] Non-penetrating World Models

- **저자**: Yuhang Dai, Yinwei Wu, Ziyue Lin
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27963v1

**요약**

인터랙티브 비디오 world model에서 물체가 장애물을 관통하는 문제를 처음으로 다루며, 이를 평가하는 NoPeBench 벤치마크를 제안합니다. 평가 결과 기존 open-source 모델들은 관통 실패를 안정적으로 막지 못했지만, diffusion transformer(DiT)의 hidden states에는 후보 action이 장애물을 관통할지 예측할 정보가 이미 담겨 있음을 발견했습니다.
핵심 방법론인 NoPeWorld는 frozen DiT의 hidden states 위에 작은 prediction head만 학습해 action의 안전 여부를 판별하고, unsafe action을 원래 의도를 최대한 보존하는 safe action으로 대체하는 경량 프레임워크입니다.
실용적으로는 6개 video world model 평균 physical violation rate를 74%에서 16%로 낮추었고, open-domain 이미지, third-person 시점, 움직이는 장애물에도 zero-shot generalization을 보였으며, 코드·벤치마크·모델 가중치를 공개했습니다.

## [6/10] Model Carving: Training Transformers That Optimize Their Own Topology

- **저자**: Kaden Zheng, Pratyusha Sharma
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27962v1

**요약**

Model Carving은 각 sublayer(attention, MLP)에 learnable scalar gate를 적용해 학습 중 training loss가 불필요한 구성 요소를 스스로 제거하도록 하며, 단일 학습 run에서 weights와 architecture(topology)를 동시에 학습하는 방법론입니다. 그 결과 Transformer 내부에서 균일하지 않은(heterogeneous) 더 작은 네트워크가 만들어집니다.
140M~2.7B 규모의 standard Transformer와 140M~1.3B 규모의 looped Transformer를 pre-training해 평가한 결과, 동일한 학습 compute에서 최대 1.7배 많은 compute로 학습한 dense 모델보다 낮은 validation loss를 달성했습니다. 또한 pruning이나 distillation으로 얻은 동일 크기 모델보다 우수했고, 이 이점은 모델 규모가 커질수록 커지며 few-shot evaluation, generation 등 downstream task로도 이어집니다.
제거된 sublayer는 실행되지 않으므로 품질 손실 없이 FLOPs per token이 최대 34% 줄고 decoding 속도가 최대 1.6배 빨라집니다. 큰 모델을 사후 압축하기보다 학습 중에 carving하는 것이 edge device용 소형 모델을 얻는 데 더 효과적임을 보여주며, architecture도 weights처럼 학습되어야 한다는 점을 실용적으로 입증합니다.

## [7/10] Ranking-Preserving Coreset Selection for Efficient Evolutionary Hyperparameter Optimization

- **저자**: Mamoona Tasadduq, Maryam Bashir
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27959v1

**요약**

Ranking-Preserving Coreset(RPC)은 대규모 데이터에서 반복 학습이 필요한 evolutionary HPO의 비용을 줄이기 위해, 전체 데이터에서의 hyperparameter configuration 상대 순위를 보존하는 compact coreset을 선택하는 프레임워크입니다. coreset 선택 자체를 evolutionary optimization 문제로 정의하여, 전체 데이터와 subset 기반 configuration 순위 간의 Spearman rank correlation을 최대화하면서 subset 크기에 페널티를 부여합니다.

선택된 coreset을 GA, CHC, PSO 세 가지 evolutionary algorithm의 HPO에 적용한 결과, 7개 tabular, 2개 text, 2개 image 벤치마크(decision tree, text classification, image classification)에서 full-dataset HPO와 비슷한 test accuracy를 유지하면서 HPO 단계 속도가 약 1.14배에서 8.80배까지 향상되었습니다. coreset 구축 비용은 end-to-end runtime 및 break-even 분석으로 별도 평가했습니다.

coreset 구축에 사용하지 않은 20개 held-out configuration에서도 11개 중 8개 데이터셋에서 동일 크기 random sampling보다 높은 ranking correlation을 보였습니다(Wilcoxon signed-rank test, p = 0.014). 따라서 순위 보존이 선택에 사용된 configuration을 넘어 일반화되며, 일회성 구축 비용은 여러 HPO 실행에서 coreset을 재사용하면 상쇄할 수 있다는 실용적 의의가 있습니다.

## [8/10] Topology Hub Optimal Transport: Eliminating Long Context Dilution at Flash Speed

- **저자**: Dylan Forde
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27951v1

**요약**

THOT(Topology Hub Optimal Transport)는 dense L×L attention 대신 local window와 K개의 shared hub로 이루어진 linear-size 그래프 위에서 Sinkhorn scaling 기반 hub-and-spoke OT를 수행하며, simplex sparsemax(O(L log L)) 또는 token-local thresholded ReLU(O(L))로 capacity gating을 하여 긴 context에서 distractor에 normalization mass가 분산되는 dilution 문제를 제거합니다. 여기에 3-sweep 1+2 annealed row-closed Sinkhorn schedule과 chunked exclusive-prefix causal variant(future leakage 0 검증)를 결합했습니다.

구현 측면에서는 exact rank-(D+2R+1) One-Reference-Tile adjoint를 batched split-factor Triton kernel(BF16 Tensor Cores, FP32 potentials)로 구현했습니다. NVIDIA L4에서 L=262K, H=8, D=64 기준 forward+VJP가 100.1 ms로 latent softmax 대비 2.2배 빠르고 compiler temporary는 4.0배 작으며, L=4,096에서는 cuDNN FlashAttention(4.37 ms) 대비 1.34 ms를 기록했습니다. 다만 multi-layer LM 실험은 fused kernel이 아닌 unfused path를 사용합니다.

L=128로 학습한 sparsemax THOT는 L=262,144에서 zero-shot fixed binding recall 97.40%(α=0)와 98.83%(α=0.05)를 달성한 반면 softmax-gated hub OT는 3.52%에 그쳤습니다. WikiText-103 multi-needle retrieval에서는 L=65K에서 100%(128/128)로 short-trained RoPE FlashAttention의 0.78%를 크게 앞섰으며, 4-layer WikiText-4K LM에서는 causal 및 masked LM 모두 소폭의 개선을 보였습니다.

## [9/10] The Optimal Sample Complexity of Agnostic PAC Learning for Partial Concept Classes

- **저자**: Liang-Yu Zou
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27946v1

**요약**

유한 VC dimension d를 갖는 partial concept class(개념이 {-1,+1,⋆} 값을 가져 일부 입력에서 정의되지 않는 클래스)에 대해, deterministic agnostic PAC learner를 구성하여 O((d+log(1/δ))/ε²)개의 i.i.d. 샘플만으로 total concept을 출력하고 최적 hypothesis 대비 오차 ε 이내를 확률 1-δ로 보장합니다.
이는 partial concept class의 agnostic PAC learning에서 최적 sample complexity를 확립한 결과로, Alon et al. (FOCS 2021)의 하한과 일치하여 기존에 남아 있던 상한과 하한 사이의 간극을 닫습니다.
실용적으로는 total concept class의 agnostic 학습 결과와 동일한 샘플 효율을 partial concept(예: margin 조건 등 데이터 구조적 가정을 모델링하는 경우)에서도 달성할 수 있음을 보여주며, 학습기가 deterministic이라는 점도 이론적 기여입니다.

## [10/10] BioEmu2: Scalable Emulation of Biomolecular Dynamics

- **저자**: Michael Gastegger, Adam E. Foster, Jos\'e Jim\'enez-Luna
- **공개일**: 2026-11-23
- **링크**: https://arxiv.org/abs/2611.27924v1

**요약**

BioEmu2는 정적 structure prediction, equilibrium sampling, time evolution을 하나로 통합한 generative model로, 단백질·핵산·modified residue·ligand·ion을 포함한 multi-component 시스템의 atomically resolved 구조를 생성하며 molecular dynamics(MD)보다 수 order of magnitude 빠르게 샘플링합니다. 실험 및 합성 구조와 대규모 MD 데이터로 학습했고, context parallel mode를 통해 megadalton 규모 복합체까지 예측할 수 있습니다.

Structure prediction 정확도는 상위 open-weight biomolecular folding 모델과 비슷한 수준이며, equilibrium distribution은 MD 기준값과 비교해 테스트한 단백질과 복합체 전반에서 free-energy 오차가 약 1 kcal/mol에 불과합니다. 또한 time propagation으로 장시간 dynamical trajectory와 binding 및 conformational change의 kinetics를 예측합니다.

Residue contact conditioning이나 user-defined bias potential steering으로 생성 구조를 제어할 수 있고, enhanced sampling을 통해 rare state가 관여하는 free energy 계산도 가능합니다. 이를 통해 biomolecular ensemble과 dynamics 연구를 대규모로 수행할 수 있는 실용적 도구를 제공합니다.
