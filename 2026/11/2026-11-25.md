## [1/10] Pruning Autonomous Driving VLAs: What to Preserve for Reasoning and Action

- **저자**: Seongchan Kim, Soowon Son, Sangoh Kim
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31240v1

**요약**

Alpamayo-1.5-10B 같은 reasoning VLA 모델에 structured pruning을 적용해 CoT reasoning 기반 scene understanding과 trajectory prediction을 모두 유지하는 방법을 연구했으며, Taylor importance 분석 결과 reasoning과 trajectory 목적이 동일한 VLM 구조에 서로 다른 중요도를 부여하고, action expert에서는 MLP channel이 query head보다 denoising step 간 importance 순위가 안정적이며 소수 channel에 중요도가 집중됨을 확인했습니다.

제안한 MoOP는 VLM pruning 시 두 목적의 importance rank를 결합하고, expert MLP channel은 stepwise importance를 집계해 고정된 subset을 선택합니다. 전체 파라미터 24.0% 감소 시 VLM-only pruning에서 주행 성능은 최강 baseline과 비슷하거나 약간 우수하고 LingoQA 점수는 dense 모델의 94.0%를 유지해 다른 방법을 크게 앞섰으며, 30.0% 감소에서도 reasoning이 붕괴하지 않은 유일한 방법입니다.

expert MLP channel의 93.75%를 제거해 총 39.4% 파라미터를 줄여도 open-loop 오차는 거의 변하지 않고 closed-loop 성능도 경쟁력을 유지했으며, post-pruning fine-tuning 없이 dense 모델 대비 end-to-end 추론 1.37x 가속과 peak memory 36.6% 절감을 달성해 자율주행 VLA의 실용적 경량화 가능성을 보여줍니다.

- **링크**: https://arxiv.org/abs/2611.31237v1

**요약**

Integral은 사전학습된 vision-language model(VLM)을 unified multimodal model로 전환하는 방법으로, 이해(understanding)와 생성(generation)에 쓰이는 시각 표현이 서로 이질적(heterogeneous)이라는 점을 핵심 병목으로 지목하고 두 작업이 공유하는 visual representation space를 구축합니다.
핵심 기술은 두 가지로, Abstraction Fusion은 frozen vision encoder의 hierarchical representation을 집계해 공유 visual token을 만들고, Block-wise MoT는 VLM과 block 경계에서만 상호작용하는 lightweight generative stream을 추가합니다.
기존 VLM의 understanding 능력을 유지하면서 강력한 visual generation으로 확장하며, 통제 비교 실험에서 reconstruction fidelity가 비슷해도 표현 공유 시 generative learning이 크게 향상되어 VLM 표현 자체가 생성의 효과적인 기반임을 보였습니다.

## [3/10] TowerBridge: Bridging the Dual-Encoder Modality Gap via Weight-Space Programming

- **저자**: Hani Alomari, Md Atabuzzaman, Chris Thomas
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31233v1

**요약**

CLIP 계열 dual encoder의 modality gap을 post hoc으로 제거하면 오히려 retrieval 성능이 떨어지는 문제를 지적하고, hard negatives에서 두 tower가 matched pair보다 더 많이 일치하는 방향을 찾는 paired statistic을 제안합니다. 이 방향들을 약하게 attenuation하면 gap은 대부분 유지한 채 retrieval이 개선되며, 이 보정은 LLM agent가 두 tower를 분석해 backpropagation 없이 closed-form weight edit을 작성하는 weight-space programming으로 발견되었습니다.

이 agent의 반복적인 보정(주로 output projection 수정)을 hard-negative margin의 first-order analysis로 정리한 closed-form recipe가 TowerBridge입니다. 라벨된 25,000쌍으로 수 초 만에 계산되고, 모델별 tuning이 필요 없으며, architecture와 inference cost도 변하지 않습니다.

21개 CLIP checkpoint(agent가 보지 못한 8개 포함) 평균으로 COCO test retrieval이 16.8 RSUM, Flickr30k test retrieval이 6.6 향상되었고 ImageNet zero-shot 정확도 하락은 최대 0.5점에 그쳤습니다. 또한 모든 checkpoint에서 hubness가 감소했고, 다른 계열 dual encoder 5개 중 4개에서도 retrieval이 개선되어 실용적인 일반화 가능성을 보였습니다.

## [4/10] Language Models Steer on Injected Uncertainty Tokens, but Fail to Self-Monitor In Situ

- **저자**: Daniel Theron
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31228v1

**요약**

Qwen2.5-7B, Llama-3.1-8B, Mistral-7B, Phi-4 네 가지 open-weights 모델의 수학 벤치마크 15,200회 시도에서 2,017개 reasoning error를 분리하고 27,568개의 counterfactual continuation을 적용해, verbalized stepwise confidence의 in-situ monitoring fidelity와 uncertainty token의 downstream steering control을 분리해 평가했습니다. 모든 모델에서 confidence는 오류 단계와 정상 단계를 구분하지 못했고(within-position AUROC 0.500~0.561), 첫 오류 시점에도 confidence가 95.1~99.9%로 포화되어 있었습니다.

반면 오류 단계에 low-confidence tag(10%)를 주입하면 95% certainty 대비 correction이 +3.7~+22.5 points 유의하게 증가했고(모든 p ≤ 0.0022), active rethinking 지시를 함께 쓰면 최대 38.5%까지 도달했습니다. 다만 이미 올바른 단계에 doubt를 주입하면 유효한 reasoning을 폐기하여 solve rate가 최대 22.8 points 하락했습니다.

결론적으로 inference-time self-correction의 병목은 downstream repair 능력이 아니라 in-situ error detection이며, verbalized confidence 기반 backtracking을 쓰는 agentic reasoning 설계에서는 신뢰할 수 있는 외부 오류 탐지 신호가 필요하다는 실용적 시사점을 제공합니다.

## [5/10] How Far Can Linear Go? BiPert, a Unified Framework for Single-Cell Perturbation Modelling

- **저자**: Abhishek Sharma, Aleksej Zelezniak
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31227v1

**요약**

BiPert는 transcriptional response를 shared component와 perturbation-specific component로 나누는 공통 linear decomposition을 바탕으로, 보지 못한 cell type에서의 perturbation 반응 예측(forward)과 발현 변화로부터 perturbed gene을 찾는 작업(inverse)을 하나의 단순한 linear framework로 통합합니다.
Forward 예측에서 BiPert는 외부 생물학적 지식 없이 unseen cell line의 gene expression 변화를 예측하는 기존 방법들보다 높은 성능을 보였고, few-shot 확장인 BiPert-FS는 측정된 perturbation 10개만으로 새로운 cell line에 적응합니다. Inverse 작업의 BiPert-ID는 single-cell expression profile에서 perturbed gene을 식별하며, unseen cell line과 donor에서 deep-learning 방법을 능가합니다.
또한 effect size를 통제한 후에도 cellular context 간 효과가 일관되게 전이되는 perturbation일수록 식별이 쉽다는 점을 보여 perturbation transfer와 identification 사이의 연결을 확립했으며, 단순하고 해석 가능한 linear model이 두 작업 모두에서 강력한 baseline이 될 수 있음을 입증했습니다.

학습 목표는 cross-view assignment 간의 mutual information을 최대화하는 것이며, 소수의 prototype에 모든 샘플이 몰리는 trivial solution을 방지하는 장치를 함께 사용합니다. 지도 학습에 편중되어 있던 dataset distillation 연구를 SSL로 확장했다는 점에서 의의가 있습니다.

## [8/10] CTLink: A Text-Prompted Segmentation Model for Linking Radiology Report Findings to 3D Chest CT Scans

- **저자**: Mohammed Baharoon, Sung Eun Kim, Mahmoud Hussain Alabbad
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31222v1

**요약**

CTLink는 흉부 CT 판독문에 기술된 finding을 텍스트 프롬프트로 입력받아 3D CT 상에서 해당 병변을 직접 segmentation하는 모델로, 텍스트로만 서술된 finding과 실제 영상 위치를 연결하는 것이 목표입니다. 4123개 noncontrast 흉부 CT와 9547개 segmented finding으로 학습했으며, 각 finding의 모든 instance를 분할한 새 데이터셋 ReXGroundingCTv2(1134 scans, 1895 findings)를 함께 구축했습니다.

ReXGroundingCT 검증셋에서 hit rate 0.816, instance F1 0.456, mean Dice 0.400을 기록해 공개 text-prompted segmentation 모델 VoxTell(0.533, 0.175, 0.234)을 크게 앞섰습니다(모두 P < .001). MICCAI 2026 ReXGrounding challenge 테스트셋에서는 CTLink 7개 모델 ensemble이 48개 참가 팀 중 가장 높은 hit rate(0.782)와 instance F1(0.386)을 달성했고, 두 명의 radiologist가 독립 분할한 50개 스캔에서는 inter-rater agreement과 같거나 더 높은 성능을 보였습니다.

실용적으로는 판독문 finding을 영상에 시각적으로 연결해 판독 이해와 검증을 돕고 모델 weights와 데이터셋을 Hugging Face에 공개해 재현성과 후속 연구에 기여합니다. 다만 diffuse non-focal finding은 radiologist 간에도 범위 표기가 일관되지 않아 여전히 주요 한계로 남아 있습니다.

## [9/10] LeJEPA Features Are Not Isotropic, and Should Not Be

- **저자**: Richeek Das, Pratik Chaudhari
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31216v1

**요약**

LeJEPA의 SIGReg 정규화 항은 실제로는 feature를 isotropic Gaussian 분포로 만들지 못하며, 저자들은 이를 더 잘 강제하도록 수정한 regularizer를 제안해 ImageNet-100에서 SIGReg와 같은 최종 accuracy에 1.3배 적은 epoch로 도달함을 보였습니다. 또한 LeJEPA의 alignment term이 feature의 magnitude와 direction을 서로 결합시켜 SIGReg와 충돌하므로, isotropic Gaussian이라는 target 자체가 지나치게 엄격하다고 주장합니다.
이를 해결하기 위해 magnitude와 direction의 marginal distribution만 강제하고 둘 사이의 independence는 요구하지 않는 간단한 regularization 항 PolarReg를 제안합니다. 이 방법은 데이터셋, batch size, embedding dimension이 달라져도 hyper-parameter 변경 없이 안정적으로 최적화됩니다.
ImageNet-1k에서 LeJEPA 및 변형 모델과 같은 accuracy에 4.7배 적은 epoch로 도달하고 최종 accuracy도 1.8점 향상시켜, self-supervised learning의 학습 효율과 튜닝 부담을 함께 줄이는 실용적 기여를 보여줍니다.

## [10/10] Seeking in Space: Benchmarking Purposeful Active Exploration of Vision-Language Models for Spatial Reasoning

- **저자**: Xiwei Liu, Yulong Li, Xuhui Li
- **공개일**: 2026-11-24
- **링크**: https://arxiv.org/abs/2611.31215v1

**요약**

ActSpace-Bench는 72개 실제 스캔 실내 장면의 234개 exploration episode, 994개 질문으로 구성된 벤치마크로, VLM이 단일 시점에서 시작해 실제 촬영된 프레임 사이를 이동하며 증거를 직접 수집한 뒤 공간 질문에 답하도록 합니다. 모든 질문은 exploration이 필요함이 검증되었고 3D annotation으로 정답이 정해지며, masked-evidence 질문으로 답을 보류(abstain)할 시점을 아는지도 평가하고, 샘플의 95% 이상이 human verification으로 정답이 확인되었습니다.
핵심 방법론은 각 모델을 reasoner로 고정한 통제된 평가 프로토콜로, 모델 자체의 exploration을 동일 budget의 random walk 및 oracle route와 비교해 evidence seeking과 spatial reasoning 능력을 분리해 측정합니다.
proprietary, open-weight, spatially specialized VLM 23종을 평가한 결과, 최상위 모델은 목적성 있게 증거를 탐색하지만 제한된 memory 때문에 상당 부분을 잃고, 약한 모델이나 specialized 모델은 random walk 수준이거나 확보한 증거를 활용한 reasoning에 실패하여, memory와 evidence-grounded reasoning이 active spatial intelligence의 향후 핵심 과제임을 제시합니다.
