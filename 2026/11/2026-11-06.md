## [6/10] Reinforcement Learning Enables Scaling Generalist Robot Policy Improvement

- **저자**: Michal Korniak, Marco Bagatella, Ralf R\"omer
- **공개일**: 2026-11-05
- **링크**: https://arxiv.org/abs/2611.06905v1

**요약**

일반화 로봇 정책(generalist robot policy)은 대규모 사전학습 후에도 배포 시 적응이 필요한데, 이 논문은 강화학습(RL) 기반 반복적 자기 개선을 단일 작업이 아닌 여러 작업에 동시에 적용하는 방법을 연구한다.

가치 추정(value estimation), 정책 추출(policy extraction), 자원 배분(resource allocation)에 대한 알고리즘 설계 선택지를 구조화된 평가로 체계적으로 비교하며, 온라인 학습에 포함되지 않은 새로운 작업에서도 성능이 향상되는 일반화가 가능함을 보인다.

실용적으로는 훈련 작업 분포와 value-based RL 사용이 이러한 일반화의 핵심 조건임을 밝혀, 다양한 로봇 작업을 한 번에 개선하는 학습 레시피를 제시한다는 점에서 의의가 있다.

## [7/10] Occlusion for Free: Detecting Occlusion from the Disagreement Between Two Monocular Distance Cues

- **저자**: Chibueze Praise Onyenweaku, Toyibat Adele, Sikirulahi Opeyemi Abdulkareem
- **공개일**: 2026-11-05
- **링크**: https://arxiv.org/abs/2611.06899v1

**요약**

보행자 가림(occlusion)을 라벨 없이 추정하기 위해, 카메라만으로 얻는 두 거리 단서인 겉보기 높이(apparent height)와 monocular metric depth의 순서 불일치를 이용한다. 가림이 있으면 검출 박스 높이는 거의 변하지 않지만 깊이 값은 가리는 물체 쪽으로 당겨지므로, 두 값의 차이가 가림 점수가 된다. 초점거리, 신장, depth scale이 필요 없고 깊이 모델의 오차가 순수 gain에 가깝다는 조건만 라벨 없이 확인하면 된다.

KITTI에서 심한 가림 검출 AUC는 0.909(검출되지 않은 보행자를 포함한 전체 주석 대상 0.888)로, 학습이나 가림 라벨 없이 달성했다. 거리 구간을 고정해도 AUC가 0.894~0.925를 유지해 단순한 거리 정보의 대리 변수가 아님을 보였으며, CARLA 합성 장면에서는 측정된 가시성 기준 0.819로 거리만 사용한 경우(0.644)를 크게 앞섰다.

깊이 융합, 가림 시뮬레이션 증강, 어텐션 같은 기존 구조적 대응책은 테스트한 설정에서 학습 분포 밖의 검출 성능을 개선하지 못했고, 독일 도로로 학습한 검출기는 다른 환경에서 정확도가 절반으로 떨어지는 것으로 나타났다.

## [10/10] SpecCompact: Accelerating LLM Agent Context Compaction with Slot-Parallel Semantic Speculative Verification

- **저자**: Yulu An, Yifei Feng, Xiangyang Yin
- **공개일**: 2026-11-05
- **링크**: https://arxiv.org/abs/2611.06876v1

**요약**

SpecCompact는 구조화된 요약 슬롯(slot)을 독립적으로 생성할 수 있다는 관찰에 기반해, 작은 drafter를 fine-tuning하여 슬롯을 병렬로 생성하고 target 모델이 각 줄을 검증·수정하는 slot-parallel semantic speculative verification 기법으로 LLM agent의 context compaction을 가속한다. 또한 반복적인 context 처리와 모델 호출을 줄이는 시스템 최적화를 더해 구현 효율을 높였다. AppWorld와 τ³ 벤치마크의 두 target 모델 실험에서 Hermes 방식 요약 대비 2.04~5.63배의 compaction 속도 향상을 보였고, 사용자 연구에서는 중앙값 기준 8.68배의 속도 향상을 확인해 장기 agent 실서비스의 지연 시간 문제 해결에 실용적 가치가 있음을 보였다. 다만 다운스트림 성능은 모델과 과제에 따라 trade-off가 존재한다는 점은 적용 시 고려가 필요하다.
