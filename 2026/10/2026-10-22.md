## [9/10] Efficient Edge-aware Attention Network for Graph Generation

- **저자**: Vincent Jung, Alba Carballo-Castro, Yiming Qin
- **공개일**: 2026-10-21
- **링크**: https://arxiv.org/abs/2610.28618v1

**요약**

Graph generative models often rely on graph-specific Transformer architectures that fail to leverage recent hardware-aware attention implementations, limiting their scalability. The adaptation is challenging due to the need to inject edge and graph-level features into pairwise attention scores, respect graph masks, and manage dynamic edge updates that cause quadratic memory usage. To address this, the authors propose an edge-aware attention layer that incorporates structural information through head-wise score modulation and updates edge representations with a lightweight residual mechanism. This approach allows for efficient implementation using PyTorch’s FlexAttention, achieving similar generation quality while reducing peak GPU memory by about 65% and significantly improving training and sampling throughput. The results indicate that the proposed architecture is a practical step toward scalable graph foundation models.
