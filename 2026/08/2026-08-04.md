## [1/10] TokTier: Exact Stateful Tokenization for Agentic LLM Serving

- **저자**: Zhenyu Zhang, Zhichao Cao
- **공개일**: 2026-07-31
- **링크**: https://arxiv.org/abs/2607.29678v1

**요약**

Agentic LLM 서빙에서 prompt cache 재사용 저하를 해결하기 위해, append 구간만 정확히 재토큰화하고 stable-boundary check를 적용하는 stateful tokenization 방법론을 제안합니다.
GPU 기반 exact pre-tokenization 및 BPE 연산을 최적화하여 기존 대비 최대 437배 빠른 속도를 달성하면서도 token ID 정확도는 완전히 유지합니다.
이를 통해 prompt cache hit rate 활용도를 극대화하고, Agentic LLM 서빙의 time-to-first-token latency를 획기적으로 낮추는 실용적 기여를 제공합니다.

- **공개일**: 2026-07-31
- **링크**: https://arxiv.org/abs/2607.29675v1

**요약**

DP-GRAMS는 higher-order kernel 기반 score estimator에 gradient clipping과 calibrated Gaussian noise를 결합한 noisy ascent 방식으로, differential privacy 하에서 density mode를 추정합니다.
