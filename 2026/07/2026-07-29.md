## [1/10] Pass the Baton: Trajectory-Relayed On-Policy Distillation

- **저자**: Haolei Xu, Xiaowen Xu, Haiwen Hong
- **공개일**: 2026-07-28
- **링크**: https://arxiv.org/abs/2607.26057v1

**요약**

학습 중 학생의 추론 방향 이탈 감지 시 교사가 개입하는 label-free handoff trigger 기반 Relay-OPD를 제안하여 표준 OPD의 prefix failure 문제를 해결한다.
제한된 relay budget로 핵심 단계에서 teacher가 trajectory를 이어받은 후 student가 최적화되도록 설계하여 수학 benchmark에서 기존 대비 성능을 향상시켰다.
학습 trajectory 길이를 50% 이상 단축하며 효율적이고 안정적인 model distillation을 가능하게 한다.

## [3/10] Spend Experts Where You Are Unsure: Confidence-Adaptive Routing for Mixture-of-Experts LoRA

- **저자**: Tom Saliencro, Rohan Desai, Priya Nair
- **공개일**: 2026-07-28
- **링크**: https://arxiv.org/abs/2607.26052v1

**요약**

MoE-LoRA의 fixed top-k routing을 대체하는 CARE(Confidence-Adaptive Routing of Experts)는 router의 output distribution을 uncertainty 신호로 활용해 nucleus sampling과 budget thermostat로 expert를 동적 라우팅합니다.
추가 parameter 없이 single-forward-pass로 적용 가능하며, LLaMA 및 Qwen 기반 benchmark에서 고정-k 대비 동일 compute 하에서 성능을 유지/향상시키고 active expert 수를 줄입니다.
out-of-distribution detection 성능 향상과 코드 공개를 통해 효율적인 LoRA fine-tuning 파이프라인에 즉시 통합 실용화할 수 있습니다.

## [10/10] UniMem: Complementary Episodic-to-Parametric Memory for Boundary-Agnostic Task Streams

- **저자**: Siyu Xia, Chenheng Zhang, Yanting Wu
- **공개일**: 2026-07-28
- **링크**: https://arxiv.org/abs/2607.26017v1

**요약**

`learnable routing token`을 활용하여 `episodic buffer`와 `parametric memory` 간 자동 전환을 조절하는 자기주도형 메모리 관리 프레임워크입니다.
