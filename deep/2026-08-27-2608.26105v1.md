## 한 줄 요약

VBVR-Pro 는 시각 생성 자체를 추론 매체로 쓰는 native visual reasoning 을 훈련 가능하고 검증 가능하고 최적화 가능하며 실험 통제 가능하게 만드는 폐루프 testbed 로서, 300 개의 절차적 생성 task 와 인간 판단에 정렬된 verifiable reward scorer 를 제공하고, image, video, interleaved 생성 모델 간 공정 비교와 대규모 다중 task 강화학습을 수행한다.

## 핵심 개념 풀이

### 1) Native visual reasoning

이 개념은 언어 모델처럼 텍스트로 추론하는 대신, 생성되는 image 나 video 자체를 문제 해결의 중간 작업 기억으로 사용하는 방식을 말한다. 예를 들어 미로 문제에서 "왼쪽으로 간다"라고 문장을 쓰는 대신, 미로 위에 경로를 직접 그린 image 를 만들어 다음 판단의 입력으로 삼는다. 여기서 visual state 는 이해해야 할 입력도, 마지막에 렌더링할 출력도 아니라 계산이 일어나는 기질(substrate)이다. 'native' 라는 표현은 언어로 옮기지 않고 시각 양식 안에서 추론이 이루어진다는 뜻이다. 이 관점은 공간 변환, 시간 연속성, 객체 지속성처럼 말로 표현하기 어려운 물리 세계 지능을 더 자연스럽게 다룰 수 있다는 동기에서 나온다.

### 2) Procedural task generator

절차적 task generator 는 문제의 구조는 같지만 표면적 조건을 매개변수로 바꿔 무한히 많은 문제 instance 를 만들어내는 프로그램이다. 예를 들어 미로 generator 는 grid 크기, 벽의 밀도, 시작점, 목표점을 무작위로 뽑아 매번 새로운 미로를 만든다. 중요한 점은 generator 안에 정답 계산기(solver)가 함께 들어 있어서 사람이 정답을 달지 않아도 자동으로 supervision 을 얻을 수 있다는 것이다. VBVR-Pro 는 이런 generator 를 300 개 두어 서로 다른 시각 추론 능력을 폭넓게 덮는다. 이 중 150 개는 기존 VBVR 을 개선한 것이고 150 개는 더 어려운 다단계 추론을 겨냥해 새로 설계했다.

### 3) Verifiable reward scorer

verifiable reward scorer 는 생성된 image 나 video 가 문제의 정답 조건을 만족하는지 규칙만으로 결정적으로 점수를 매기는 평가기다. VLM judge 와 달리 확률적 언어 모델을 부르지 않기 때문에 같은 입력에 항상 같은 점수가 나오고 API 비용도 들지 않는다. pixel 단위 비교 대신 색상 분할, 윤곽 검출, OCR, 프레임 간 궤적 추적 같은 고전 컴퓨터 비전 방법으로 공의 색, 모양, 위치, 개수 같은 의미 속성을 먼저 추출한다. 그런 다음 task 별 검사 규칙으로 점수를 합산하는데, 부드러운 기준은 가중합을 쓰고 벽 통과 같은 hard constraint 는 곱셈으로 결합해 한 번의 위반이 점수를 크게 떨어뜨린다. 이렇게 하면 점수가 낮은 이유도 어떤 검사를 실패했는지로 분해할 수 있다.

### 4) VLM-as-a-judge

VLM-as-a-judge 는 큰 멀티모달 언어 모델에게 생성 결과와 문제를 함께 보여주고 "이 답이 맞는가?"를 평가하게 하는 방식이다. 개방형 출력을 유연하게 다룰 수 있어 최근 visual reasoning 벤치마크에서 널리 쓰인다. 그러나 VBVR-Pro 의 분석에 따르면 이 방식은 미세한 색상 차이를 놓치거나 결정적 오류를 간과하거나 task 규칙 자체를 오해하는 일이 잦다. 게다가 temperature 를 0 으로 두고 같은 video 를 재평가해도 샘플의 55~93% 에서 점수가 바뀌는 비재현성 문제가 있다. 강화학습 reward 로 쓸 때 이런 비일관성이 최적화 신호를 흔들 수 있다.

### 5) Interleaved text-image generation

interleaved generation 은 하나의 모델이 텍스트 추론과 중간 image 를 번갈아 만들어내는 방식이다. 'interleaved' 는 텍스트 블록과 image 블록이 교차 배치된다는 뜻이다. 예를 들어 미로에서 각 단계의 위치를 image 로 찍고 그 사이에 "여기서 오른쪽으로 돌았다" 같은 텍스트를 붙이는 식이다. VBVR-Pro 는 같은 문제를 video 로도, 여러 장의 핵심 image 로도, 텍스트 주석과 함께 interleaved 형태로도 표현해 세 가지 생성 기질을 공정하게 비교한다. 이 방식은 비디오 전체를 생성하는 것보다 계산량이 적으면서도 중간 시각 상태를 외부화할 수 있어 실용적 대안이 될 수 있다.

### 6) Chain-of-Step / Multi-Path Exploration

Chain-of-Step 은 diffusion 모델이 한 번에 답을 내는 것이 아니라 denoising 단계를 따라 추론 흔적을 남기는 현상이다. 예를 들어 초기 denoising 단계에서 미로의 여러 후보 경로가 동시에 흐릿하게 그려졌다가 후반 단계에서 가장 짧은 경로 하나로 수렴하는 것을 multi-path exploration 이라 부른다. 또 다른 예로 여러 가능한 시각 상태가 겹쳐 보이다가 마지막에 하나로 모이는 superposition-based exploration 도 관찰된다. VBVR-Pro 는 이 시각화를 통해 모델이 단순히 텍스트 chain-of-thought 을 따라가는 것이 아니라 diffusion 과정 자체에서 시각적 탐색을 수행한다는 증거를 제시한다. 이는 visual generation 이 단순 출력 형식이 아니라 실제 추론 기질이라는 주장을 뒷받침한다.

## 문제의식

기존 visual reasoning 벤치마크는 대부분 평가 전용이라 훈련 데이터를 거의 제공하지 않는다. RISE-Video, V-ReasonBench, RULER-Bench 같은 벤치마크는 수백 개의 문제로 모델을 평가할 수는 있어도, 그 위에서 모델을 훈련할 수 있는 규모의 supervision 은 없다. 반대로 대규모 합성 데이터를 제공하는 연구는 단순한 상징적 설정에 집중해 실제 시각 추론 능력을 가르치는지 불확실했다. 평가 측면에서는 VLM-as-a-judge 가 만연해 있는데, 이는 정확하지 않고 비용이 크며 재실행해도 점수가 달라져 신뢰하기 어렵다. 예를 들어 어떤 VLM judge 는 같은 video 를 다시 평가할 때 92.8% 샘플에서 점수가 바뀌기도 한다. modality 비교도 어려운데, video, image, interleaved 생성기가 서로 다른 데이터와 평가 프로토콜로 시험되어 어느 기질이 왜 더 나은지 원인을 분리할 수 없었다. 이 때문에 "시각 생성을 통한 추론"을 대규모로 훈련하거나 reward 로 최적화하거나 공정하게 비교하는 일이 모두 병목에 막혀 있었다.

## 핵심 아이디어

핵심은 하나의 문제 분포에서 모든 modality 를 동시에 생성하게 하여 통제된 비교를 가능하게 하고, 결정적 scorer 가 평가와 reward 를 동시에 제공하게 하는 폐루프를 만드는 것이다. procedural generator 300 개를 두어 좁은 task 반복이 아니라 넓은 task coverage 로 전이 가능한 기술을 가르친다. video 와 image 는 서로 다른 데이터가 아니라 같은 문제의 다른 렌더링으로 만들어, 모델이 배운 과제 구조는 같되 출력 기질만 다르게 한다. reward scorer 는 VLM judge 와 달리 task-specific rule 로 인간 판단과 정렬되므로 RL reward 로 쓸 때도 잡음이 적다. 마지막으로 이 testbed 를 통해 중간 시각 상태를 제거하거나 오염시키는 개입 실험을 하여 visual trajectory 가 언어 chain-of-thought 보다 더 중요한 기질임을 검증한다. 즉 같은 task space, 같은 verifiable evaluation, 같은 RL pipeline 이라는 세 가지 축이 맞물려야 native visual reasoning 을 과학적으로 연구할 수 있다는 것이 이 논문의 설계 철학이다.

## 방법

### 1) Task design

VBVR-Pro 는 perception, spatiality, transformation, abstraction, knowledge 의 다섯 인지 능력으로 task 를 분류한다. perception 은 OCR, 기호 인식, counting, 정렬이고 spatiality 는 상대 위치와 기하 관계, transformation 은 2D 이동과 회전, abstraction 은 패턴 귀납과 규칙 추론, knowledge 는 아이콘 의미와 물리 현상 등이다. 각 generator 는 grid 크기, 객체 수, 배치, 외형, 난이도 같은 매개변수 공간에서 설정을 뽑아 문제를 만든다. 모든 task 는 해답이 모호하지 않고, 시각 상태 변환이 풀이에 필수적이며, 무작위 시각 다양성이 크도록 설계한다. 또 단순 패턴 매칭이 아니라 여러 단계 추론을 요구하도록 장려한다.

### 2) Multi-modality rendering

한 문제에서 video 와 image 를 함께 만든다. image modality 는 Last-Frame, Key-Frame, Multi-Frame 의 세 가지 출력 체계를 쓴다. Last-Frame 은 최종 상태 하나로 답이 충분한 task, Key-Frame 은 미로 경로처럼 핵심 전이만 남기고 경로를 그려 넣은 task, Multi-Frame 은 시간 연속성이나 프레임 타당성이 중요한 task 에 쓴다. 이렇게 하면 video 의 시간 정보가 image 표현에서도 보존되어 같은 문제를 놓고 image 생성기와 video 생성기를 공정하게 비교할 수 있다.

### 3) Dataset 구성

300 개 task 중 50 개는 훈련에서 완전히 제외한 out-of-domain(OOD) 평가용으로 남긴다. 나머지 250 개 task 에서 각 5,000 개 instance 를 뽑아 1.25M 훈련 instance 를 만든다. VBVR-Pro-Bench 는 OOD 50 개와 훈련에 포함된 in-domain 50 개를 합쳐 총 100 개 task 로 구성한다. RL 실험용으로는 50 개 in-domain task 만 덮는 50K subset 을 따로 둔다.

### 4) Verifiable scorer 구현

100 개 벤치마크 task 각각에 전용 scorer 를 구현한다. HSV 색 분할, contour 검출, OCR, 프레임 추적 등으로 의미 속성을 추출하고 task-specific check 를 적용한다. 예를 들어 색 혼합 task 에서는 생성된 공의 hue 를 확인하고, 원형 고리 task 에서는 원의 개수와 색 보존 여부를 확인한다. hard constraint 는 곱셈, soft criteria 는 가중합으로 결합한다. 이 scorer 는 API 호출이 없고 GPU 는 OCR 정도에만 선택적으로 쓰며 완전 결정적이다.

### 5) RL 학습

baseline 은 VBVR-Pro-Wan2.2-TI2V-5B 를 VBVR-Pro-Dataset 로 SFT 한 모델이다. 같은 50K subset 으로 SFT, RLVLM, RLVR 세 조건을 비교한다. RLVLM 은 Qwen3.6-27B 를 reward judge 로 쓰고, RLVR 은 verifiable scorer 를 reward 로 쓴다. 탐색을 위해 Coefficients-Preserving Sampling(CPS)을 쓴다. 그 수식은 다음과 같다.

$$
x_{t-\Delta t}=(1-(t-\Delta t))\widehat{x}_0+(t-\Delta t)\cos(\eta\pi/2)\widehat{x}_1+(t-\Delta t)\sin(\eta\pi/2)\epsilon
$$

여기서 $x_{t-\Delta t}$ 는 다음 denoising 단계의 잠재 표현, $\widehat{x}_0$ 는 모델이 예측한 깨끗한 샘플, $\widehat{x}_1$ 은 예측된 노이즈, $\epsilon\sim\mathcal{N}(0,I)$ 는 새로 뽑은 표준 정규 노이즈, $\eta\in[0,1]$ 는 확률성 계수, $t$ 와 $\Delta t$ 는 diffusion 시간과 스텝 크기다. $\eta=0$ 이면 결정적 ODE sampling 이 된다. 예측 노이즈 계수의 제곱 $\cos^2(\eta\pi/2)$ 와 새 노이즈 계수의 제곱 $\sin^2(\eta\pi/2)$ 의 합이 1 이므로, $\eta$ 를 키워도 스케줄러가 의도한 전체 노이즈 계수는 늘지 않는다. 즉 새로운 노이즈가 예측 노이즈의 일부를 대체할 뿐이어서 다양성은 높이고 시각 왜곡은 억제한다.

## 왜 성립하는가

### 실험적 근거: 전이 학습이 진짜 시각 추론인가

전이 성립에 관해 논문은 세 가지 진단을 제시한다. 첫째, nearest-neighbor 분석에서 외부 벤치마크 질의와 가장 가까운 훈련 sample 들이 CLIP, DINOv2, BGE 특징 공간에서 시각적·의미적으로 뚜렷이 달라 직접 암기로 설명되지 않는다. 둘째, 같은 프롬프트에 시각 입력만 뒤집거나 180도 회전한 counterfactual 에서도 성능이 0.613으로 유지되어, 모델이 지시문 껍데기가 아니라 시각 상태에 반응한다는 것을 보인다. 셋째, Chain-of-Step 시각화에서 초기 denoising 단계에 여러 후보 해가 탐색되다가 수렴하는 모습은 표면적 instruction pattern fitting 이 아니라 재사용 가능한 시각 연산 학습과 더 일관된다.

### scorer 의 인간 정렬 근거

scorer 의 신뢰성은 human preference arena 로 뒷받침된다. 8 개 video 생성기, 100 task, task 당 1 개 instance 를 뽑아 모델 쌍을 비교하고 각 쌍에 10 명의 인간 주석을 받았다. 이 투표 단위 비교에서 VBVR-Pro scorer 는 0.60 이상의 인간 일치도를 보여 GPT-5.5 의 0.54, Gemini-3.1-Pro 의 0.52 를 넘었다. 인간 주석자 간 일치 천장이 0.77 이므로 완벽 일치는 기대할 수 없지만, 모델 순위 상관은 in-domain Spearman $\rho=0.95$, out-of-domain $\rho=1.00$ 으로 매우 높다.

### visual trajectory 가 핵심 기질이라는 근거

visual trajectory 우위는 training ablation 과 inference intervention 두 갈래에서 확인된다. Table 5 에서 SenseNova-U1 모델은 중간 image 를 한 장으로 줄이면 전체 점수가 0.638에서 0.527로 0.111 떨어지지만, 중간 텍스트를 placeholder 로 바꾸면 0.629로 거의 유지된다. Table 6 의 추론 개입에서는 입력 image 를 제거하면 전체 점수가 0.064로, 중간 image 를 제거하면 0.099로 붕괴하는 반면 중간 텍스트 제거는 0.533으로 훨씬 완만한 저하를 보인다. 이는 시각 상태가 training 에서 더 유용할 뿐 아니라 inference 중에도 실제로 사용되는 작업 기억이라는 인과적 증거다.

### verifiable reward 가 RL 에서 우수하다는 근거

RL 성립은 Table 8 로 확인된다. verifiable reward 를 쓴 RLVR 은 전체 0.548로 SFT 0.503, RLVLM 0.508을 넘는다. OOD 점수도 RLVR 0.377로 SFT 0.328보다 높아 reward-guided 최적화가 훈련 분포 밖 일반화를 개선한다. Figure 11 에서 RLVR 은 100 step 마다 꾸준히 상승하는 반면 RLVLM 은 곧 정체되고 400~500 step 에서 일시 하락한다. 이는 결정적 task-grounded reward 가 잡음이 적은 학습 신호를 제공한다는 해석을 뒷받침한다.

## 구체적 예시

Figure 12 의 color-sequence completion task 는 색 순서를 보고 다음 색을 완성하는 문제다. pre-RL 모델은 denoising 초기 Step 0~3 에서 파란색이라는 오답에 사실상 고정되고 Step 29 까지 그 선택을 바꾸지 않는다. 반면 RLVR 모델은 초반에 보라색이라는 오답을 냈다가 Step 6 에서 예측 색을 수정하기 시작해 Step 29 에 정답인 분홍색에 도달한다. 두 모델 모두 같은 30-step sampling 일정을 쓰므로 이 차이는 추가 계산량 때문이 아니다. 즉 RLVR 은 초기 denoising 이후에도 task-relevant refinement 를 계속 수행하는 later-step self-correction 능력을 보여준다.

Figure 13 의 maze navigation 예는 점수 변화가 더 극적이다. pre-RL 모델은 81 프레임 전체에서 에이전트 위치가 이어지지 않고 여러 곳에 끊겨 나타나 유효한 경로를 만들지 못해 score 0.2249 를 받는다. RLVR 모델은 Start-to-Red, Red-to-Cyan, Cyan-to-Goal 의 3 단계로 이어지는 일관된 방향 궤적을 만들고 결국 목표에 도달해 score 0.8692 를 받는다. 이 개선은 최종 프레임 하나가 아니라 중간 상태 전이의 시간적 일관성에서 나타난다. 즉 RLVR 은 고정된 denoising 예산 안에서도 다단계 공간 계획을 유지하고 실행하는 능력을 강화한다.

## 실험과 결과

Table 4 는 30 개 이상의 모델을 VBVR-Pro-Bench 에서 비교한다. 오픈소스 모델 9 개를 VBVR-Pro-Dataset 로 훈련했을 때 평균 전체 점수 이득이 0.290 이었고, in-domain 평균 이득은 0.401, out-of-domain 평균 이득은 0.179였다. 예를 들어 Wan2.2-I2V-A14B 는 기본 점수 0.182에서 VBVR-Pro-Wan2.2-I2V-A14B 로 0.670까지 올라 가장 강한 오픈소스 video 모델이 되었고, SenseNova-U1 은 0.408에서 0.638로 올랐다. 하지만 가장 강한 훈련 모델조차 인간 수준보다 크게 낮아 개선 여지가 크다.

modality 비교에서는 video 모델이 OOD transformation 같은 시간 상태 추적에서 강하고, interleaved 모델은 많은 in-domain task 에서 video 에 필적하면서도 생성 비용이 적어 정확도-효율 trade-off 가 좋다. 단일 image 생성은 중간 상태를 담지 못해 transformation task 에서 크게 약하다. Table 5 의 ablation 이 이를 뒷받침한다.

외부 전이 평가 Table 7 에서 VBVR-Pro-Wan2.2-I2V-A14B 는 Wan2.2-I2V-A14B 기본 모델 대비 V-ReasonBench 를 10.21에서 38.22로, VideoThinkBench mini 를 25.71에서 52.86으로, MME-CoF-Pro 를 24.76에서 48.39로, BabyVision-Gen 을 0.36에서 12.50으로 끌어올렸다. 이는 절차적으로 만든 추상 장면 학습이 실제 장면과 로봇 조작 추론으로 전이됨을 보여준다.

RL 실험 Table 8 에서는 같은 SFT 초기화와 같은 50K 데이터에서 RLVR 이 전체 0.548, in-domain 0.719, out-of-domain 0.377로 가장 높다. RLVLM 은 0.508, SFT 는 0.503이다. Figure 11 의 훈련 곡선에서 RLVR 의 상승세가 지속되는 반면 RLVLM 은 불안정하다. 이 결과들은 verifiable reward 가 VLM judge 보다 강화학습 reward 로 우수하다는 직접 증거다.

## 한계

논문은 가장 강한 훈련 모델조차 인간 수준에 크게 미치지 못한다고 명시한다. verifiable scorer 의 인간 일치도가 0.60 을 넘지만 인간 주석자 천장 0.77보다 낮아, 어려운 비교에서는 scorer 도 완벽하지 않다는 한계가 있다. scorer 는 VBVR-Pro-Bench 의 100 개 task 에 구현되어 있고 전체 300 개 task 전부에 대해 공개된 것은 아니다. 훈련 데이터는 절차적으로 생성된 추상 장면 중심이라 실제 세계의 복잡한 시각 장면과 조명, 실사 객체와는 차이가 있을 수 있다. RLVR 의 OOD 성능이 0.377로 여전히 낮아, RL 이 out-of-domain task 전이를 어디까지 확장하는지는 더 연구가 필요하다. RLVLM 의 400~500 step 불안정은 부록에서 조사되었지만, verifiable scorer 를 만들기 어려운 개방형 실제 task 에는 이 방법을 바로 쓰기 어렵다는 약점이 있다. 논문에 명시는 없으나, procedural generator 와 scorer 를 새 task 마다 설계하는 비용이 크다는 점도 실무 적용의 제약이다.

## 왜 중요한가

이 논문은 visual generation 이 단순한 출력 형식이 아니라 추론 기질이 될 수 있다는 것을 훈련-평가-최적화 세 축에서 체계적으로 보여준다. 후속 연구는 VBVR-Pro 의 verifiable scorer 를 재사용해 다양한 video, image, interleaved 모델의 RL 을 공정하게 비교할 수 있다. 실무적으로는 미로 내비게이션, 로봇 조작, 게임 전략, 설계 검증처럼 공간적·시간적 정확성이 중요한 생성형 AI 에서 VLM judge 대신 결정적 scorer 를 쓰면 평가 비용과 비재현성을 크게 줄일 수 있다. interleaved generation 이 계산 효율이 좋다는 결과는 실시간 추론이 필요한 응용에서 video 대신 멀티 프레임 image 와 텍스트를 쓰는 실용적 대안을 제시한다. 마지막으로 visual trajectory 가 언어 chain-of-thought 보다 중요하다는 발견은 언어 중심 추론 패러다임과 보완적인 native visual reasoning 이라는 연구 분야를 여는 신호다.

## 원문 초록

> Native visual reasoning treats visual generation as the medium of reasoning itself: visual states (i.e. images and videos) are not merely inputs to be understood or outputs to be rendered, but first-class substrates for problem solving beyond language. Yet progress remains bottlenecked by the lack of scalable training tasks, reliable feedback, and controlled comparisons across generative substrates. In this work, we introduce VBVR-Pro, a closed-loop testbed that makes native visual reasoning through generation trainable, verifiable, optimizable, and experimentally controllable. 1) Task scaling. VBVR-Pro turns visual reasoning into a controlled task space of 300 procedurally generated tasks. Models trained on VBVR-Pro show strong transfer beyond the proposed suite across seven external visual reasoning benchmarks such as RISE-Video, MME-CoF-Pro, and BabyVision. 2) Verifiable rewards. VBVR-Pro provides verifiable reward scorers for task-grounded evaluation. Through a systematic study of leading MLLMs as judges, we identify recurring failure modes of the prevalent VLM-as-a-judge paradigm. In contrast, the proposed scorers are grounded in deterministic, task-specific rules, achieve fine-grained alignment with human judgments. Importantly, they serve as reliable reward signals for large-scale multi-task reinforcement learning and demonstrate stronger post-RL performance across visual reasoning tasks. 3) Mechanism study. VBVR-Pro enables controlled modality studies across more than 30 image, video, and interleaved generators. Our analysis shows that video generation remains strongest for tasks requiring persistent spatiotemporal state tracking, while interleaved generation provides a compute-efficient alternative. Critically, ablations and probing suggest the presence of vision-native trajectories that are crucial to visual reasoning. We release all data, models, scorers, and code.
