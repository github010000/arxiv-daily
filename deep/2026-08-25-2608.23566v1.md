## 한 줄 요약

BPCO는 critic 기반 강화학습이 불안정해지는 원인들을 통제 실험으로 분리해 내고, DPPO와 보상 범위로 제한된 value prediction, Monte Carlo value target, 정규화하지 않은 advantage, length-adaptive GAE를 결합해 프롬프트당 응답 하나만으로도 group 기반 방식에 맞먹거나 더 나은 안정적 critic 학습 조리법을 제시한다.

## 핵심 개념 풀이

### credit assignment와 advantage

강화학습으로 언어 모델을 학습시킬 때, 모델은 프롬프트에 대한 응답을 토큰 단위로 하나씩 생성한다. 그런데 보상은 대개 응답이 끝난 뒤에 한 번만 주어진다. 예를 들어 수학 문제 풀이에서 최종 답이 맞으면 1점, 틀리면 0점을 받는다고 하자. 응답 전체가 맞았다고 해서 모든 토큰이 다 좋은 토큰이었던 것은 아니다. 중간에 실수했지만 나중에 우연히 바로잡았을 수도 있고, 초반 토큰은 매우 좋았는데 후반부 한 토큰 때문에 전부 틀렸을 수도 있다. 이렇게 최종 결과에 각 토큰이 얼마나 기여했는지를 나누는 문제를 credit assignment라고 부른다.

advantage는 특정 상태에서 특정 토큰을 선택한 것이 평균적인 기대보다 얼마나 더 좋은 결과를 가져왔는지를 나타내는 값이다. advantage가 양수이면 그 토큰을 고를 확률을 높이고, 음수이면 낮추는 방식으로 정책을 갱신한다. critic 기반 방식의 핵심 동기는 이 advantage를 응답 하나만으로도 토큰 단위로 추정하려는 것이다. group 기반 방식은 응답 여러 개를 뽑아 최종 보상을 비교하기 때문에 토큰 단위 정보가 사라진다.

### value function과 critic

value function $V(s_t)$는 어떤 접두사 상태 $s_t$, 즉 프롬프트와 지금까지 생성된 토큰들까지 주어졌을 때 앞으로 받을 최종 보상의 기댓값을 뜻한다. 예를 들어 이진 보상 문제라면 $V(s_t)$는 "지금 이 상태에서 계속 생성을 했을 때 최종 답이 맞을 확률"로 해석할 수 있다. critic은 이 value function을 근사하는 신경망이다. 논문에서는 critic $V_\phi(s_t)$가 접두사마다 성공 확률 같은 값을 출력하도록 학습시킨다.

critic을 학습시키려면 어떤 값에 가까워져야 하는지 목표가 필요하다. 그 목표를 value target이라고 부른다. critic은 보통 policy가 생성한 rollout 데이터를 회귀 문제처럼 학습한다. 중요한 점은 critic이 학습 중에만 쓰이고 배포 시에는 버려진다는 것이다. 이 때문에 critic의 입력을 policy와 다르게 줄 수 있다는 아이디어가 이 논문의 privileged information 개념으로 이어진다.

### Generalized Advantage Estimation과 bootstrapping

Generalized Advantage Estimation, 줄여서 GAE는 advantage를 추정할 때 한 단계만 보는 추정과 끝까지 보는 추정을 섞는 방법이다. 먼저 temporal-difference residual $\delta_t$를 계산한다. 이는 "다음 상태의 value가 현재 상태의 value보다 얼마나 높아졌는가"에 해당한다. 식으로는 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$인데, 여기서 $r_t$는 즉시 보상, $\gamma$는 할인율이다. 언어 모델의 outcome reward 문제에서는 중간 보상이 없고 마지막에만 보상이 있으므로 대부분 $r_t=0$이고 $\gamma=1$로 둔다.

GAE는 이 residual들을 $\lambda$라는 계수로 지수적으로 가중합한다. $\lambda=1$이면 사실상 최종 보상까지 전부 반영하는 Monte Carlo 추정이 된다. $\lambda<1$이면 critic이 예측한 다음 상태 value, 즉 이전 critic의 추정치를 더 많이 사용한다. 이렇게 자기 자신의 예측을 목표에 사용하는 것을 bootstrapping이라고 한다. bootstrapping은 분산을 줄여 주지만 critic이 틀리면 그 오차가 advantage와 value target에 그대로 스며든다. GAE의 $\lambda$는 이 편향과 분산 사이를 조절하는 손잡이다.

### PPO clipping과 DPPO

Proximal Policy Optimization, PPO는 정책이 한 번에 너무 크게 바뀌지 않도록 확률 비율 $\rho_t$를 clipping한다. $\rho_t$는 현재 정책이 특정 토큰을 고를 확률 $\pi_\theta(y_t|s_t)$을 rollout을 생성한 과거 행동 정책 $\mu(y_t|s_t)$로 나눈 값이다. PPO는 $\rho_t$를 $1-\epsilon$과 $1+\epsilon$ 사이로 잘라서, advantage가 가리키는 방향으로 확률 비율을 무한정 키우거나 줄이지 못하게 만든다. 이렇게 하면 정책 갱신이 작은 신뢰 영역 안에 머무른다.

그런데 언어 모델의 어휘는 수만 개에 이르고, 특정 토큰이 뽑힐 확률은 토큰마다 크게 다르다. 같은 비율 clipping을 적용하면 원래 확률이 0.5인 토큰은 절대 확률 변화가 0.1까지 허용되지만, 원래 확률이 0.001인 토큰은 0.0002까지만 바뀔 수 있다. 이는 저확률 토큰과 고확률 토큰을 매우 불균등하게 다룬다. DPPO는 clipping 경계를 $\epsilon/\mu(y_t|s_t)$로 바꿔서, 모든 토큰이 동일한 절대 확률 변화 $\epsilon$ 안에서만 움직이도록 한다. 이 논문은 DPPO를 기본 정책 최적화기로 사용한다.

### group 기반 방식

GRPO 같은 group 기반 방식은 critic을 학습시키는 대신 프롬프트 하나에 응답을 여러 개 생성한다. 그리고 같은 프롬프트에서 나온 응답들의 보상 평균과 표준편차를 구해, 평균보다 높은 응답에는 양수 advantage를, 낮은 응답에는 음수 advantage를 준다. 이렇게 하면 critic 없이도 응답 간 상대 비교로 advantage를 만들 수 있다. Dr. GRPO는 표준편차로 나누는 정규화를 제거한 변형이다. 표준편차 정규화는 프롬프트 내 보상 분산이 작으면 작은 차이를 과장하고, 분산이 크면 큰 차이를 축소할 수 있기 때문이다.

group 방식의 단점은 프롬프트마다 여러 rollout을 뽑아야 한다는 점이다. 또한 응답 하나 안의 모든 토큰에 같은 advantage를 부여하므로 토큰 단위 credit assignment를 하지 못한다. 예를 들어 틀린 응답 안에 아주 좋은 초반 토큰이 있었더라도 모든 토큰이 똑같이 음수 advantage를 받는다. critic 기반 방식은 이와 달리 응답 하나만으로도 접두사마다 다른 advantage를 만들 수 있다.

### privileged information

critic은 학습 중에만 사용되므로 policy가 받는 입력과 다른 입력을 받을 수 있다. 수학 문제에서 정답 참조값이나 공식 풀이를 critic에게 추가로 알려 주는 것이 그 예이다. 이 정보 $q(x)$는 프롬프트 $x$가 정해지면 같이 정해지는 평가 관련 정보이므로, 이상적인 value function 자체를 바꾸지는 않는다. 다만 유한한 크기의 신경망이 그 value function을 더 쉽게 근사하도록 도울 수 있다.

이 아이디어는 다중 에이전트 강화학습의 centralized training with decentralized execution과 비슷하다. 학습 시에는 중앙 critic이 게임의 숨은 상태를 볼 수 있지만, 실제 행동하는 policy는 자기 관측만 사용하는 구조다. 이 논문에서는 정답 답안, 공식 풀이, grading rubric 같은 보상 정의 정보를 critic에만 제공한다. privileged information이 항상 좋은 것은 아니며, 작은 데이터에서는 critic이 빨리 학습되는 만큼 과적합도 빨라질 수 있다.

## 문제의식

critic 기반 LLM 강화학습은 이론적으로는 응답 하나만으로 토큰 단위 advantage를 만들 수 있지만 실제로는 불안정하다. 이 논문은 그 불안정성이 여러 가지 구현 선택들이 서로 어긋나서 생긴다고 본다. 기존 PPO의 ratio clipping은 어휘 내 저확률 토큰과 고확률 토큰을 다르게 취급한다. 이로 인해 특정 토큰은 거의 안 바뀌고, 특정 토큰은 지나치게 크게 바뀌는 불균형 갱신이 일어난다.

또한 표준 GAE value target은 $\lambda<1$일 때 이전 critic의 예측을 포함한다. 이는 bootstrapping이므로 critic 오차가 목표에 누적될 수 있다. 게다가 학습이 잘 되고 있는지 보는 explained variance 지표조차 잘못된 신호를 줄 수 있다. 부트스트랩된 목표를 critic이 거의 완벽하게 맞추는 것처럼 보여도, 그 목표 자체가 이미 치우쳐 있으면 실제 최종 보상을 잘 예측한다는 뜻이 되지 않는다.

고정된 GAE $\lambda$도 응답 길이에 따라 다른 효과를 만든다. $\lambda=0.99$라면 최종 보상의 영향이 가장 첫 토큰까지 전파될 때 대략 $0.99^L$이라는 계수가 곱해진다. 응답이 짧으면 이 계수가 크고, 응답이 길면 아주 작아진다. 즉 긴 응답의 초반 토큰들은 최종 보상 신호를 거의 받지 못하고, 짧은 응답의 토큰들은 상대적으로 강하게 받는다. 이는 바람직하지 않은 길이 편향이다.

논문은 두 가지 구현상 문제를 추가로 지적한다. 첫째, 많은 구현이 선형 value head를 쓰는데 이는 보상의 실제 범위를 벗어난 값을 출력할 수 있다. 예를 들어 보상이 [0,1]로 알려져 있는데 value head가 2.5나 -1.8을 출력할 수 있다. 기대 보상은 항상 보상 범위 안에 있어야 하므로 이는 구조적으로 잘못된 출력이다. 둘째, 배치마다 advantage를 평균 0, 표준편차 1로 정규화하는 구현이 많다. 정책이 거의 최적에 가까워져 advantage가 0 근처에서 작게 흔들릴 때, 표준편차로 나누면 작은 잡음을 큰 학습 신호로 바꿔서 갱신이 줄어들지 않게 만든다.

group 방식은 critic 없이 안정적일 수 있지만 프롬프트당 응답을 여러 개 샘플링해야 하고, 응답 내 모든 토큰에 같은 advantage를 준다. critic을 안정적으로 학습시키는 조리법이 있다면 샘플 효율성과 토큰 단위 credit assignment 양쪽 이점을 얻을 수 있다. 그러나 그동안 표준 critic recipe가 불안정해서 실무에서는 group 방식이 널리 쓰였다.

## 핵심 아이디어

BPCO의 핵심은 critic의 출력 범위, critic의 학습 목표, critic이 만든 policy advantage 신호가 모두 보상 구조와 정합하도록 맞추는 것이다. value prediction은 보상 범위로 제한하고, value target은 부트스트랩되지 않은 Monte Carlo 결과로 바꾸고, policy advantage는 정규화하지 않고 그대로 사용하며, GAE $\lambda$는 응답 길이에 맞게 조정한다. 여기에 DPPO를 써서 토큰별 확률 변화를 공정하게 clipping한다.

이 아이디어가 문제를 푸는 이유는 각 요소가 기존 불안정성의 특정 원인을 직접 제거하기 때문이다. 선형 value head가 보상 범위를 벗어나면 advantage 자체의 scale이 잘못될 수 있으므로 arctangent로 범위를 제한한다. value target에 이전 critic의 예측이 들어가면 치우친 목표와 critic 오차가 증폭될 수 있으므로 최종 보상 자체를 목표로 쓴다. advantage 정규화는 수렴 직전의 작은 신호를 과장하므로 raw advantage를 유지한다. 고정 $\lambda$는 길이에 따라 최종 보상의 영향이 달라지므로 길이 적응형 $\lambda$를 쓴다.

또 하나의 핵심은 critic이 학습 중에만 존재한다는 점을 적극적으로 이용하는 것이다. critic에게는 정답, 공식 풀이, rubric 같은 평가 기준 정보를 추가 입력으로 줄 수 있다. 이 정보는 policy의 입력이나 배포 환경을 바꾸지 않으면서, critic이 더 쉬운 함수 근사 문제를 풀게 만든다. 다만 이득은 과적합 위험과 함께 오므로 항상 좋은 것은 아니다.

논문은 각 선택을 통제 실험으로 분리해서 보여 준다. 작은 데이터에서도 최적화 문제를 드러내는 sanity test를 만든 뒤, 한 번에 한 구성 요소만 바꾸면서 학습 안정성과 일반화 지표를 관찰했다. 그 결과 각 변경이 실제로 어떤 불안정성을 제거하는지 인과적으로 드러난다. 최종 BPCO는 이 변경들을 결합한 recipe이다.

## 방법

### 1단계: PPO를 DPPO로 교체한다

PPO의 목적식은 $\mathcal{L}_{\mathrm{PPO}} = \mathbb{E}_t[\min(\rho_t \hat A_t, \operatorname{clip}(\rho_t, 1-\epsilon, 1+\epsilon)\hat A_t)]$이다. 여기서 $\rho_t = \pi_\theta(y_t|s_t) / \mu(y_t|s_t)$는 rollout 당시 정책 $\mu$와 현재 정책 $\pi_\theta$ 사이의 토큰별 확률 비율이다. $\hat A_t$는 advantage 추정치다. advantage가 양수면 $\rho_t$를 키우는 방향으로, 음수면 줄이는 방향으로 유도하되 clipping으로 신뢰 영역을 만든다.

DPPO는 clipping 경계를 $\epsilon/\mu(y_t|s_t)$로 바꾼다. 즉 $\operatorname{clip}(\rho_t, 1-\epsilon/\mu(y_t|s_t), 1+\epsilon/\mu(y_t|s_t))$를 사용한다. 부등식을 풀면 $|\pi_\theta(y_t|s_t)-\mu(y_t|s_t)| \le \epsilon$과 동등하다. 따라서 모든 토큰이 동일한 절대 확률 변화 한도 $\epsilon$을 갖는다. sanity test에서 PPO는 학습 보상이 올라가다가 붕괴했지만 DPPO는 $\lambda=1$에서 안정적이었다. 그러나 $\lambda$를 0.99로 낮추면 DPPO도 다시 불안정해져서, policy clipping만으로는 충분하지 않다는 것이 드러났다.

### 2단계: value prediction을 보상 범위로 제한한다

보상이 $[R_{\min}, R_{\max}]$ 안에 있다면 그 기댓값도 같은 구간 안에 있어야 한다. 그런데 선형 head는 임의의 실수를 출력하므로 이 성질을 어긴다. 논문은 head의 raw 출력 $z_\phi(s_t)$를 arctangent로 압축한다.

$$V_\phi(s_t)=R_{\min}+(R_{\max}-R_{\min})\left(\frac{1}{2}+\frac{1}{\pi}\arctan(z_\phi(s_t))\right)$$

arctangent는 실수 전체를 $(-\pi/2,\pi/2)$로 보내므로, 이 값은 항상 열린 구간 $(R_{\min}, R_{\max})$ 안에 들어온다. 이진 보상에서는 $R_{\min}=0, R_{\max}=1$이므로 critic 출력이 항상 (0,1) 안에 있다. 예를 들어 $z=3$이면 $V \approx 0.897$, $z=-3$이면 $V \approx 0.103$이 된다. 이 제한은 선형 head가 만들던 극단값을 없애고 학습 보상이 1에 가까워지도록 만들었다.

### 3단계: unbiased Monte Carlo value target을 쓴다

기존 구현은 critic target으로 $\widehat{V}_t(\lambda)=\widehat{A}_t^{\mathrm{GAE}(\lambda)}+V_{\phi_{\mathrm{old}}}(s_t)$를 쓴다. 이 목표에는 $\lambda<1$일 때 이전 critic $V_{\phi_{\mathrm{old}}}$가 들어 있다. 따라서 목표 자체가 critic의 오차를 포함하는 biased target이 된다. 논문은 policy advantage와 critic target의 $\lambda$를 분리한다. policy advantage에는 분산을 줄이기 위해 $\lambda_\pi=0.99$를 쓰지만, critic target에는 $\lambda_V=1$을 쓴다.

$\gamma=1$이고 중간 보상이 없고 최종 보상만 있다면 $\lambda_V=1$일 때 목표가 다음처럼 단순해진다.

$$\widehat{V}_t = \widehat{A}_t^{\mathrm{GAE}(1)}+V_{\phi_{\mathrm{old}}}(s_t)=R(x,y)$$

즉 critic은 최종 보상 결과를 직접 맞추게 된다. 이는 현재 접두사에서 계속 샘플링했을 때의 최종 보상에 대한 unbiased Monte Carlo 표본이다. 부트스트랩 목표와 달리 critic 오차가 목표에 다시 들어가지 않는다. explained variance를 부트스트랩 목표 기준으로 계산하면 critic이 금세 1에 가까워 보이지만, 그 목표 자체가 biased이기 때문에 실제 관측 보상을 잘 맞춘다는 뜻은 아니다. 관측 결과를 목표로 삼은 뒤 explained variance가 비로소 정직한 지표가 된다.

### 4단계: advantage normalization을 제거한다

많은 PPO 구현은 policy 갱신 전에 배치 내 advantage를 평균 0, 표준편차 1로 정규화한다. 배치 평균 $\bar A$와 표준편차 $\sigma_A$로 $\widetilde{A}_t=(\hat A_t-\bar A)/\sigma_A$를 만드는 것이다. 이 변환은 정책이 거의 최적에 가까워질 때 문제가 된다. advantage가 0 근처에서 작게 흔들리면, raw advantage는 "이제 더 배울 것이 거의 없다"는 신호를 담고 있다. 그런데 표준편차로 나누면 작은 추정 잡음이 다시 큰 학습 신호로 증폭된다.

또한 평균을 빼면 양수 advantage라도 배치 평균보다 작으면 음수로 뒤집힐 수 있다. 예를 들어 raw advantage가 [0.004, 0.005, -0.004, -0.005]라면 실제로는 절반은 약한 양수, 절반은 약한 음수인데, 표준편차가 작으면 정규화 뒤에는 값들이 크게 벌어진다. 논문은 이 정규화를 제거하고 raw GAE advantage를 policy 갱신에 그대로 사용한다. 이렇게 하면 정책이 최적에 가까워질수록 갱신 크기가 자연스럽게 줄어든다.

### 5단계: critic에게만 privileged information을 준다

critic은 학습 중에만 쓰이므로 policy가 받지 못하는 평가 정보를 critic에게 줄 수 있다. 수학 문제에서 $q(x)$는 정답 참조값 또는 공식 풀이가 될 수 있다. privileged critic은 $V^\mu_\phi(s_t,q(x)) \approx \mathbb{E}_\mu[R(x,y;q(x)) \mid s_t,q(x)]$를 학습한다. $q(x)$는 프롬프트 $x$에 의해 정해지는 값이므로 이상적인 value function을 바꾸지 않는다. 다만 네트워크가 value를 근사하기 쉽게 만든다.

sanity test에서 정답 참조값을 critic에만 주었을 때 학습 보상 상승이 빨라졌고 explained variance도 높아졌다. 하지만 AIME 2025 avg@32는 더 빨리 오르다가 더 일찍 정점을 찍고 하락했다. 이는 critic이 더 정확해지면 학습은 빨라지지만 작은 데이터에서는 과적합도 빨라질 수 있음을 보여 준다.

### 6단계: length-adaptive GAE를 도입한다

고정 $\lambda_\pi$는 응답 길이에 따라 최종 보상의 영향이 크게 달라지는 문제가 있다. 길이 $L=|y|$에 대해 policy용 $\lambda_\pi$를 다음과 같이 정한다.

$$\lambda_\pi(L)=1-\frac{1}{\alpha L}$$

여기서 $\alpha>0$는 편향과 분산의 trade-off를 조절하는 하이퍼파라미터다. 가장 첫 토큰의 advantage에서 최종 residual에 붙는 계수는 대략 $(1-\frac{1}{\alpha L})^L \approx \exp(-1/\alpha)$가 되어 응답 길이에 거의 무관해진다. $\alpha$가 클수록 이 계수가 1에 가까워져 Monte Carlo에 가깝고, 작을수록 더 많이 할인되어 bootstrapping에 가깝다. 논문의 sanity test에서는 $\alpha=0.4$가 가장 좋은 trade-off를 보였다. critic target은 여전히 $\lambda_V=1$을 유지한다.

## 왜 성립하는가

이 논문은 수학적 증명보다 통제된 경험적 근거로 각 구성 요소의 역할을 보인다. 먼저 작고 풀 수 있는 1,460개 문제를 사용해, 좋은 recipe라면 학습 보상을 거의 100%까지 올려야 하는 sanity test를 설계했다. 초기 모델이 이미 풀 수 있는 문제들이므로 실패의 원인을 모델 용량이나 보상 신호 부족이 아니라 최적화 문제로 해석할 수 있다는 점이 중요하다. 여기서 PPO가 붕괴하고 DPPO가 안정되는 것을 확인했다. 하지만 DPPO도 $\lambda=0.99$에서 불안정해졌으므로 policy clipping만으로 불안정성이 다 설명되지 않는다.

value bound가 성립하는 이유는 보상의 기댓값은 항상 보상 범위 안에 있어야 한다는 단순한 사실에 있다. arctangent parameterization은 임의의 head 출력을 유한한 구간으로 보내므로 구조적으로 잘못된 critic 출력이 나올 수 없다. 선형 head의 극단 출력이 사라지면서 advantage의 scale도 안정화된다. empirical 결과로는 unbounded head가 [0,1]을 벗어나는 값을 출력할 때 학습 보상이 불안정했고, bounded head는 학습 보상이 1에 접근했다.

Monte Carlo target의 타당성은 $\gamma=1$, outcome reward, $\lambda_V=1$이라는 조건에서 목표가 정확히 최종 보상 $R(x,y)$로 telescoping 된다는 계산에서 나온다. 이 목표는 현재 접두사에서 계속 rollout했을 때 얻는 보상의 기댓값에 대한 unbiased 표본이다. 부트스트랩 목표와 달리 이전 critic의 오차를 포함하지 않으므로 critic이 자신의 편향을 점점 더 크게 학습하는 피드백 고리를 끊는다. explained variance가 부트스트랩 목표에서 거의 1이 되는 것이 실제로는 정확도를 뜻하지 않는다는 관찰은 이 지표 해석의 함정을 잘 보여 준다.

advantage normalization 제거는 "학습 신호가 0으로 수렴해야 한다"는 원칙에 근거한다. 정책이 최적에 가까워지면 advantage는 0에 가까워지고 variance도 작아져야 한다. raw advantage를 쓰면 갱신이 자연히 줄어든다. 표준편차로 나누면 이 자연스러운 감쇠가 사라지고 잡음을 일정한 크기로 증폭한다. controlled study에서 normalization을 없앤 경우 advantage range가 작고 안정적으로 유지되었고, normalization을 쓰면 policy가 최적에 가까워질수록 advantage magnitude가 커지는 문제가 관찰되었다.

length-adaptive GAE는 지수 할인 계수가 길이에 따라 얼마나 달라지는지를 직접 계산한 근거로 도입되었다. 고정 $\lambda=0.99$는 길이가 20이면 최종 residual 계수가 약 0.818이지만 길이가 2000이면 약 $1.9\times10^{-9}$가 된다. 이렇게 되면 긴 응답의 초반 토큰에는 최종 보상 신호가 거의 도달하지 않는다. LA-GAE는 $1-1/(\alpha L)$로 이 계수를 길이와 무관하게 $\exp(-1/\alpha)$ 근처로 유지한다. 실험에서 고정 $\lambda=0.99$는 학습은 빠르지만 검증 성능이 정점 후 급락했고, $\lambda=1$은 느리지만 안정적이었으며, $\alpha=0.4$가 그 사이의 균형을 잡았다.

## 구체적 예시

length-adaptive GAE의 효과를 숫자로 따라가 보자. 이진 보상 문제에서 최종 보상이 응답 끝의 한 지점에서만 주어진다고 하자. policy advantage의 첫 토큰에는 마지막 temporal-difference residual에 $\lambda_\pi^L$이 곱해진다. 만약 $\lambda_\pi=0.99$로 고정되어 있으면 응답 길이 $L=20$일 때 $0.99^{20}\approx 0.818$이다. 즉 최종 보상 신호의 약 82%가 첫 토큰까지 전달된다. 그런데 같은 $\lambda$로 $L=2000$이면 $0.99^{2000}\approx 1.9\times10^{-9}$이다. 최종 보상 신호가 사실상 0이 되어 첫 토큰은 무엇을 배워야 할지 알 수 없다.

이제 LA-GAE를 $\alpha=0.4$로 적용해 보자. $L=20$이면 $\lambda_\pi(20)=1-\frac{1}{0.4\times20}=1-\frac{1}{8}=0.875$다. 이 계수를 첫 토큰까지 전파하면 $0.875^{20}\approx 0.069$가 된다. $L=2000$이면 $\lambda_\pi(2000)=1-\frac{1}{0.4\times2000}=1-\frac{1}{800}=0.99875$가 되고, 이를 2000제곱하면 $0.99875^{2000}\approx 0.082$가 된다. 두 값은 정확히 같지는 않지만 같은 0.1 근처에 있다. 고정 $\lambda$에서 0.818과 $1.9\times10^{-9}$가 나던 것과 비교하면 길이 불균형이 크게 해소된다.

왜 이런 근사가 성립하는지도 살펴볼 수 있다. $\lambda=1-\frac{1}{\alpha L}$일 때 $\ln\lambda \approx -\frac{1}{\alpha L}$이므로 $L\ln\lambda \approx -\frac{1}{\alpha}$다. 따라서 $\lambda^L \approx \exp(-1/\alpha)$가 된다. $\alpha=0.4$이면 $\exp(-2.5)\approx 0.082$다. $L$이 충분히 크면 모든 길이에서 첫 토큰이 받는 최종 보상 신호가 이 값 근처로 수렴한다. 이처럼 LA-GAE는 "긴 응답은 초반 토큰을 최적화하기 어렵고 짧은 응답은 과하게 최적화된다"는 문제를 길이 불변 계수로 완화한다.

## 실험과 결과

sanity test는 DeepSeek-R1-Distill-Qwen-1.5B를 초기 모델이 이미 풀 수 있는 1,460개 수학 문제에 fine-tuning했다. 각 iteration은 1,024개 trajectory를 포함하고, minibatch 크기는 256, 최적화 epoch은 1이며 policy learning rate는 $10^{-6}$, critic learning rate는 $10^{-5}$다. 각 run은 1,500 iterations 동안 진행된다. 과적합 여부는 AIME 2025 avg@32, 즉 문제당 32개 응답을 표집했을 때의 평균 정확도로 관찰했다. PPO는 학습 보상이 붕괴했고, DPPO와 $\lambda=1$이 안정적이었다. 그러나 $\lambda=0.99$에서는 DPPO도 불안정했다.

대규모 데이터 실험에서는 DeepScaleR 데이터셋을 사용했다. 이 데이터셋은 40.3K개의 수학 문제-답 쌍으로 구성되어 있고, 약 7.3K개 문제에 공식 풀이가 있다. 최대 응답 길이는 24k로 제한했다. 그룹 기반 baseline은 Dr. GRPO를 사용하고 group size 16으로 총 배치 크기를 맞추었다. critic 기반 baseline은 decoupled GAE와 length-adaptive GAE 같은 기존 기법을 포함하지만 unbounded value head와 advantage normalization을 유지한다. 이 설정에서 BPCO는 critic baseline과 group baseline을 모두 일관되게 앞섰다. 학습 중 explained variance도 critic baseline보다 지속적으로 높았는데, 이는 BPCO가 실제로 더 나은 critic을 학습한다

## 원문 초록

> Group-based reinforcement learning methods such as GRPO for large language models avoid training a critic by sampling multiple responses for each prompt. A reliable critic could instead estimate token-level advantages from one response, but standard critic-based training recipes are often unstable. We study this instability and develop \textbf{Best-Practice Critic Optimization (BPCO)}, a recipe that combines DPPO, value predictions bounded to the reward range, Monte Carlo value targets, unnormalized policy advantages, and length-adaptive generalized advantage estimation. Because the critic is used only during training, BPCO can also condition it on reward-defining information, such as a reference answer or grading rubric, that is hidden from the policy. Controlled experiments isolate the effect of each design choice. Across mathematical reasoning tasks with models ranging from 1.5B parameters to 30B-A3B mixtures of experts, BPCO improves a strong critic-based baseline consistently, and matches or exceeds a group-based baseline while sampling one response per prompt. The same recipe also improves learning with rubric-based rewards. These results show that a carefully designed critic provides a reliable alternative to group-relative advantage estimation. Code is available at https://github.com/QPHutu/golden_critic
