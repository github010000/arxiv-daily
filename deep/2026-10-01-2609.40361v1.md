## 한 줄 요약

이 논문은 multimodal large language model(MLLM)이 임상 진단을 할 때 accuracy 대신 AUROC를 prompt 최적화 목표로 삼도록, prompt 진화 과정의 평가 행렬 row를 instance 단위 correctness에서 positive-negative pair의 순서 비교로 바꾸는 Ranking-PE를 제안하고, MIMIC의 세 질환에서 accuracy 기반 prompt 진화보다 AUROC와 balanced accuracy를 모두 크게 끌어올린다.

## 핵심 개념 풀이

**AUROC와 ROC curve**

AUROC는 Area Under the Receiver Operating Characteristic curve의 약자이다. 모델이 어떤 질환에 대한 연속 점수를 출력한다고 하면, 이 점수에 임계값을 적용해 양성과 음성을 나누게 된다. 임계값을 낮추면 양성으로 판정하는 범위가 넓어져 true positive rate는 올라가지만 false positive rate도 함께 올라간다. ROC curve는 이렇게 임계값을 바꿔 가며 얻은 true positive rate와 false positive rate의 조합을 그린 곡선이고, AUROC는 그 아래 면적이다. AUROC는 곧 "양성 환자 하나와 음성 환자 하나를 무작위로 뽑았을 때, 모델이 양성 환자에게 더 높은 점수를 줄 확률"이라는 해석을 가진다. 이 점 때문에 AUROC는 임계값을 미리 고르지 않아도 되는 threshold-free 지표이고, 클래스 비율이 한쪽으로 쏠려 있어도 분포 자체의 변별 순위를 평가할 수 있다.

**Class imbalance와 accuracy의 함정**

의료 데이터는 질환이 있는 환자와 없는 환자의 비율이 극단적으로 다른 경우가 흔하다. 예를 들어 어떤 검사 집단에서 양성 비율이 96%라면, 모든 환자를 무조건 "양성"이라고 답하는 단순 모델도 accuracy는 96%가 된다. 하지만 이런 모델은 음성 환자를 전혀 구분하지 못하므로 임상적으로는 쓸모가 없다. accuracy는 "전체 중 몇 개를 맞혔는가"만 보기 때문에, 다수 class에 찍는 행동을 오히려 보상한다. 반면 AUROC는 양성과 음성을 상대적으로 잘 줄 세우는지 본다. 그래서 class imbalance가 심한 임상 진단에서는 accuracy만 보고 모델을 고르거나 prompt를 최적화하면, 실제로는 나쁜 ranking 모델을 좋은 모델로 착각하게 된다.

**Prompt 최적화와 reflective prompt evolution**

Prompt 최적화는 모델 가중치를 바꾸지 않고, 모델에 입력으로 주는 instruction 텍스트만 탐색하여 성능을 높이는 방법이다. reflective prompt evolution은 이 탐색을 언어 모델이 스스로 수행하게 만든다. 먼저 여러 후보 prompt를 검증 데이터에서 평가하고, 어떤 예제를 틀렸는지 같은 신호를 텍스트로 만든다. 그 뒤 reflector로 불리는 언어 모델이 이 텍스트 진단을 읽고 "다음에 시도할 prompt"를 새로 제안한다. Reflective라는 이름은 모델이 단순히 확률적 탐색을 하는 것이 아니라, 실패 사례를 읽고 원인을 추론하듯 prompt를 수정한다는 점에서 붙었다. 이 계열에는 GEPA, DSPy, APO 같은 시스템이 있다.

**Scores matrix와 row schema**

Reflective prompt evolution은 보통 후보 prompt별 성능을 scores matrix라는 표로 관리한다. 원래 accuracy 기반 방식에서는 이 표의 row 하나하나가 검증 instance 하나에 대응하고, column 하나하나가 후보 prompt 하나에 대응한다. 각 cell에는 "이 후보 prompt가 이 instance를 맞혔는가"를 나타내는 1 또는 0이 들어간다. 그 column 평균이 곧 그 prompt의 accuracy가 되고, 이 accuracy가 후보 prompt 선택과 final selection을 지배한다. 이 논문은 이 matrix에서 row가 어떤 사건을 기록하는가 하는 row schema 자체가 검색의 숨은 최적화 단위라고 본다. row를 instance correctness로 두면 column 평균은 accuracy가 되지만, row를 positive-negative pair의 순서 비교로 바꾸면 column 평균이 AUROC가 된다.

**Log-odds score와 Wilcoxon-Mann-Whitney identity**

MLLM이 "Yes" 또는 "No" 토큰을 출력한다고 할 때, 두 토큰의 log probability 차이를 모델의 연속 점수로 사용할 수 있다. 이것이 log-odds score이고, 별도 모델 forward pass를 추가하지 않고도 decoding 과정에서 이미 얻은 token logprob에서 읽을 수 있다. 한편 Wilcoxon-Mann-Whitney identity는 통계에서 "두 집단의 값을 한 쌍씩 비교해 순서가 맞는 비율"이 곧 AUROC와 같다는 정리이다. 구체적으로, 모든 positive 하나와 negative 하나의 쌍에 대해 positive 점수가 더 높으면 1, 낮으면 0, 같으면 0.5를 매기고 이를 평균하면 empirical AUROC가 된다. 이 identity 덕분에 scores matrix의 row를 pair로 바꾸는 것만으로도 column 평균을 AUROC로 만들 수 있다.

## 문제의식

기존 MLLM 적응 파이프라인은 거의 대부분 accuracy 기반 목적 함수에 묶여 있다. 그런데 임상 데이터는 class imbalance가 심하기 때문에 accuracy는 위험한 지표가 된다. 예를 들어 병변이 흔한 질환에서는 대부분 "있다"고 답하면 accuracy가 높게 나온다. 실제로 이 논문이 사용한 Atelectasis task의 positive prevalence는 96.2%에 달한다. 이런 상황에서는 모든 환자를 양성으로 찍는 prompt가 accuracy 기준으로 좋아 보일 수 있고, prompt 탐색은 점점 더 그런 방향으로 prompt를 진화시킬 수 있다.

기존 reflective prompt evolution 시스템은 scores matrix의 row로 instance correctness를 기록한다. row가 instance 단위이므로 column 평균은 accuracy가 되고, Pareto filtering, 다음 후보 prompt 생성에 쓰이는 피드백, 최종 prompt 선택이 모두 accuracy 신호에 이끌린다. 그 결과 검색이 ranking을 악화시키는 prompt를 선택할 수 있다. 논문의 실험에서는 MedGemma-4B에 accuracy 기반 prompt evolution을 적용했을 때 평균 AUROC가 53.5%로 base 모델의 59.3%보다 오히려 5.8 percentage point 낮아졌다. 즉 accuracy 기반 검색이 모델이 원래 가진 ranking 신호를 깎아먹는 failure mode가 실제로 나타난다.

또한 임상 오류의 비용은 비대칭이다. 놓친 consolidation은 false alarm보다 훨씬 위험할 수 있는데, accuracy는 이 비대칭성을 구조적으로 표현할 수 없다. accuracy 기반 prompt 진화는 틀린 예제 리스트만 reflector에게 알려줄 뿐, 그 틀림이 위험한 false negative인지, 점수가 애매해서인지, 다른 음성 예제보다 순위가 뒤집혀서인지 알려주지 않는다. 따라서 임상 screening이나 triage처럼 나중에 운영점을 잡아야 하는 실제 workflow에서는 accuracy를 최적화하고 보고하는 것 자체가 MLLM 개발 방향을 잘못 인도한다.

## 핵심 아이디어

핵심 아이디어는 prompt search가 읽는 scores matrix의 row 사건을 정확히 갈아끼우는 것이다. instance correctness를 row로 쓰면 column 평균이 accuracy가 되지만, positive-negative pair의 순서를 row로 쓰면 column 평균이 Wilcoxon-Mann-Whitney identity에 의해 empirical AUROC가 된다. 이렇게 하면 파라미터를 다시 학습하거나 surrogate loss를 도입할 필요 없이, 검색의 목적 함수가 accuracy에서 AUROC로 바뀐다.

이 갈아끼움을 한 곳만 하는 것이 아니라, prompt evolution이 신호를 소비하는 세 층위 모두에 적용한다. 첫째, Pareto dominance를 결정하는 scores matrix 자체이다. 둘째, reflector가 새 prompt를 제안할 때 읽는 예제별 피드백이다. 셋째, 마지막에 최종 prompt를 고르는 final selection이다. final selection만 AUROC로 바꾸어도 이미 생성된 후보 풀 자체가 accuracy 쪽으로 치우쳐 있으면 검색 방향을 되돌리기 어렵다. 반대로 matrix만 AUROC로 바꾸고 reflector 피드백이 여전히 correctness만 알려주면, reflector는 ranking을 움직이는 prompt를 잘 제안하지 못한다. 따라서 세 층을 함께 정렬해야 한다.

이 방식이 가능한 이유는 prompt evolution이 gradient 기반 optimizer가 아니라 discrete search이기 때문이다. gradient descent는 지시 함수 $1[s(x^+) > s(x^-)]$를 미분할 수 없어 logistic 같은 surrogate로 smoothing해야 한다. 하지만 reflective prompt search는 cell 값을 미분하는 것이 아니라, 후보 prompt를 Pareto로 거르고 column 평균으로 고르는 discrete 연산만 하므로 지시 함수를 있는 그대로 쓸 수 있다. 그래서 relaxed surrogate도, auxiliary loss도, 추가 model rollouts도 없이 비분리적 ranking 목적을 그대로 최적화하게 된다.

마지막으로, 좋은 ranking 신호는 prompt search만으로는 충분하지 않을 수 있다. 이 논문은 의료 영상에 적응된 visual backbone이 전제 조건이라고 본다. 의료용 사전학습이 된 MedGemma를 쓰거나, vision encoder를 포함해 SFT를 하는 것이 그 토대를 만든다. 그 위에 Ranking-PE를 얹으면 accuracy 기반으로는 얻지 못하는 AUROC 향상이 나온다.

## 방법

먼저 이진 임상 진단 task를 정의한다. 입력 $x$는 chest X-ray 이미지와 structured electronic health record(EHR) 텍스트의 쌍 $x=(\mathrm{image}, \mathrm{ehr})$이다. 질환 $d$가 주어지면 모델은 "Does this patient have disease $d$?" 같은 templated question에 답하고, 출력은 Yes 토큰과 No 토큰에 대한 분포가 된다.

AUROC처럼 ranking을 평가하려면 이산 label이 아니라 연속 점수가 필요하다. 이 논문은 표준 decoding pass에서 이미 얻는 answer-token logprob을 사용한다. top-k logprob에서 Yes와 No의 log probability를 읽고, 다음과 같은 log-odds score를 만든다.

```math
s_{\Phi}(x,d) = \log p_{\Phi}(\mathrm{Yes}\mid x,d) - \log p_{\Phi}(\mathrm{No}\mid x,d).
```

이 $s_{\Phi}(x,d)$는 이후 scores matrix, reflector 피드백, final selection이 모두 소비하는 단일 점수다. 추가 rollout 비용이 들지 않는다는 점이 중요하다.

AUROC는 아래처럼 임계값 없이 양성 점수가 음성 점수보다 높을 확률로 정의된다.

```math
\mathrm{AUROC}(\Phi) = \Pr(s_{\Phi}(X^+) > s_{\Phi}(X^-)) + \frac12 \Pr(s_{\Phi}(X^+) = s_{\Phi}(X^-)).
```

여기서 $X^+$는 양성 환자, $X^-$는 음성 환자다.

Stage 1은 SFT이다. 학습 데이터에는 이미지, EHR, 질환, ground-truth Yes/No 토큰이 포함된다. 손실 함수는 정답 토큰의 next-token log-likelihood를 최대화하는 표준적인 supervised loss다.

```math
\mathcal{L}_{\mathrm{SFT}}(\theta) = -\frac{1}{L}\sum_{n=1}^{L} \log p_{\theta}(y_n \mid x_n, d_n).
```

Qwen 실험에서는 언어 backbone에 LoRA adapter를 붙이고 vision encoder 전체를 학습시키는 vision-encoder-tuned SFT가 vision encoder를 frozen한 SFT보다 이후 prompt evolution까지 갔을 때 AUROC가 더 높았다. 처음부터 의료 사전학습이 된 MedGemma 같은 checkpoint에서는 Stage 1을 건너뛰고 Stage 2만 수행한다.

Stage 2가 Ranking-PE이다. 원래 accuracy 기반 방식에서는 scores matrix $M$의 row가 instance $n$이고 cell은 $M_{n,k}=1[\Phi_k \text{ correct on } n]$가 된다. 이 column 평균은 accuracy다. Ranking-PE는 row를 positive-negative pair로 바꾼다. positive 집합 $P$, negative 집합 $N$에 대해 pair score를 다음과 같이 정의한다.

```math
r(a,b) = 1[a>b] + \frac12 1[a=b].
```

이는 양성 점수가 음성 점수보다 높으면 1, 같으면 0.5, 낮으면 0이다. 이 $r$을 모든 pair에 대해 평균하면 empirical AUROC가 된다.

```math
\mathrm{AUROC}(\Phi) = \frac{1}{|P||N|} \sum_{(i,j)\in P\times N} r(s_{\Phi}(x_i^+), s_{\Phi}(x_j^-)).
```

따라서 pair-indexed matrix $\tilde{M}_{(i,j),k}=r(s_{\Phi_k}(x_i^+), s_{\Phi_k}(x_j^-))$의 column 평균은 validation AUROC가 된다. final selection은 이 column 평균을 최대화하는 prompt를 고른다. 즉 $\Phi^*=\arg\max_k \mathrm{AUROC}(\Phi_k)$가 된다. Pareto dominance도 달라진다. 어떤 후보 prompt가 다른 후보 prompt보다 모든 pair row에서 점수가 같거나 높고, 적어도 한 row에서는 더 높다면 다른 후보를 dominate한다. 이 dominance가 instance correctness 집합이 아니라 pairwise ordering 집합 기준으로 일어난다.

pair 수가 너무 커질 경우에는 max_pairs 개수만큼 row를 uniform subsample한다. 이렇게 해서 얻은 column 평균은 empirical AUROC의 unbiased Monte Carlo estimator이므로 최적화하는 양은 그대로 AUROC이고, 추정치의 variance만 달라진다.

reflector 피드백도 ranking에 맞게 보강한다. 원래 피드백 $\mu_f(x_n,\hat{y}_{n,k},y_n)$은 사실상 "맞았는가" 하나로 요약된다. Ranking-PE는 여기에 세 가지 텍스트 신호를 추가한다. 첫째는 TP, TN, FN, FP라는 clinical error type이다. FN은 "clinically dangerous"라고 명시해 임상 검진에서 false negative가 더 위험하다는 비대칭 비용을 reflector에게 드러낸다. 둘째는 confidence magnitude로, log-odds score $s_{\Phi_k}(x_n)$의 부호와 크기를 low, moderate, high, extremely high 같은 자연어 bucket으로 함께 준다. 셋째는 cross-example rank context다. 가장 최근에 완전히 평가된 후보 prompt의 검증 점수 분포를 참조로 하여, 현재 예제의 score가 같은 class의 다른 검증 예제들과 비교해 어느 위치에 있는지를 알려준다. 양성 예제라면 양성 참조 점수 분포 안에서의 순위 비율을 주고, 음성 예제라면 음성 참조 점수 분포 안에서의 순위 비율을 준다. 이 세 가지는 cached된 검증 점수로 계산할 수 있어서 pair-level matrix 없이도 독립적으로 사용할 수 있다.

Ranking-PE는 세 가지 정렬을 누적해서 얹는다. 첫째, AUROC 기반 final selection. 둘째, pair-level Pareto scoring. 셋째, ranking-shaped feedback. 실험의 component ablation에서는 pair-level matrix가 accuracy 기반보다 AUROC를 높이고, ranking-shaped feedback을 더하면 가장 높은 AUROC가 된다.

## 왜 성립하는가

이 방식의 정당성은 Wilcoxon-Mann-Whitney identity에서 거의 직접 나온다. AUROC는 연속 정의상 양성 점수가 음성 점수보다 높을 확률이다. 유한한 검증 집합에서는 이 확률이 모든 $(positive, negative)$ pair에 대한 순서 비교의 평균으로 정확히 실현된다. 그래서 $\tilde{M}$의 column 평균이 empirical AUROC와 일치하고, final selection이 곧 validation AUROC 최대화가 된다.

Pareto filtering도 row 사건이 pair가 된 상태에서는 ranking 목적에 안전하다. 후보 prompt $A$가 후보 prompt $B$를 pair-level로 dominate한다는 것은, $A$가 $B$보다 어떤 pair에서도 더 나쁘지 않고 적어도 한 pair에서는 더 좋다는 뜻이다. 각 pair의 $r$ 값이 AUROC를 구성하는 기본 단위이므로, 이 조건이면 $A$의 AUROC는 $B$보다 낮을 수 없다. 따라서 $B$를 버려도 AUROC 최대 후보를 잃지 않는다. 이는 accuracy 기반 dominance가 "더 많은 instance를 맞힌 prompt"만 보존하는 것과 논리적으로 같은 구조를 ranking 사건에 대해 반복한 것이다.

reflector 피드백이 ranking-shaped이어야 하는 이유는, scores matrix가 아무리 AUROC를 정확히 추정해도 다음 prompt를 만드는 reflector가 correctness 비트만 본다면 탐색이 여전히 accuracy 쪽으로 갈 수 있기 때문이다. confidence magnitude와 cross-example rank context는 "양성 환자 점수가 음성 환자들보다 충분히 높지 않다"는 정보를 reflector가 텍스트로 받아들이게 한다. clinical error type은 accuracy가 표현하지 못하는 false negative의 임상적 비용까지 전달한다. component ablation에서 ranking feedback을 뺀 pair-level Pareto만으로는 평균 AUROC가 70.7%에 머물고, feedback을 더해야 73.8%로 오르는 것이 이 주장을 뒷받침한다.

또 하나 중요한 이유는, prompt search가 지시 함수를 미분하지 않기 때문이다. 기존 learning-to-rank에서는 $1[s(x^+)>s(x^-)]$를 직접 쓰면 gradient가 없으므로 logistic이나 hinge 같은 surrogate로 smoothing한다. 하지만 Ranking-PE의 최적화 단계는 후보 prompt를 discrete하게 비교하고 선택하는 것이지, 점수를 미분해 가중치를 갱신하는 것이 아니다. 따라서 smoothing 없이 $1$과 $0.5$와 $0$을 그대로 쓸 수 있고, 최적화되는 양은 relaxed surrogate가 아니라 empirical pairwise ranking objective 그 자체가 된다.

마지막으로 pair subsampling의 불편성도 성립한다. 전체 $P\times N$ row에서 무작위로 max_pairs개만 뽑아 평균하면, 기댓값은 전체 row 평균과 같다. 따라서 subsampling으로 계산량을 줄여도 탐색이 목표로 하는 AUROC 추정량은 바뀌지 않는다. 실험에서는 pair cap을 300에서 10,000까지 바꿔도 Cardiomegaly AUROC가 70.6%에서 71.3% 사이로 0.7 percentage point 정도만 흔들려, cap 선택에 강건함을 보인다.

## 구체적 예시

Ranking-PE의 점수 계산을 작은 예시로 재현할 수 있다. 어떤 후보 prompt에 대해 양성 환자 2명의 log-odds score가 $x_1^+=0.85$, $x_2^+=0.55$이고 음성 환자 2명의 score가 $x_1^-=0.60$, $x_2^-=0.30$이라고 하자. 만들 수 있는 positive-negative pair는 4개다. 첫 번째 pair $(0.85, 0.60)$은 양성이 더 높으므로 $r=1$이다. 두 번째 pair $(0.85, 0.30)$도 $r=1$이다. 세 번째 pair $(0.55, 0.60)$은 양성이 음성보다 낮으므로 $r=0$이다. 네 번째 pair $(0.55, 0.30)$은 다시 $r=1$이다. 네 pair의 평균은 $(1+1+0+1)/4 = 0.75$다. 이는 이 prompt가 4개 pair 중 3개에서 순서를 맞혔다는 뜻이고, empirical AUROC도 0.75다. 만약 어떤 pair의 양성 점수와 음성 점수가 정확히 같다면 그 pair는 0.5로 계산되어 AUROC 정의의 tie 처리와 일치한다.

이 원리가 실제 실험에서 어떤 차이를 만드는지가 Table 1의 Atelectasis에서 잘 보인다. Atelectasis는 positive prevalence가 96.2%로 극단적으로 불균형하다. Qwen3-VL-8B + SFT(VE-tuned) 조건에서 Accuracy-PE는 AUROC 63.6%와 balanced accuracy 45.4%를 기록한다. 같은 SFT base에 Ranking-PE를 적용하면 AUROC는 70.7%, balanced accuracy는 70.9%가 된다. AUROC 차이는 +7.1 percentage point, balanced accuracy 차이는 +25.5 percentage point다. balanced accuracy는 sensitivity와 specificity의 평균인데, 단순히 다수 class를 찍으면 50% 정도에 머문다. Accuracy-PE의 45.4%는 사실상 이런 극단 불균형 task에서 model이 ranking을 잘 못 만들고 있음을 보여준다. Ranking-PE의 70.9%는 양성과 음성을 어느 정도 구분하기 시작했다는 뜻이다.

MedGemma-4B의 Atelectasis에서는 base AUROC가 46.7%인데 Accuracy-PE는 46.4%로 거의 그대로이고, Ranking-PE는 69.1%로 크게 오른다. 이는 accuracy 기반 검색이 남긴 prompt 풀에서는 AUROC가 나아지지 않지만, pair-level row로 검색을 돌리면 음성 예제와 양성 예제의 상대 순서를 뒤집는 prompt를 찾아낼 수 있음을 보여준다. balanced accuracy도 Accuracy-PE의 47.9%에서 Ranking-PE는 60.5%가 된다.

## 실험과 결과

실험 데이터는 MIMIC-CXR 흉부 X선 영상을 MIMIC-IV의 structured EHR 문맥과 연결한 것이다. disease task는 Atelectasis, Cardiomegaly, Consolidation 세 가지이며, 전체 코호트 positive prevalence는 각각 96.2%, 78.7%, 68.9%다. primary metric은 AUROC이고, ranking 향상이 실제 classification 성능도 함께 올리는지 확인하기 위해 default decoder threshold에서 balanced accuracy를 보고, AUPRC는 appendix에서 보강한다.

주 실험인 Table 1에서 Qwen3-VL-8B + SFT(VE-tuned) 조건의 Ranking-PE는 평균 AUROC 73.8%와 평균 balanced accuracy 68.6%를 기록한다. Accuracy-PE는 같은 조건에서 평균 AUROC 68.0%, balanced accuracy 55.1%다. Ranking-PE가 accuracy 기반 방식보다 AUROC에서 +5.8 percentage point, balanced accuracy에서 +13.5 percentage point 높다. MedGemma-4B에서는 Ranking-PE가 평균 AUROC 69.7%로 Accuracy-PE의 53.5%보다 +16.2 percentage point 높다. MedGemma base의 평균 AUROC가 59.3%이므로, Accuracy-PE는 base보다 -5.8 percentage point로 ranking을 악화시켰지만 Ranking-PE는 base보다 +10.4 percentage point 개선했다. 이는 accuracy 최적화 prompt search가 ranking 신호를 깎을 수 있다는 경고를 수치로 보여준다.

대안 목적 함수들과의 비교도 있다. balanced accuracy selection, class-weighted instance score, scalar-AUROC search 중 Qwen에서는 scalar-AUROC search가 평균 69.6%로 가장 강하지만 Ranking-PE의 73.8%보다 +4.2 percentage point 낮다. MedGemma에서는 balanced-accuracy selection이 평균 59.0%로 가장 강하지만 Ranking-PE의 69.7%보다 +10.7 percentage point 낮다. 즉 단순히 selection metric만 바꾸거나 클래스 가중치를 주는 정도로는 pair-level Pareto와 ranking-shaped feedback이 합쳐진 효과를 따라잡지 못한다.

Matrix-metric ablation인 Table 3은 각 구성 요소의 기여를 분해한다. Accuracy-PE에서 final selection만 AUROC로 바꾸면 평균 AUROC가 68.0%에서 61.3%로 오히려 떨어진다. 이는 후보 prompt 생성과 Pareto filtering은 여전히 accuracy에 잡혀 있는데 마지막에 AUROC로 고르기만 하면, accuracy 기준으로는 좋지만 ranking 기준으로는 나쁜 prompt들을 억지로 고르게 되기 때문이다. 여기에 pair-level Pareto matrix를 더하면 평균 AUROC가 70.7%로 올라 Accuracy-PE보다 +2.7 percentage point 높아진다. 여기에 ranking-shaped feedback을 더하면 73.8%에 도달한다. 반대로 full method에서 pair-level Pareto만 instance-level matrix로 되돌리면 평균 AUROC가 65.8%로 떨어진다. 이는 pair-level matrix가 feedback 이전 단계에서도 이득을 만들고, 둘이 결합될 때 가장 강하다는 것을 보여준다.

SFT staging 실험에서는 Qwen3-VL-8B에 SFT 없이 Ranking-PE만 쓰면 평균 AUROC가 68.4%이고, vision encoder를 frozen한 SFT 위에서는 70.3%, vision encoder를 tuned한 SFT 위에서는 73.8%가 된다. VE-tuned SFT가 VE-frozen SFT보다 +3.5 percentage point 높아, vision encoder tuning이 language-side LoRA만으로는 얻지 못하는 추가 이득을 만든다. 같은 4B 규모 비교에서는 의료 사전학습 모델 MedGemma-4B에 Ranking-PE를 적용한 평균 AUROC가 69.7%인 반면, 같은 계열의 비의료 control Gemma3-4B는 51.6%에 그친다. gap이 18.1 percentage point다. 즉 vision-encoder-tuned SFT든 medical pretraining이든 의료 시각 토대가 있어야 prompt search가 ranking을 살릴 수 있다.

reflector를 바꾸는 실험도 있다. Qwen3-VL-8B + SFT(VE-tuned) 파이프라인에서 task adapt된 self-reflector를 GPT-5-nano나 GPT-5-mini로 바꾸면 평균 AUROC가 73.8%에서 각각 66.7%, 67.9%로 떨어진다. 이 setting에서는 일반 closed-source reflector가 task-adapted self-reflection을 대체하지 못한다는 결론이 나온다.

## 한계

저자가 밝힌 한계는 우선 평가 범위가 MIMIC-IV 기반 세 질환, 두 MLLM 계열로 제한되어 있다는 점이다. 다른 영상 modality, 다른 언어, 다른 label space에는 검증되지 않았다. pair-level Pareto formulation은 binary AUROC를 기준으로 설계되었고, multi-label이나 ordinal 확장은 자연스럽지만 실험되지 않았다. 평가에 사용한 patient-disjoint test set은 규모가 작고, 특히 negative minority의 표현이 제한적일 수 있다.

closed-source 모델은 top-k logprob 접근이 제한되어 3-level verbal score로 대체했기 때문에, Table 1에서 closed-source zero-shot 결과는 open-source 행과 완전히 동등하게 해석하기 어렵다. 저자는 open-source recipe 중심으로 비교를 보라고 명시한다. 또한 이 논문은 실제 임상 배포 시스템을 만든 것이 아니라 평가와 최적화 방법론을 제안한 것이며, 전향적 검증이나 clinician oversight 없이 사용해서는 안 된다고 강조한다.

읽으며 드러나는 추가 약점은, pair subsampling을 하면 AUROC 추정의 variance가 커질 수 있고, pair cap의 강건성은 일부 disease에서만 보고되었다는 점이다. ranking-shaped feedback도 여러 텍스트 신호의 조합으로 구성되는데, feedback-signal ablation은 질환별로 일부만 제시되어 신호별 기여가 모든 disease에서 동일하게 안정적인지는 명확하지 않다. 의료 visual backbone이 전제 조건이라는 주장은 실험적으로 설득력이 있지만, 그 인과 경로까지 세밀하게 분해하지는 않았다.

## 왜 중요한가

이 논문은 임상 MLLM adaptation에서 accuracy보다 AUROC를 최적화해야 한다는 실용적 방향을 구체적인 prompt 최적화 방법으로 보여준다. 특히 accuracy 기반 prompt evolution이 어떤 경우에는 base 모델의 ranking 신호를 오히려 깎아내릴 수 있다는 경고는 중요하다. 기존 DSPy, GEPA 같은 시스템을 쓰는 실무자라면, scores matrix의 row 사건만 바꾸고 reflector 피드백을 ranking 정보로 보강하는 방식으로 지금 가진 파이프라인을 AUROC 기반으로 바꿀 수 있다. 모델을 다시 학습하거나 surrogate loss를 도입하거나 추가 rollout을 할 필요가 없다는 점이 실무적 매력이다.

이론적으로는 "row schema"라는 관점을 제시했다는 점이 후속 연구에 유용하다. instance-level Pareto는 accuracy를 만들고, pair-level Pareto는 unrelaxed empirical ranking objective를 만든다. 같은 black-box prompt 검색 시스템에서 row 사건을 바꾸는 것만으로 다른 지표를 최적화할 수 있다는 event-space lens는 앞으로 multi-label이나 ordinal AUROC처럼 더 복잡한 임상 목표로 확장할 때 자연스러운 출발점이 된다.

또한 gradient가 없는 방식에서는 지시 함수를 smoothing하지 않고 AUROC를 직접 최적화할 수 있다는 사실을 보여준다. learning-to-rank 전통에서는 미분을 위해 지시 함수를 logistic이나 hinge로 근사해야 했지만, prompt evolution은 discrete search이기 때문에 그 근사가 필요 없다. 이는 prompt 최적화가 ranking metric처럼 비분리적이고 비볼록한 지표를 다루는 데에서 기존 gradient 기반 classifier 학습보다 오히려 구조적으로 유리할 수 있음을 시사한다.

마지막으로, ranking-aware prompt optimization만으로는 부족하고 medical-grade visual backbone이 선행되어야 한다는 실험 결과는 의료 MLLM 실무에서 adaptation 순서를 어떻게 설계할지에 대한 지침을 준다. 먼저 vision encoder를 포함한 SFT 또는 medical pretraining으로 의료 영상 신호를 정렬한 뒤, 그 위에서 AUROC에 정렬된 prompt search를 돌리는 two-stage recipe가 accuracy 기반 대안보다 훨씬 안정적이다.

## 원문 초록

> Multimodal large language models (MLLMs) are rapidly advancing clinical diagnosis, yet their adaptation pipelines remain anchored to accuracy-based objectives. Clinical data are heavily class-imbalanced: a constant-majority predictor can score above 90% accuracy while being clinically useless. We therefore evaluate and optimize for AUROC, a threshold-free score that ranks positives above negatives and is invariant to class balance. We focus on prompt optimization in MLLMs. Reflective methods such as GEPA use a binary scores matrix with one row per evaluation instance and one column per candidate prompt; cells record per-instance correctness, so the column average is accuracy and drives candidate selection. We introduce pair-level Pareto prompt evolution (Ranking-PE), which replaces each correctness row with a pairwise-ordering row over (positive, negative) instance pairs: the cell is 1 if the candidate scores the positive higher than the paired negative. The column average then equals empirical AUROC (by the Wilcoxon-Mann-Whitney identity). We apply this swap at all three layers the prompt evolution search reads from - the scores matrix that decides Pareto dominance, the per-example feedback to the reflection LM, and final candidate selection - at no extra model calls and with no surrogate loss. Across three diseases on MIMIC, accuracy-based prompt evolution can degrade ranking; Ranking-PE reverses this, beating the accuracy-based recipe by +5.8 AUROC pp on fine-tuned Qwen3-VL-8B and +16.2 pp on MedGemma-4B. Ablations examine each design component and show that a medical-grade visual backbone - via vision-encoder-tuned SFT or medical pretraining - is a prerequisite that prompt search cannot replace - our recipe extends reflective prompt evolution from text-only data to multimodal clinical decision-making.
