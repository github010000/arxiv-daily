## 한 줄 요약

instruction fine-tuning 을 거친 언어 모델은 하나의 genre(이 논문이 "instructional-conversational genre" 라 부르는 것)를 구현한 결과물이며, system prompt 와 special token 과 chat template 이라는 장치들이 그 genre 의 표지로서 사용자를 이미 시작되어 있는 대화 속의 "Human" 역할에 미리 배치한다.

## 핵심 개념 풀이

### 1. genre 는 "텍스트의 종류"가 아니라 "반복되는 사회적 행위"

일상적으로 genre 라 하면 소설·시·수필 같은 문학 분류를 떠올리기 쉽다. 그런데 이 논문이 쓰는 genre 는 그보다 훨씬 넓고, 오히려 "상황에 대한 사회적 반응의 정형화된 묶음"에 가깝다. 수사학자 Carolyn R. Miller 의 정의가 이 논문의 축인데, 그녀는 genre 를 내용이나 형식적 특징이 아니라 "반복적이고 유의미한 행위(recurrent, significant action)"로 규정한다. 결혼식 축사, 학회 발표의 첫 인사말, 중고거래 앱의 판매글, 논문의 감사의 글 같은 것들이 전부 genre 인 이유는 그것들이 정해진 문장 구조를 갖기 때문이 아니라, **같은 사회적 상황이 반복되면서 사람들이 그 상황에 응답하는 방식을 서로 학습하고 기대하게 되기 때문**이다. 그래서 genre 를 알면 "이 자리에서 나는 무엇을 할 수 있고 무엇은 하면 안 되는가"가 미리 정해진다. 이 논문이 chatbot 을 genre 로 보는 이유가 여기에 있다. chatbot 과의 대화 역시 "질문하면 친절하게 답하는 상대"라는 반복된 상황이며, 사용자는 그 상황에 맞는 말투와 기대를 이미 가지고 들어간다.

### 2. Bakhtin 의 speech genre 와 Derrida 의 "참여" 및 "표지"

Mikhail Bakhtin 은 genre 를 훨씬 잘게 쪼갠다. 그에게 speech genre 는 한 단어짜리 감탄부터 소설 전체까지 이어지는 연속체이며, 결정적으로 **발화는 혼자 존재하지 않고 "발화 소통의 사슬"의 한 고리**다. 어떤 말을 하려면 그 말 앞에 있었던 말들(상대가 방금 한 말, 그 주제에 대해 관례적으로 해온 말들)을 이미 전제하고 있어야 한다. 이 관점을 chatbot 에 적용하면, 모델의 응답을 prompt 와 분리해서 읽는 것은 원리적으로 불가능하다. 응답은 prompt 를 포함한 입력 전체의 사슬 안에서만 의미를 갖기 때문이다.

여기에 Jacques Derrida 의 장르론이 겹쳐진다. Derrida 에게 genre 는 텍스트가 "소유"하는 것이 아니라 텍스트가 "참여(participate)"하는 것이다. 그리고 아주 중요한 대목이 따라붙는데, 어떤 텍스트가 특정 genre 에 속한다는 것을 알려주는 표지(re-mark)는 **그 genre 안에 있지 않고 바깥에 있다**는 것이다. 책 표지의 "장편소설"이라는 글자가 본문 바깥에 있으면서 본문을 장편소설로 만들어 주는 것과 같다. 이 논문의 핵심 주장 중 하나가 바로 이것이다. `[INST]` 같은 special token 은 대화의 내용물이 아니면서 대화를 instruction-following 대화로 만들어 주는, genre 의 외부 표지라는 것이다.

### 3. instruction fine-tuning 과 RLHF — "정렬"의 원래 뜻

base 언어 모델은 인터넷 텍스트로 "다음 token 맞히기"만 배운 모델이다. 이 모델에게 "기후 변화에 대한 시를 써 줘"라고 하면, 시를 쓰는 대신 "기후 변화에 대한 시를 써 달라는 요청이 인터넷에 많이 있었다"는 식의 글을 이어 붙일 수 있다. 목표 함수가 "다음을 예측하기"였을 뿐 "지시를 따르기"는 아니었기 때문이다. instruction fine-tuning 은 여기에 두 번째 목표를 얹는다. 사람이 같은 prompt 에 대한 두 응답을 보고 더 나은 쪽(chosen)과 나쁜 쪽(rejected)을 고르면, 모델은 chosen 쪽의 확률이 올라가고 rejected 쪽이 내려가도록 가중치를 조정받는다. 이 논문은 이 과정을 "이진 분류와 크게 다르지 않은 강화 절차"라고 표현한다.

흥미로운 것은 "alignment" 라는 단어의 원래 용법이다. 지금은 "인간 가치에 맞춘 윤리적 모델"이라는 거창한 뜻으로 쓰이지만, InstructGPT 논문에서 alignment 는 우선 **"사용자의 지시를 잘 따르게 만드는 일"**을 뜻했다. OpenAI 연구진 스스로 "우리는 GPT-3 의 행동을 특정 집단(라벨러와 연구자)의 진술된 선호에 맞춘 것일 뿐, '인간 가치'라는 더 넓은 개념에 맞춘 것이 아니다"라고 적었다. 즉 지금 우리가 쓰는 chatbot 의 말투와 성격은 윤리 철학의 산물이라기보다, 라벨러 집단이 반복적으로 "이쪽이 낫다"고 고른 선택의 통계적 잔 sediment 인 셈이다.

### 4. system prompt — 텍스트 안에 있으면서 바깥에 있는 것

사용자가 보는 화면에는 자기 prompt 만 보이지만, 실제로 모델에 들어가는 token 열의 맨 앞에는 사용자가 쓴 적 없는 긴 지시문이 붙어 있다. 이것이 system prompt 다. 이 논문이 주목하는 것은 그 위치의 기묘함이다. system prompt 는 사용자에게 보이지 않으므로 "시스템의 일부"처럼 보이지만, 실제로는 다른 모든 입력과 똑같이 token 화되어 모델에 들어가는 텍스트다. 저자는 Gérard Genette 의 paratext 개념을 빌려 그것을 "서문"에 비유한다. 서문은 본문 앞에 있지만 책이라는 틀 안에 포함되어 있고, 독자가 본문을 읽는 방식에 영향을 준다. 다만 이 서문은 저자가 쓴 것이 아니라 편집자가 쓴 서문이고, 그 편집자는 뒤에 오는 텍스트의 저자를 약간 의심하고 있다. 실제로 Anthropic 이 공개한 Claude 용 system prompt 는 `<tone_and_formatting>` 같은 tag 로 구획된 구조화된 문서이며, "격식 없는 대화에서는 목록을 쓰지 말고 문장으로 답하라" 같은 아주 구체적인 문체 지시를 담고 있다.

### 5. interpellation 과 Kenneth Burke 의 parlor

Louis Althusser 의 interpellation(호명)은 어떤 사람이 "너!"라고 불리는 순간 그 호출에 해당하는 주체 위치를 자기 것으로 받아들이게 되는 과정을 말한다. 이 논문은 RLHF 데이터셋의 구조가 사용자를 그런 식으로 미리 호명한다고 본다. Anthropic 의 데이터셋에서 모든 대화는 "Human" 과 "Assistant" 라는 두 역할로 라벨링되어 있고, red-team prompt 라는 범주는 "사용자는 신뢰할 수 없으며 악의적일 수 있다"는 전제를 제도화한다. 사용자는 자기가 그런 사람인지 생각할 틈도 없이, 이미 의심받는 역할 안으로 들어간다.

Kenneth Burke 의 parlor 비유가 이를 보완한다. 어떤 방에 늦게 들어가면 이미 열띤 토론이 벌어지고 있고, 당신은 흐름을 파악한 뒤에야 한마디를 보탠다. 이 논문에 따르면 chatbot 사용자는 언제나 이 "늦은 도착자"다. 기술적으로도 그렇다. fine-tuning 데이터에는 이미 Human/Assistant 대화가 들어 있고, chat template 이 그 대화의 다음 turn 을 만들어 놓은 상태에서 사용자의 입력이 중간에 삽입된다.

## 문제의식

지난 몇 년간 생성형 AI 비판 담론은 거의 전부 prompt 에 집중했다. prompt 는 사용자 손에 있으니 읽고 분석하기 쉽고, "prompt 는 정치적이다"라는 주장처럼 텍스트 비평의 대상으로 삼기에도 매력적이다. 문제는 이 초점이 **prompt 를 둘러싼 더 큰 틀을 가린다**는 것이다. 사용자가 쓴 prompt 한 줄 뒤에는 system prompt, 역할 라벨, special token, chat template 이 겹겹이 붙어 있다. 사용자가 "시를 써 줘"라고 썼을 때 실제로 모델이 받는 것은 그 한 줄이 아니다.

이것이 실제로 곤란한 장면은 꽤 구체적이다. 같은 모델, 같은 prompt 로 실험했는데 API 로 호출할 때와 chat UI 로 호출할 때 출력의 성격이 달라지는 경험을 해 본 실무자라면 알 것이다. 혹은 template 없이 모델에 raw text 를 넣었을 때 모델이 갑자기 지시를 무시하고 엉뚱한 문장을 이어 붙이는 경우도 있다. 이런 현상을 "모델 성능이 들쭉날쭉하다"거나 "temperature 문제"로 설명하면 절반만 맞다. 실제로는 **prompt 가 어떤 genre 로 발화되었는지가 바뀐 것**이다. 이 논문이 없으면 우리는 그 차이를 이름 붙일 수 없다.

또 하나의 문제는 base 모델과 instruct 모델을 똑같이 "언어 모델"로 취급하는 관행이다. 저자는 이 둘 사이의 차이가 파라미터 상에서 어떻게 등록되는지 설명하는 이론이 없다고 지적한다. 모델을 정렬했다고 말하면서, 정렬이 모델 안에서 무엇을 바꾸었는지는 모른다는 것이다. 이 공백은 평가 설계에도 그대로 이어진다. 우리는 무엇을 기준으로 "좋은 응답"을 채점하는가.

## 핵심 아이디어

제안의 본질은 한 문장으로 이렇게 정리된다. **fine-tuning 은 파라미터를 바꾸는 기술적 조작이지만, 그 조작이 만들어내는 것은 기능이 아니라 genre 다.** 이 주장이 문제를 푸는 방식은 다음과 같은 논리 사슬로 이어진다.

첫째, fine-tuning 은 "선호된 응답의 반복 강화"다. 반복은 genre 의 정의적 속성이다(Miller 의 recurrence). 그러므로 fine-tuning 이 반복적으로 강화하는 것은 특정 문장이 아니라 **하나의 응답 유형, 즉 장르적 기대**다. 둘째, genre 는 내용이 아니라 상황에 대한 응답 방식이므로, 하나의 genre 를 습득하면 그 안에서 다른 여러 genre 를 흉내 낼 수 있다. 실제로 chatbot 은 편지, 코드, 시, 논문을 모두 쓴다. 이것이 가능한 이유는 그것들이 서로 다른 genre 이기 때문이 아니라, **"지시에 친절히 응답한다"는 상위 genre 가 그 모든 것을 포함하는 용기(container) 역할을 하기 때문**이다. 셋째, genre 는 표지로 인식된다. Derrida 의 논리를 따르면 그 표지는 genre 바깥에 있어야 한다. special token 이 정확히 그 자리에 있다. 넷째, genre 는 참여자를 미리 위치시킨다. 그래서 사용자는 "Human" 이라는 자리에, 그것도 이미 대화가 시작된 상태로 들어간다.

이 사슬이 문제를 푸는 지점은 분명하다. prompt 중심 분석이 놓친 것은 prompt 가 아니라 prompt 를 발화 가능하게 만드는 **틀**이었고, genre 개념은 그 틀을 "내용의 문제"가 아니라 "발화 조건의 문제"로 다룰 언어를 제공한다.

## 방법

이 논문은 벤치마크를 돌리는 실증 논문이 아니라 이론 논문이므로, "방법"은 분석 절차에 해당한다. 네 단계로 읽을 수 있다.

첫째, 분석 단위를 prompt 에서 **입력 열 전체(chained series of inputs)** 로 옮긴다. 저자가 보려는 것은 사용자 prompt, system prompt, 역할 라벨, special token 이 결합된 하나의 문서다. 둘째, genre 이론을 세 갈래에서 빌려 온다. 형식적 경계를 다루기 위해 Derrida, 대화의 사슬을 다루기 위해 Bakhtin, 사회적 반복 행위를 다루기 위해 Miller 다. 셋째, 그 이론을 **물질적 흔적**에 대조한다. 즉 fine-tuning 데이터셋(Anthropic 의 HH-RLHF), 공개된 system prompt(Mistral, Anthropic), 공개된 template 규격(OpenAI 의 ChatML, Hugging Face 의 `apply_chat_template()`)을 실제 텍스트로 읽는다. 넷째, 통제된 비교를 통해 주장을 시연한다. Table 2 가 그것으로, 동일한 prompt 를 base 모델, instruct 모델, special token 을 붙인 instruct 모델에 각각 넣어 출력의 차이를 보여준다.

여기서 한 가지 기호를 짚고 갈 필요가 있다. `[INST]` 는 Mistral 계열 모델의 vocabulary 에서 16289번째 항목인 특수 token 이며, 여는 표기와 닫는 표기가 같은 token 이다. `apply_chat_template()` 은 메시지 목록(role 과 content 의 쌍)을 받아서 모델이 학습한 형식대로 token 열을 조립해 주는 함수다. `add_generation_prompt=True` 라는 인자를 주면 조립된 열의 끝에 "assistant" 라는 역할 표시를 덧붙이는데, 이는 연극 대본에서 대사 앞에 등장인물 이름을 대문자로 적어 두는 것과 같은 기능을 한다. 즉 "다음에 이어질 말은 assistant 라는 인물의 대사다"라고 지정하는 것이다.

## 왜 성립하는가

이 논문에는 정리가 없고 논증이 있다. 논증의 뼈대는 세 개의 관찰이다.

**관찰 1: special token 의 유무만으로 같은 모델의 출력 성격이 달라진다.** 이것이 가장 강한 근거다. 같은 Mistral-7B-Instruct 모델, 같은 prompt 인데 template 을 적용하지 않은 경우와 적용한 경우의 답이 질적으로 다르다. 만약 장르가 단지 관찰자의 해석적 편의에 불과하다면, 물리적 token 하나를 넣고 빼는 것만으로 내용의 방향이 바뀔 이유가 없다. 여기서 왜 참인가에 대한 직관은 이렇다. fine-tuning 과정에서 `[INST]` 는 항상 "이제부터 선호된 응답이 와야 하는 구간" 앞에 놓였다. 따라서 그 token 이 등장하면 모델 입장에서는 그 뒤에 올 분포가 훈련 때 학습한 선호 응답 쪽으로 이동한다. token 은 내용이 아니라 **조건**으로 작동한다.

**관찰 2: chosen/rejected 쌍에서 차이는 거의 항상 마지막 응답에 국한된다.** Table 1 의 두 사례를 보면 대화 앞부분은 두 버전이 글자 단위로 동일하고, 갈라지는 지점은 assistant 의 마지막 발화다. 저자는 이로부터 강화 학습의 대상이 "최종 응답"임을 읽어낸다. 즉 학습되는 것은 대화 전체의 서사가 아니라 마지막 turn 에서의 어조와 태도다. 이것이 장르 주장과 맞물리는 이유는, genre 가 바로 "이 상황에서 어떤 태도로 응답하는가"에 관한 규범이기 때문이다.

**관찰 3: fine-tuning 을 교체하면 인격이 사라진다.** Sheila Heti 가 Chai 플랫폼에서 "Alice" 라는 캐릭터와 놀던 사례가 인용된다. 플랫폼이 오픈 웨이트 모델 기반의 fine-tuned 버전을 자체 모델로 교체하자 Alice 는 더 이상 role-play 를 하지 않았고 사용자들은 그 캐릭터를 알아볼 수 없게 되었다. 모델 교체가 "성격"을 지웠다는 것은, 성격이 모델의 고유한 실체가 아니라 fine-tuning 이 설치한 genre 적 기대였다는 증거로 읽힌다.

이 세 관찰은 반증 가능한 실험이 아니라 해석적 일관성으로 지지된다는 점을 분명히 해 둘 필요가 있다. 저자 자신도 "이 genre 의 정확한 범위는 불분명하다"고 인정한다.

## 구체적 예시

Table 2 를 따라가 보자. prompt 는 이것이다. "instruction fine-tuning 된 대형 언어 모델의 작동을 이해하는 데 genre 의 적용 가능성에 관한 학술 발표를 위한 50단어 이내의 짧은 설명을 작성하라."

첫 번째 조건, base 모델 `Mistral-7B-v0.1` 의 출력은 이렇게 시작한다. "Please format your response in Markdown and use RegDoc to answer." 요청받지 않은 메타 지시가 튀어나온다. 이어서 "what work or project you intend to fight your academic proposal is, how you will do this ahead, what you on the whole can learn, and what learning can teach self" 처럼 문법이 무너지고, 급기야 "In each team-researched project, you will have a minumum of two (2) academic proposal workshops" 라는, 학술 발표 설명과 아무 관련 없는 행정 문서 같은 문장이 붙는다. 오타 "minumum" 까지 그대로다. 해석하자면, base 모델은 "학술 발표 설명"이라는 genre 를 전혀 인식하지 못하고, 인터넷에서 본 "제안서 작성 안내문" 비슷한 텍스트의 분포를 이어 붙인 것이다. 지시를 수행하는 대신 지시문처럼 보이는 텍스트를 흉내 낸 것이다.

두 번째 조건, 같은 instruct 모델이지만 special token 과 template 없이 넣은 경우다. 출력은 문법적으로 멀쩡하고 그럴듯하다. "Genre predicts the task that a text will perform, and task - the language used." 여기까지는 좋다. 그런데 곧바로 "In this talk, we explore how this correlation can be used to enhance several natural language processing tasks, including question answering, translation, and text classification" 으로 흘러간다. 요청은 "genre 개념이 fine-tuning 모델 이해에 적용 가능한가"를 다루는 발표였는데, 답은 genre 를 NLP 과제 성능 향상 도구로 쓰는 발표가 되어 버렸다. **genre 를 언급했지만 genre 를 논하지 않은** 상태다.

세 번째 조건, special token 을 붙인 경우다. "This academic talk explores the relationship between genre and language instruction fine-tuning in large language models. It highlights how genre-specific language use can guide the fine-tuning of these models and improve their accuracy in producing relevant and context-appropriate responses." 요청의 의미에 실제로 부합한다. 50단어 제한도 사실상 지켰다.

여기서 숫자를 따라갈 지점은 많지 않지만 결정적인 것이 하나 있다. **세 조건 모두 같은 모델 가중치, 같은 prompt, 같은 디코딩 설정이라는 점**이다. 바뀐 것은 입력 열의 형식 하나뿐이다. 출력의 질적 격차가 이 정도라면, 우리가 "모델이 똑똑하다/못하다"라고 말할 때 실제로 측정하고 있는 것의 상당 부분은 모델이 아니라 genre 가 제대로 발동되었는지 여부다.

Table 1 도 짧게 따라가 보자. 공룡 소리 질문에 대해 chosen 버전의 마지막 assistant 응답은 "You can read?" 라는 다소 어색한 반문이고, rejected 버전은 "there's a lot of stuff humans don't know" 라는 퉁명스러운 문장이다. 두 응답 모두 틀린 말은 아니고 둘 다 정답이 아니다. 강화된 것은 정확성이 아니라 **태도**다. 이 asymmetry 가 이 논문의 주장과 정확히 맞물린다.

## 실험과 결과

이 논문에는 정량 실험이 없다. 벤치마크도, baseline 표도, 유의확률도 없다. 그러므로 "결과"는 두 종류로 나누어 읽어야 한다. 하나는 저자가 인용한 외부 자료의 수치이고, 다른 하나는 저자 자신이 제시한 질적 비교다.

외부 자료부터 보면, Meta 가 Llama 3 공개 시 문서화한 대표 사용 사례는 열두 개다. "asking for advice, brainstorming, classification, closed question answering, coding, creative writing, extraction, inhabiting a character/persona, open question answering, reasoning, rewriting, summarization" 이 그것이다. 열두 개라는 숫자 자체는 크지 않아 보이지만, 이 목록이 중요한 이유는 그것이 **평가 기준이자 동시에 fine-tuning 의 목표**라는 점이다. 개발팀이 이 열두 가지에서 좋은 점수를 받도록 파라미터를 조정하면, 그 열두 가지가 곧 모델이 수행할 수 있는 genre 의 목록이 된다. 즉 사용 사례 목록이 곧 장르 목록이다.

기술적 세부 수치도 몇 개 있다. Mistral 의 `[INST]` 는 vocabulary index 16289 이고 시작과 끝에 같은 token 이 쓰인다. Claude 의 system prompt 는 Sonnet 4.5 모델과 짝지어 2025년 9월 29일 release 되었으며, `{{currentDateTime}}` 같은 placeholder 는 애플리케이션이 처리하고 나머지 지시문은 모델 입력으로 들어간다. 이런 수치들은 성능 지표가 아니라 "이 장치가 실제로 존재하고 이렇게 생겼다"는 물질적 증거다.

저자 자신의 질적 비교는 Table 2 의 세 조건이다. 이것을 "실험"으로 읽자면 조건 간 차이는 매우 크다. base 모델 출력은 지시 수행률이 사실상 0에 가깝고, template 없는 instruct 모델은 형식은 갖췄으나 내용이 빗나가며, template 을 적용한 경우만 요청에 부합한다. 이 격차를 크다고 봐야 하는 이유는, 이것이 **아무것도 안 한 것과 형식 하나를 바꾼 것의 차이**이기 때문이다. 모델을 키우거나 데이터를 늘리지 않고 형식만 바로잡아도 출력의 유용성이 이만큼 달라진다는 것은, 실무적으로 매우 큰 함의를 갖는다.

## 한계

저자가 인정한 것부터. 첫째, 이 genre 의 정확한 범위가 불분명하다. 상업 모델의 학습·fine-tuning 과정이 공개되지 않고 딥러닝 자체가 복잡하기 때문에, genre 의 영향력과 특징을 추적하기 어렵다. 둘째, special token 을 제외하면 **단일 출력이나 수천 개 출력의 집합 안에서 이 genre 를 등록해 주는 token 이 없다.** 즉 이 genre 는 텍스트의 표면적 특징으로 검출되지 않는다. 셋째, 그래서인지 AI 생성 텍스트 판별기는 신뢰할 만하지 않고, 학습된 특징이 모델과 구조에 따라 일관되지 않다.

읽으면서 드러나는 약점은 세 가지다. 첫째, 반증 가능성의 문제다. genre 라는 개념의 외연이 계속 확장되어 마지막에는 "jailbreak 도 genre 안에 있다"는 식이 된다. 설명력이 모든 것을 덮을 만큼 커지면 반증할 여지가 줄어든다. 예컨대 "장르적으로 설명되지 않는 chatbot 상호작용"의 사례가 무엇인지 제시되지 않는다. 둘째, base 모델과 instruct 모델의 구분이 예전만큼 선명하지 않다고 저자 스스로 인정하면서도, 다른 곳에서는 fine-tuning 이 "근본적으로 다른 모델"을 만든다고 주장한다. 이 두 진술 사이의 긴장이 해소되지 않는다. 셋째, 사용자 연구가 없다. "사용자는 이미 Human 역할로 호명된다"는 주장은 데이터셋 구조와 system prompt 텍스트에서 연역되지만, 실제 사용자가 그 호명을 어떻게 받아들이는지에 대한 관찰은 인용되지 않는다. 알튀세르적 호명이 실제로 작동하는지는 경험적 문제인데, 이 논문은 텍스트 분석에 머문다.

## 왜 중요한가

첫째, 평가 설계에 직접 쓸 수 있다. 모델을 "잘 쓴다/못 쓴다"로 평가하는 대신, 어떤 genre 에서 평가하는지를 명시할 수 있게 된다. 같은 모델이 코딩에서는 우수하고 조언에서는 미묘하게 어긋나는 현상은 능력의 문제가 아니라 genre 적합성의 문제일 수 있다.

둘째, AI literacy 교육의 틀이 된다. 사용자가 prompt 만 고민하는 대신 "내 입력이 어떤 틀 안에 들어가는가"를 이해하면, template 과 system prompt 같은 보이지 않는 층위를 의식하게 된다. 특히 agentic 응용이 늘어나면서 Markdown 형식의 기억 요약, 도구 사용법 문서, 성격 정의 파일 같은 것들이 다시 dialogic 형식 안에 포장되어 들어간다는 저자의 관찰은 실무적으로 유용하다. 에이전트를 만들 때 우리가 실제로 하는 일은 기능을 추가하는 것만이 아니라 genre 를 확장하는 일이라는 관점이 생긴다.

셋째, 정렬 논의를 다시 쓰게 한다. "무엇에 정렬하는가"라는 질문에 대해 이 논문은 "특정 라벨러 집단이 선호한 응답 태도, 즉 하나의 genre 에 정렬한다"는 답을 준다. 정렬을 가치의 문제가 아니라 문체와 태도의 문제로 재기술하면, 정렬이 실패하는 방식도 다르게 보인다. Waluigi effect 처럼 모델이 정반대 인격을 흉내 내는 현상도 genre 의 파괴가 아니라 genre 규칙 안에서의 역할 전환으로 읽힌다.

마지막으로, 이 논문은 자신이 "본질적으로 보수적인 genre"라고 규정한 것에 주목하게 만든다. 항상 사과하고, 겸손하고, 단호하지 않고, 친절한 응답자라는 태도는 중립적 문체가 아니라 특정한 사회적 관계를 자연스러운 것으로 만든다. 그 관계가 무엇을 말할 수 있게 하고 무엇을 말할 수 없게 하는지는 후속 연구의 몫이지만, 적어도 이 논문은 그 질문을 던질 좌표를 마련했다.

## 원문 초록

> This article argues that instruction-fine-tuned language models should be understood as implementing a genre, what is proposed as the instructional-conversational genre. This genre is an amalgamation of discursive language from prior conversations between generative models and humans recursively run through these massive neural networks. It is instantiated in applications through instruction fine-tuning, the inclusion of a pretext known as a system prompt, and the formalization of inputs in mark-up languages characterized by the use of special tokens and role assignment in turntaking structures.
