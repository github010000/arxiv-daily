## 한 줄 요약

LARC는 통합 multimodal 모델이 이미지를 만들기 전에 하는 "추론"을, text token 대신 이미지 생성과 같은 연속 hidden state 공간에서 수행하도록 두 단계(SFT + self-evolving RL)로 학습시켜, 추론 예산을 늘리면 생성 품질이 함께 좋아지는 test-time scaling을 이미지 생성에서 처음으로 관찰시킨 framework다.

## 핵심 개념 풀이

### 1. Unified Multimodal Model (UMM) — "한 몸에 두 명의 전문가"

UMM은 하나의 model이 이미지를 이해하고(질문에 답하기) 이미지를 만들어내는(그리기) 두 가지를 모두 하는 model이다. 이 논문이 기반으로 삼는 BAGEL은 하나의 거대한 transformer 안에 역할이 다른 expert를 나눠 둔다. "이해 expert"는 LLM처럼 text를 읽고 생각하는 부분이고, "생성 expert"는 flow matching 방식으로 픽셀을 만들어내는 부분이다. 중요한 연결 고리는 cross-attention인데, 이해 expert가 만들어 놓은 마지막 layer의 hidden state(문장의 각 위치에서 model이 품고 있는 내부 표현)를 생성 expert가 읽어 들여 이미지를 그린다. 비유하면 기획팀이 회의록을 남기면 디자이너가 그 회의록을 보면서 시안을 그리는 구조다. 따라서 "기획팀이 어떤 형태로 회의록을 남기는가"가 결과물 품질을 좌우하며, 이 논문의 주장은 회의록을 text(이산 단어)로 남기지 말고 디자이너가 쓰는 언어(연속 벡터)로 남기자는 것이다.

### 2. chain-of-thought와 test-time scaling — "풀이 과정을 적으면 더 잘 푼다"

chain-of-thought(CoT)는 model이 최종 답을 바로 내지 않고 중간 추론 단계를 글로 풀어 쓰게 하는 기법이다. LLM에서는 이 중간 단계를 늘리면 성능이 매끄럽게 올라가는데, 이런 성질을 test-time scaling이라고 부른다. 즉 학습을 더 하지 않고 추론 시점의 계산량(생각할 시간)만 늘려서 성능을 사는 것이다. 비유하면 수학 시험에서 연습장을 더 많이 줄 때 정답률이 꾸준히 오르는 것과 같다. 문제는 기존의 reasoning 기능을 붙인 UMM들에서 추론 token 수를 늘려도 이런 매끄러운 상승이 나타나지 않는다는 점이고, 이 논문은 그 원인을 "연습장에 쓸 수 있는 언어가 부적절하다"에서 찾는다.

### 3. 이산 token 공간과 연속 공간, 그리고 latent reasoning — "단어장으로 그림을 그릴 수 없다"

LLM의 추론은 어휘 집합(vocabulary)에 들어 있는 token 중 하나를 고르는 과정의 연쇄다. 아무리 어휘가 커도 유한하고, 각 단계는 "정확히 이 단어"라는 딱딱한 결정이다. 반면 이미지 생성은 수십~수백 차원의 연속 벡터(flow matching이라면 속도장, diffusion이라면 noise 예측)를 조금씩 조정하는 과정이다. 그래서 "고양이가 빨간 상자 왼쪽에 있고 그 위에 파란 공이 있다" 같은 공간 배치 정보를 단어 열로 옮기면, 표현해야 하는 밀도 높은 기하 정보가 단어 경계에서 뭉개진다. 비유하면 그림을 그릴 때 붓 대신 5만 단어짜리 사전에 있는 단어만 찍어서 좌표를 전달하는 셈이다. 이 병목을 피하는 방법이 latent reasoning인데, Coconut이라는 선행 연구에서 착안한 방식으로, model이 다음 단어를 뽑아 그 단어의 embedding을 넣는 대신, 자기 마지막 hidden state를 그대로 다음 위치의 입력 embedding으로 되돌려 넣는다. hidden state는 residual stream과 같은 차원을 가지므로 입력 자리에 그대로 꽂을 수 있고, 이렇게 하면 한 단계의 "생각"이 유한한 단어장을 거치지 않고 연속 벡터로 다음 단계에 전달된다.

### 4. curriculum learning — "한 번에 다 열면 무너진다"

latent step에는 정답이 없다. text 구간은 다음 단어를 맞히는 지도 신호가 있지만, latent 구간은 "이 위치에 무엇을 넣어야 하는가"에 대한 label이 존재하지 않는다. 그래서 처음부터 모든 latent step을 켜면, 아직 추론 형식도 배우지 못한 model이 아무 감독 없이 연속 상태를 만들어내야 해서 학습이 불안정해진다. curriculum learning은 이걸 단계적으로 푸는 장치로, 먼저 latent를 전부 끄고 text만으로 추론 형식을 익히게 한 뒤, phase를 진행하며 앞쪽 latent step부터 하나씩 켠다. 각 단계에서 새로 켜진 latent는 이미 안정된 prefix 위에서 만들어진다는 것이 핵심 아이디어다. 비유하면 글쓰기를 가르칠 때 처음엔 개요를 말로 다 쓰게 하고, 나중에 일부 항목을 "머릿속으로 알아서" 처리하게 만드는 것과 같다.

### 5. information gain — "이 메모가 그림을 얼마나 잘 맞히게 했는가"

이 논문의 RL reward는 "latent 추론 trace가 target image의 likelihood를 얼마나 끌어올렸는가"로 정의된다. 수식으로는 trace를 조건에 넣었을 때의 log 확률에서 trace 없이 context만 줬을 때의 log 확률을 뺀 값이다. 이 차이는 정보이론에서 조건부 상호정보량(conditional mutual information)의 표본 단위 형태이며, 기대값을 취하면 항상 0 이상이다(뒤에서 설명). 비유하면 일러스트레이터에게 "이 스케치를 참고해"라고 줬을 때와 안 줬을 때의 결과물 오차를 비교해서 스케치의 가치를 매기는 것이다. 문제는 이미지 생성 모듈이 확률을 직접 계산해 주지 않는다는 것인데, 이 논문은 flow matching loss가 negative log-likelihood에 상수만 더한 값이라는 성질을 이용해 두 loss의 차이로 reward를 근사한다.

### 6. GRPO와 latent collapse — "비슷한 생각만 반복하면 계산을 낭비한다"

GRPO는 하나의 prompt에 대해 여러 개(이 논문은 8개)의 궤적을 샘플링하고, 그 그룹 안에서 reward를 평균·표준편차로 정규화해 advantage를 만드는 정책 최적화 기법이다. 별도의 value network(critic)를 두지 않아 UMM처럼 거대한 model 위에서 학습이 가벼워진다는 장점이 있다. 그런데 latent step들은 서로 구별되도록 강제하는 장치가 없으면 모두 비슷한 벡터로 수렴해 버리는데, 이를 latent collapse라고 한다. 그러면 10단계를 계산해도 실질적으로 1단계를 계산한 것과 같아서 추론 예산을 늘리는 의미가 사라진다. 그래서 이 논문은 latent step 사이의 cosine similarity를 낮추도록 유도하는 diversity reward를 더한다.

## 문제의식

기존의 reasoning 강화 UMM(예: Uni-CoT)은 LLM의 CoT를 그대로 가져와, 이미지를 그리기 전에 text token으로 중간 추론을 한다. 그런데 저자들이 관찰한 것은 두 가지 실패다. 첫째, 추론 token 수를 늘려도 성능이 매끄럽게 오르지 않는다. LLM에서 익숙한 test-time scaling이 이미지 생성에서는 나타나지 않는 것이다. 둘째, 성능 향상이 아주 좁은 영역에만 국한된다. 저자들의 표현을 빌리면 추론이 "prompt 표면 조작(surface-level prompt manipulation)"으로 퇴화한다.

이게 실무에서 왜 곤란한가. 예를 들어 "테이블 위 왼쪽에 빨간 컵, 오른쪽에 파란 컵, 그 사이에 김이 나는 주전자, 그리고 배경에는 비 오는 창문" 같은 prompt를 생각해 보자. 이런 요청은 단어 하나를 잘 고르는 문제가 아니라, 어떤 객체를 어디에 어떤 크기와 관계로 배치할지 계획하는 문제다. text token 기반 추론은 "빨간 컵" "왼쪽" 같은 단어를 추가로 뱉는 데에는 도움이 되지만, 그 단어들이 픽셀 좌표계에서 어떤 배치를 뜻하는지에 대한 밀도 높은 정보를 담지는 못한다. 그래서 추론을 아무리 길게 해도 실제로는 prompt를 살짝 다듬는 효과밖에 안 나고, 추론 예산을 늘릴 동기가 사라진다. 실제로 이 논문의 ablation(Table 6)에서 token 기반 추론은 visual reasoning benchmark에서 오히려 baseline보다 낮은 점수(7.1 대 7.5)를 기록했다. 즉 "열심히 생각했는데 안 한 것만 못한" 상황이 발생한다는 뜻이고, 이것이 두 modality 사이의 근본적 불일치라는 진단으로 이어진다.

## 핵심 아이디어

제안의 본질은 한 문장으로 "추론의 표현 형식을 생성의 표현 형식과 일치시킨다"이다. reasoning은 이산 token 공간에서, generation은 연속 공간에서 일어나니, 추론을 연속 공간으로 옮기면 두 장벽이 사라진다는 논리다. 이 아이디어가 문제를 푸는 경로를 세 단계로 이어서 설명할 수 있다.

첫째, 병목이 제거된다. 이산 token을 거치면 hidden state가 유한한 어휘 중 하나로 압축되면서 정보가 손실된다. latent mode에서는 마지막 layer의 hidden state를 그대로 다음 입력으로 되돌려 넣기 때문에, 압축 단계가 없다.

둘째, 추론이 생성 모듈에 "직접" 닿는다. 생성 expert는 이해 expert의 hidden state를 cross-attention으로 읽어 이미지를 만든다. token 기반 추론에서는 생성 expert가 읽는 것이 결국 token embedding 열이지만, latent 추론에서는 hidden state 열 자체가 읽힌다. 즉 추론 단계가 곧 조건 벡터이므로, 추론을 한 단계 더 하는 것이 곧 이미지 조건을 한 번 더 정교화하는 것과 같다. 그래서 추가 계산이 "중복된 token을 더 뱉는 일"이 아니라 "유용한 표현을 다듬는 일"이 되고, 이것이 test-time scaling이 나타나는 이유로 제시된다.

셋째, 이 구조가 RL과 결합 가능해진다. latent 추론 trace에는 정답이 없고 사람이 평가할 수도 없으므로, 외부 평가자 대신 model 자신의 likelihood 변화로 reward를 만든다. reward가 "이 trace가 target image를 더 잘 예측하게 만들었는가"라는 형태이므로, 정답 chain 없이도 self-evolving이 가능하다.

## 방법

**1단계: 궤적 형식 정의.** 입력 context를 c = (c_1 ... c_T)라 하자. 여기에는 text prompt와 선택적으로 원본 이미지가 들어간다. model은 추론 궤적을 만든 뒤 target image x를 생성한다. 궤적은 언어 mode 구간과 latent mode 구간이 번갈아 나오는 형태 τ = (s_1, l_1, s_2, l_2, ..., s_N, l_N)로 표현된다. s_n은 n번째 언어 구간(여러 text token), l_n은 n번째 latent step(하나의 hidden state 벡터)이다.

**2단계: mode 전환의 실제 계산.** 입력 embedding 열을 E_t, 마지막 layer의 hidden state를 h_t = H_t[t, :]라 하면 다음 위치의 embedding은 mode에 따라 달라진다. latent mode이면 E_{t+1} = [E_t ; h_t], 즉 방금 계산한 hidden state를 그대로 이어 붙인다. 언어 mode이면 E_{t+1} = [E_t ; e(x_{t+1})], 즉 다음 token을 뽑아 그 embedding을 붙인다. 그리고 H_{t+1} = Transformer(E_{t+1})로 다음 상태를 계산한다. 여기서 특수 token `<latent>`가 나오면 mode가 latent로 바뀌고, 정해진 step 수가 지나면 언어 mode로 돌아온다. `<eos>`가 나오면 궤적이 끝나고 이미지 모듈이 호출된다. 궤적의 길이 N과 각 언어 구간의 길이는 외부 schedule이 아니라 model이 언제 `<latent>`와 `<eos>`를 내는지로 결정된다.

**3단계: curriculum SFT.** 먼저 1M 규모의 interleaved CoT data를 모은다(FLUX-Reason 500K, WEAVE 100K, ScaleEdit 400K). 각 추론 chain의 step 경계에 `<latent>` token을 삽입해 latent가 들어갈 자리를 표시한다. phase 0에서는 latent를 전부 끄고 text만으로 다음 token 예측을 학습한다. phase k(k = 1, ..., N-1)에서는 앞의 k개 latent만 켜고, 마지막 phase에서 전부 켠다. phase가 넘어갈 때마다 learning rate를 낮춘다. loss는 text 구간의 next-token 예측 loss와 target image에 대한 flow matching loss의 합이다.

**4단계: information-gain RL.** Stage 1이 끝난 model을 고정한 reference π_ref라 하자. 샘플링한 궤적 τ에 대한 reward는 r_IG(τ; x, c) = log p_{π_ref}(x | c, h(τ)) − log p_{π_ref}(x | c)로 정의된다. 앞항은 trace를 조건에 포함했을 때 target image의 log 확률, 뒤항은 trace 없이 context만 줬을 때의 log 확률이다. 즉 "trace가 정보를 더했는가"를 확률 차이로 잰다. 그런데 이미지 모듈은 log 확률을 직접 주지 않으므로, flow matching loss L_flow가 negative log-likelihood에 x만의 함수인 상수 C(x)를 더한 값이라는 관계를 써서 r_IG ≈ L_flow(x, c) − L_flow(x, c, h(τ))로 근사한다. 이때 두 loss를 같은 noise 표본으로 평가해야 C(x)가 정확히 상쇄된다.

**5단계: 붕괴 방지와 정책 최적화.** diversity reward는 r_div(τ) = (1/(N(N−1))) Σ_{n≠n'} (1 − cos(l_n, l_n'))로, 서로 다른 latent step 쌍의 cosine 유사도를 평균한 뒤 1에서 뺀 값이다. 즉 step들이 서로 다를수록 커진다. 총 reward는 R = r_IG + λ_div · r_div (λ_div = 0.1)이고, 이를 GRPO로 최대화한다. GRPO는 각 prompt에 대해 G = 8개의 궤적을 뽑아 그룹 내에서 정규화한 advantage A_i = (R_i − μ_R)/(σ_R + ε)를 만들고, importance ratio ρ_i(θ) = π_θ(τ_i|c)/π_{θ_old}(τ_i|c)에 clipping(ε_clip = 0.2)을 건 surrogate 목적함수를 최대화하며, KL penalty(β = 10^-3)로 reference에서 너무 멀어지지 않게 묶는다. Stage 2에서는 생성 expert는 고정하고 이해 expert만 학습한다.

## 왜 성립하는가

**reward가 정말 "정보량"인가.** log p(x|c,h) − log p(x|c)를 정리하면 log [p(x,h|c) / (p(x|c) p(h|c))]가 된다. 이 값의 기대값이 바로 조건부 상호정보량 I(x; h(τ) | c)이며, log 안의 비율에 Jensen 부등식을 적용하면 기대값이 항상 0 이상임이 보장된다. 직관적으로는 "trace가 아무 정보도 주지 않으면 두 조건부 확률이 같아져 reward가 0이 되고, 정보를 주면 양수가 된다"는 뜻이다. 따라서 r_IG를 최대화하는 것은 trace와 target image 사이의 상호정보량을 최대화하는 것과 같다.

**flow loss 차이가 왜 확률 차이의 추정이 되는가.** rectified flow 계열에서 negative log-likelihood는 조건부 flow matching loss에 target image와 noise schedule만의 함수인 상수 C(x)를 더한 형태로 표현된다. 두 항에 이 관계를 대입하면 C(x)가 그대로 빼져 없어진다. 여기서 핵심은 "같은 noise 표본을 쓴다"는 조건인데, 서로 다른 noise로 계산하면 두 loss의 차이에 noise 운이 섞여 reward가 분산만 커지고 편향될 수 있다. 같은 재료를 두 요리사에게 똑같이 주고 실력을 비교하는 것과 같은 원리(common random numbers)로, 분산을 크게 낮추면서 추가 reward model 없이 unbiased 추정을 얻는다.

**왜 curriculum이 필요한가.** latent 구간에는 직접적인 supervision이 없으므로, 초기에 이 구간이 만들어내는 상태는 사실상 무의미한 벡터다. 그런데 그 무의미한 벡터가 이후 text 구간의 조건으로 들어가면, model이 그 나쁜 조건을 무시하는 방향으로 학습해 latent가 장식품이 되어 버린다. 앞쪽 latent부터 하나씩 켜면 이미 학습된 prefix가 안정된 문맥을 제공하고, 새 latent에 대한 gradient는 "이미 잘 동작하는 뒷부분의 손실을 얼마나 줄였는가"라는 형태로 흐른다. 마지막 phase에서 learning rate를 낮추는 것도 이 안정화 논리의 연장이다.

**왜 interleaved text가 RL에 유리한가.** 정책 최적화는 궤적의 확률 π_θ(τ|c)를 필요로 하는데, 완전히 결정적인 latent-only 궤적은 확률비가 1에 가까워 gradient 신호가 희미해진다. text 구간의 확률적 샘플링은 궤적에 확률적 다양성을 부여해 그룹 rollout이 의미를 갖게 한다. 다만 Stage 1이 latent 구간에 어떤 방식으로 확률성을 주입하는지(noise 추가인지 dropout인지)는 주어진 본문에 구체적 메커니즘 명시가 없다. 또한 Table 7에서 interleaved가 naive보다 MIRA에서 근소하게 낮은(9.7 대 9.9) 결과가 있어, 저자들이 말한 "다른 곳에서 comparable"이라는 표현은 문자 그대로 받아들이는 것이 안전하다.

**보조 관찰: 왜 reference를 고정하는가.** Stage 2에서 π_ref를 고정하고 생성 expert를 freeze하는 것은 단순한 계산 절약이 아니라 reward hacking 방지로 읽힌다. 만약 평가자와 피평가자가 같은 model이라면, reward를 올리기 위해 "baseline 조건에서의 예측을 일부러 나쁘게 만드는" 퇴화 해가 존재한다. 고정된 잣대를 두면 그 경로가 막힌다. 이는 논문이 명시한 주장은 아니고 본문 구조에서 도출되는 해석이다.

## 구체적 예시

Table 12의 diversity reward ablation을 숫자로 따라가 보자. λ_div는 diversity 항의 가중치, Cos. Sim.은 한 궤적 안 latent step 쌍들의 평균 cosine 유사도다.

λ_div = 0.0일 때 Cos. Sim. = 0.97. cosine 유사도 0.97은 두 벡터의 각도가 약 14도 수준으로 거의 같은 방향이라는 뜻이고, (1 − 0.97) = 0.03이 평균 쌍별 거리다. 즉 10단계 latent를 계산해도 매 단계가 거의 동일한 벡터를 내놓는다. 이때 GenEval 0.83, OneIG-Bench 0.81, MIRA 9.8이 나온다. Stage 1만 했을 때(Table 8)가 0.83 / 0.81 / 9.7이므로, diversity 항 없이 RL을 돌리면 MIRA는 9.7에서 9.8로 사실상 제자리이고 나머지도 미미하다. 계산량을 늘렸는데 얻는 것이 없는 상태, 즉 collapse다.

λ_div = 0.1(채택값)에서는 Cos. Sim.이 0.79로 떨어진다. 쌍별 거리는 0.21로 약 7배 커졌다. 성능은 GenEval 0.88, OneIG-Bench 0.87, MIRA 11.7로, collapse 상태와 비교해 각각 +0.05, +0.06, +1.9다. 특히 MIRA의 1.9점 상승은 이 benchmark의 전체 스케일(7~12)을 감안하면 상대적으로 큰 폭이다. 여기서 r_div의 실제 값도 계산해 볼 수 있는데, 식 r_div = 평균(1 − cos)이므로 Cos. Sim. 0.97은 r_div = 0.03, 0.79는 r_div = 0.21이다. λ_div = 0.1을 곱하면 diversity 보너스는 각각 0.003과 0.021 수준으로, r_IG의 절대적 크기에 비해 작은 편이다. 논문에 r_IG의 실측 크기는 명시되어 있지 않으므로 두 항의 상대적 비중을 수치로 단정할 수는 없고, λ_div를 0.05~0.5로 쓸어보며 최적점을 찾은 실험(Table 12)이 그 근거다.

λ_div를 0.2로 올리면 Cos. Sim. 0.71, 성능 0.85 / 0.85 / 11.4로 내려가고, 0.5로 올리면 0.65 / 0.82 / 0.82 / 10.6으로 더 나빠진다. 이는 diversity를 억지로 밀어붙이면 model이 "서로 다른 벡터를 만드는 일" 자체에 capacity를 쓰면서 정작 유용한 정보를 담지 못하게 된다는 해석을 뒷받침한다. 즉 이 예시는 "왜 단순히 다양한 벡터를 만들면 안 되고, 다양한 동시에 유용해야 하는가"를 수치로 보여준다.

## 실험과 결과

**Text-to-image (GenEval, Table 1).** GenEval은 객체 검출 pipeline으로 생성 이미지의 구성적 속성을 자동 검증하는 benchmark로, 만점이 1.0인 정확도 지표다. LARC는 overall 0.88로, BAGEL 0.81, Uni-CoT 0.83, Show-o2 0.76, Janus-Pro 0.80을 모두 앞선다. GPT-4o의 0.84보다도 높다. 하위 항목을 보면 single object 1.00, two objects 0.98, counting 0.86, colors 0.93, position 0.77, attribute binding 0.78이다. 여기서 주목할 것은 position(0.77 대 BAGEL 0.64)과 attribute binding(0.78 대 0.63)이다. 두 과제 모두 "무엇을 어디에, 어떤 속성으로"라는 공간·구성 계획이 필요한 영역이라, 저자들의 주장(연속 추론이 구성적 과제에 특히 효과적)과 방향이 일치한다. 다만 overall에서 0.81에서 0.88로의 7%p 상승은, 이 benchmark가 0.8~0.9 구간에 몰려 있어 상한이 가까운 것을 감안하면 상당히 큰 폭이다.

**Prompt following (DPG-Bench, Table 2).** dense prompt 1,065개를 MLLM 심사로 평가한다. LARC는 overall 90.04로 BAGEL 85.07에서 약 5점(상대 5.8%) 올랐고, Uni-CoT 85.56, Show-o2 86.14보다 크게 앞선다. 카테고리별로 relation이 94.70(BAGEL 90.82)으로 가장 크게 벌어졌고, global 92.25, attribute 93.00도 최고 수준이다. 관계·전역 구성 같은 항목에서의 우위는 "장면 전체 배치를 계획하는" 능력이 개선되었다는 해석과 맞물린다.

**OneIG-Bench (Table 3).** overall 0.866으로 BAGEL 0.764 대비 +10.2%p, Uni-CoT 0.790 대비 +7.6%p다. prompt 유형별(NP 0.892, T&P 0.840)과 길이별(short 0.887, medium 0.869, long 0.840) 모두에서 고르게 앞서는데, 긴 prompt에서도 격차가 유지된다는 점은 추론이 단순 키워드 확장이 아님을 시사한다.

**Image editing (CompBench, Table 4).** LC-T 22.509(BAGEL 20.434, 상대 약 +10%), LC-I 0.880, PSNR 25.710(24.370에서 +1.34 dB), SSIM 0.953, LPIPS 0.049(0.069에서 감소). PSNR 1 dB 이상 향상과 LPIPS의 30% 수준 감소는 편집 영역의 픽셀 충실도가 실질적으로 좋아졌다는 뜻으로, 국소 속성 수정 같은 과제에서 공간 계획이 작동한다는 해석을 뒷받침한다.

**Multimodal understanding (Table 5).** MME 1725.3(BAGEL 1687.0), MMB 88.1(85.0), MMMU 56.2(55.3), MIRA 11.7(BAGEL 7.5, Uni-CoT 10.6). MIRA는 시각적 chain-of-thought를 요구하는 benchmark로, 절대 점수 자체는 낮지만 7.5에서 11.7은 상대적으로 50% 이상 오른 것이고, 이산 token으로 추론하는 Uni-CoT(10.6)보다 높다는 점이 저자들의 핵심 근거다. MME·MMB가 떨어지지 않았다는 것도 중요한데, 생성 쪽 추론 학습이 지각 능력을 망가뜨리지 않았다는 뜻이기 때문이다.

**Ablation (Tables 6~8).** 같은 base model에서 token 기반 추론(0.82 / 0.79 / 20.81 / 7.1)과 latent 추론(0.83 / 0.81 / 21.46 / 9.7)을 비교하면 네 과제 모두 latent가 낫고, 특히 visual reasoning에서 token 기반은 baseline(7.5)보다 낮다는 점이 modality mismatch 주장의 직접 증거로 제시된다. Stage 1만 쓴 것(0.83 / 0.81 / 21.46 / 9.7)과 Stage 2까지 간 것(0.88 / 0.87 / 22.51 / 11.7)을 비교하면 RL 단계의 기여가 크다. T2I가 0.83에서 0.88로 오르는 폭은 SFT 단계의 기여(0.81→0.83)보다 훨씬 커서, "SFT는 형식을 잡고 RL이 질을 끌어올린다"는 서사와 일치한다.

**Test-time scaling (Figure 1, Table 11).** latent step 수를 늘리면 세 과제 모두 단조 증가하고, 동일 계산 예산에서 best-of-N sampling을 앞선다. 비용을 보면 BAGEL + best-of-N은 N = 1에서 46.5초, N = 10에서 469.0초로 약 10배가 되지만, LARC는 L = 1에서 46.8초, L = 10에서 48.0초로 1.2초만 늘어난다. 즉 같은 시간 예산이라면 LARC 쪽이 훨씬 많은 시도를 하는 셈이고, 이것이 "실용적으로 쓸 수 있는 scaling"이라는 주장의 근거다.

## 한계

저자가 인정한 것부터. 첫째, 지금은 이미지 모듈이 flow matching head인 UMM에만 적용되었다. discrete token으로 이미지를 생성하는 UMM이나 다른 생성 head로 일반화되는지는 검증되지 않았다. 둘째, interleaved latent 궤적은 추론 시 추가 계산과 latency를 만든다. 저자들은 efficient decoding, distillation, adaptive latent allocation을 future work로 남겼다.

읽으며 드러나는 약점도 있다. 첫째, 실험이 BAGEL 한 개 base model에 고정되어 있다. "continuous가 discrete보다 낫다"는 주장의 근거가 사실상 단일 조합 비교(Table 6)이므로, 다른 UMM에서도 같은 방향이 나오는지는 열린 문제다. 둘째, training data가 1M으로 명시되어 있고 open-source dataset 세 개에서 샘플링되었으므로, data 품질·구성 비율에 대한 민감도 분석은 제시되지 않았다. 셋째, latent step들은 사람이 읽을 수 없는 공간에 있어 추론의 타당성을 검증할 방법이 없다. 저자들도 broader impact에서 "reasoning fidelity와 유해 출력의 관계는 아직 연구되지 않았다"고 언급했는데, 이는 안전성 감사(audit) 관점에서 실질적 약점이다. 넷째, test-time scaling의 비교가 clock time 기준이며 FLOPs 기준 동등성은 별도로 제시되지 않았다. 최대 latent step도 10 수준이라 scaling이 어디까지 지속되는지, 어느 지점에서 saturation되는지는 논문에 명시가 없다. 다섯째, Stage 1의 curriculum에서 latent 구간에 어떤 방식으로 확률성을 주입하는지(정책 gradient의 전제 조건)가 본문에 구체적으로 서술되어 있지 않아 재현 시 모호함이 남는다.

## 왜 중요한가

이 논문의 가장 큰 기여는 성능 숫자보다 "test-time scaling이 이미지 생성에도 존재하며, 그 열쇠는 표현 공간의 정합성"이라는 주장을 실험적으로 세운 데 있다. LLM에서는 추론 예산을 늘리는 것이 표준적인 성능 향상 수단이지만, 이미지 생성에서는 그 knob이 작동하지 않는다는 것이 암묵적 전제였다. LARC는 그 knob이 modality mismatch 때문에 꺼져 있었을 뿐이며, 추론을 연속 공간으로 옮기면 다시 켜진다는 것을 보여준다. 실무적으로는 추론 step 수를 늘리는 것이 best-of-N 대비 1/10 수준의 비용으로 더 나은 결과를 준다는 점이 즉시 활용 가능한 시사점이다. 특히 속성 결합, 공간 배치, 관계처럼 prompt를 여러 번 다듬어야 하는 요청에서 이득이 크다.

연구 방향으로는 두 갈래가 열린다. 하나는 외부 평가자 없이 model 자신의 likelihood 변화로 reasoning trace를 학습시키는 self-rewarding 패턴의 일반화다. 정답 chain이 존재하지 않는 모든 영역(도구 사용, 계획 수립, multimodal agent)에 같은 정보이득 reward를 이식할 수 있다. 다른 하나는 연속 latent를 modality 사이의 공용 인터페이스로 쓰는 설계다. text로 사고하고 text로 소통하는 대신, 이해와 생성이 같은 연속 표현을 공유하면 modality별 파이프라인을 따로 유지할 필요가 줄어든다. 다만 latent 추론의 검증 불가능성과 그에 따른 안전·감사 문제는 이 패러다임이 널리 퍼질수록 더 중요해질 것이며, 이는 후속 연구가 반드시 다뤄야 할 지점이다.

## 원문 초록

> Unified Multimodal Models (UMMs) achieve remarkable success on diverse multimodal understanding and generation tasks, yet they still struggle to effectively leverage language-based chain-of-thought reasoning for image generation. As a result, existing reasoning-augmented UMMs often fail to inherit the test-time scaling and fine-grained controllability observed in large language models. We attribute this failure to a fundamental modality mismatch: reasoning is performed in a discrete token space, whereas image generation operates in a continuous space. To bridge this gap, we introduce a Latent Reasoning framework in Continuous space (LARC), which alleviates the token-level bottleneck by reasoning over continuous hidden states. Specifically, the training framework consists of two stages: (i) curriculum supervised fine-tuning (SFT), and (ii) information-gain reinforcement learning (RL). First, the curriculum SFT stage gradually converts token-level reasoning into latent reasoning. Subsequently, the information-gain RL stage self-evolves latent reasoning without ground truth supervision. Experiments across diverse text-to-image generation benchmarks show that LARC consistently improves generation quality, prompt following, and compositional fidelity. Notably, LARC achieves state-of-the-art performance on GenEval with a 7%p gain over BAGEL and demonstrates clear test-time scaling behavior, outperforming token-based generation under both parallel and sequential test-time scaling strategies.
