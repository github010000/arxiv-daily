## 한 줄 요약
ContractLens는 frozen pretrained LLM 내부에서 malicious smart contract와 benign contract를 구분하는 critical layer와 malicious contract-discriminative unit(MCDU)을 찾아내고, 그 activation만 모아 가벼운 classifier로 malicious smart contract를 탐지하는 해석 가능하고 label-efficient한 framework이다.

## 핵심 개념 풀이

**1. Smart contract와 malicious intent.** Smart contract는 blockchain 위에서 미리 정한 규칙을 실행하는 program이다. 한 번 배포되면 수정이 어렵기 때문에, 겉으로는 평범한 refund나 transfer 기능처럼 보이면서 실제로는 owner에게 자금을 보내거나 특정 주소의 매도를 막는 식의 숨은 logic이 문제가 된다. 이 논문의 dataset은 Binance Smart Chain에서 수집한 contract에 fee, honeypot, blacklist, mint, max sell 같은 열 가지 malicious intent label을 붙인다. 여기서 malicious label은 “실제로 on-chain에서 공격이 확인되었다”는 뜻이 아니라 “해당 contract code에 그런 malicious capability가 있다”는 code-level label이다. 이 구분은 논문의 성능 해석에 중요하다. 왜냐하면 label 자체가 공격 실행의 결과가 아니라 code에 내재한 위험 가능성을 가리키기 때문이다.

**2. LLM의 internal representation, layer, MLP unit.** Transformer LLM은 입력 token을 여러 layer를 거치며 hidden state로 바꾼다. 각 layer의 hidden state는 token마다 하나의 긴 숫자 vector이고, 논문은 non-padding token들의 hidden state를 평균 내어 contract 하나를 대표하는 contract-level vector를 만든다. 이렇게 하면 “이 contract의 code 전체가 model 내부에서 어떤 숫자 pattern으로 요약되는가”를 layer별로 비교할 수 있다. 또한 각 layer에는 MLP module이 있고, 그 안의 각 neuron은 하나의 숫자 좌표를 출력한다. 논문은 이 좌표를 unit 또는 neuron이라고 부르며, 특정 unit의 activation이 malicious logic에 민감하게 반응하는지를 본다. 즉 “어느 layer가 contract의 malicious함을 잘 표현하는가”와 “그 layer 안의 어느 neuron이 그 표현에 기여하는가”를 나누어 찾는 것이 이 논문의 기본 시각이다.

**3. Linear probe.** Linear probe는 frozen model의 representation 위에 logistic regression 같은 단순한 선형 classifier를 하나 얹어서, 그 representation만으로 label을 얼마나 잘 맞출 수 있는지 보는 도구다. 논문의 probe는 sigmoid 함수를 사용해 “이 contract가 malicious일 확률”을 출력하고, AUROC로 성능을 잰다. AUROC는 threshold를 하나로 고정하지 않고 모든 threshold에서 malicious와 benign을 얼마나 잘 분리하는지를 재는 지표라서, class 비율이 달라도 비교하기 쉽다. 중요한 점은 probe 성능이 높다는 것이 “그 layer가 malicious logic을 실제로 사용한다”는 증명은 아니라는 것이다. 그래서 논문은 probe 성능만 보지 않고, malicious logic을 제거했을 때 representation이 변하는지와 겉만 바꿨을 때 안정적인지를 함께 본다.

**4. Counterfactual과 surface perturbation.** Counterfactual은 “malicious logic만 제거하고 나머지는 최대한 유지한” contract variant이다. 예를 들어 owner가 특정 주소를 block해서 매도를 막는 honeypot logic이 있다면, 그 block logic을 없애고 label을 malicious에서 benign으로 바꾼다. 반대로 surface perturbation은 comment 삭제, formatting 정리, pragma 변경, variable 이름 변경, function 순서 변경처럼 program의 behavior는 유지하면서 겉모습만 바꾸는 변형이다. 좋은 representation이라면 malicious logic 제거에는 크게 반응하고, behavior-preserving surface edit에는 별로 흔들리지 않아야 한다. 이 두 변형을 대조하는 것이 “진짜 malicious semantics를 보는가, 아니면 변수명이나 주석 같은 겉모습을 보는가”를 가르는 핵심 장치다.

**5. Activation contrast, probe weight, malicious-logic specificity.** Activation contrast는 malicious contract에서 특정 neuron의 평균 activation이 benign contract에서보다 얼마나 큰지를 나타낸다. Probe weight는 그 neuron이 probe의 decision boundary에 얼마나 강하게 기여하는지를 말한다. Malicious-logic specificity는 그 neuron이 malicious logic 제거에는 얼마나 민감하게 반응하는지를, surface perturbation에는 얼마나 둔감한지로 나눈 비율이다. 이 세 신호를 곱하면 “malicious와 benign을 잘 구분하고, probe 결정에 중요하며, 겉모습보다 malicious semantics에 반응하는 neuron”이 높은 점수를 받는다. 하나만 쓰면 code 길이, template, 변수명 같은 우연한 단서가 높은 점수를 받을 수 있기 때문에 세 신호를 결합하는 것이 논문의 설계 의도다.

**6. Kneedle과 masking intervention.** Kneedle은 정렬된 점수 curve에서 “어디부터가 긴 꼬리인가”를 찾는 heuristic이다. 논문은 모든 candidate neuron의 importance score를 내림차순으로 정렬한 뒤, curve가 급격히 떨어지다가 완만해지는 지점, 즉 knee point를 찾고 그 앞의 neuron만 MCDU로 남긴다. 고정된 개수를 자르는 대신 data에서 자연스러운 cut-off를 정한다는 뜻이다. Masking intervention은 찾은 neuron의 activation을 0으로 만들어 classifier 성능이 얼마나 떨어지는지 보는 실험이다. 만약 MCDU가 정말 중요하다면 random neuron이나 activation 크기가 비슷한 non-MCDU를 masking할 때보다 MCDU를 masking할 때 성능이 더 크게 떨어져야 한다. 이 비교가 “찾은 neuron이 단순히 우연히 높은 점수를 받은 것이 아니다”라는 기능적 증거가 된다.

## 문제의식
기존 smart contract 보안 분석은 크게 세 갈래였다. 첫째, Oyente나 Slither 같은 program analysis 도구는 미리 정의한 보안 속성 위반을 symbolic execution이나 static analysis로 찾는다. 둘째, supervised learning 방법은 contract representation에서 intent label로 가는 mapping을 학습한다. 셋째, 최근의 LLM 기반 auditing은 prompt design, external knowledge, agent workflow, chain-of-thought, fine-tuning 등으로 code 이해와 vulnerability reasoning을 끌어내려 한다. 그런데 이 세 갈래 모두 “어떤 내부 표현이 malicious logic을 담고 있는가”를 잘 설명하지 않는다. Program analysis는 규칙에 적힌 것만 찾고, supervised detector와 LLM auditing은 prediction 품질이나 auditing 절차에 집중한다.

이것이 실제로 곤란한 이유는 audit 현장에서 “malicious”라는 판정만으로는 부족하기 때문이다. Auditor는 왜 이 contract가 suspicious한지, model이 진짜 owner 권한 남용이나 transfer restriction을 본 것인지, 아니면 변수명이나 comment, code template 같은 겉모습에 반응한 것인지 알고 싶어 한다. 예를 들어 공격자가 variable 이름만 바꾸고 comment를 지우고 function 순서를 섞어도 detector가 쉽게 흔들린다면, 그 detector는 새로운 변종에 취약하다. 또한 LLM을 fine-tuning하려면 label과 compute가 필요하고, model이 update될 때마다 다시 학습해야 한다. Prompt engineering도 prompt 문구에 따라 결과가 달라져 재현성과 신뢰성이 떨어진다. 이 논문은 바로 이 지점에서 “pretrained LLM 안에 이미 security-relevant한 latent knowledge가 존재하며, 그것을 layer와 neuron 수준에서 찾아 쓸 수 있는가”를 묻는다.

## 핵심 아이디어
논문의 출발점은 경험 많은 개발자가 refund처럼 보이는 function이 실제로는 자금을 owner에게 돌린다는 것을 보고, 공격 유형을 정확히 이름 붙이기 전에도 “이상하다”고 느낀다는 관찰이다. 그 판단은 function의 겉으로 말한 목적과 실제 효과 사이의 불일치를 읽는 능력에서 나온다. 저자들은 smart contract code로 pretraining된 LLM도 이와 유사한 security-relevant distinction을 내부에 encode할 수 있다고 가설을 세운다. 따라서 새 classifier를 처음부터 학습하거나 LLM 전체를 fine-tuning하는 대신, frozen LLM 내부에서 그 지식을 localize해서 쓰자는 것이 핵심이다.

Localize하는 기준은 세 가지다. 첫째, malicious와 benign을 linear probe로 잘 분리하는 layer여야 한다. 둘째, malicious logic을 제거했을 때 representation이 크게 변해야 한다. 셋째, behavior-preserving surface modification에는 안정적이어야 한다. 이 세 조건을 모두 만족하는 layer를 critical layer로 부른다. 그 다음 critical layer의 MLP 안에서 activation contrast, probe weight, malicious-logic specificity를 결합해 MCDU를 찾는다. MCDU의 activation만 concatenate해서 작은 logistic regression classifier를 학습하면, backbone은 frozen인 채로 detection이 가능하다. 이 아이디어가 문제를 푸는 이유는 “malicious logic에 민감하고 겉모습에는 둔감한 내부 신호”를 직접 골라내기 때문이다. 그래서 prediction 성능뿐 아니라 어느 layer와 neuron이 판단에 기여하는지에 대한 해석도 얻는다.

## 방법
**1단계: critical layer localization.** 입력 smart contract를 $x$라고 하자. 각 layer $l$에서 non-padding token의 hidden state를 평균 내어 contract-level representation $\mathbf{h}_{l}(x)$를 만든다. 그 위에 linear probe를 학습한다. 식은 $p_{l}(x)=\sigma(\mathbf{w}_{l}^{\top}\mathbf{h}_{l}(x)+b_{l})$이고, $\sigma$는 sigmoid, $\mathbf{w}_{l}$은 probe weight vector, $b_{l}$은 bias이다. 이 probe는 “layer $l$의 representation만 보고 malicious일 확률을 얼마나 잘 예측하는가”를 계산한다. Validation set에서 AUROC를 $A^{(l)}$라고 하고, $A^{(l)}$가 threshold $\tau_{\mathrm{sep}}$ 이상인 layer를 separability candidate set $\mathcal{L}_{\mathrm{sep}}$로 둔다.

**2단계: malicious logic sensitivity.** 각 malicious contract $x$에 대해 malicious behavior를 담당하는 code를 제거한 counterfactual $x_{\mathrm{cf}}$를 만든다. Layer $l$에서 representation 변화는 정규화된 vector 사이의 L2 distance로 잰다. 식은 $d_{\mathrm{cf}}^{(l)}(x)=\lVert \mathbf{h}_{l}(x)/\lVert\mathbf{h}_{l}(x)\rVert_{2}-\mathbf{h}_{l}(x_{\mathrm{cf}})/\lVert\mathbf{h}_{l}(x_{\mathrm{cf}})\rVert_{2}\rVert_{2}$이다. 여기서 normalization은 representation의 크기 차이를 없애고 방향 변화에 집중하기 위한 것이다. 하지만 code를 제거하면 input 구조 자체도 바뀌므로, 비슷한 크기의 random non-semantic code 수정을 한 control $\widetilde{x}$와 비교한다. 상대적 민감도는 $R_{\mathrm{cf}}^{(l)}=\mathbb{E}_{x}[d_{\mathrm{cf}}^{(l)}(x)]/(\mathbb{E}_{x,\widetilde{x}}[d_{\mathrm{ctrl}}^{(l)}(x,\widetilde{x})]+\epsilon)$이다. $\epsilon$은 분모가 0이 되는 것을 막는 작은 값이다. 또한 malicious probability가 얼마나 떨어지는지 $\Delta p^{(l)}=\mathbb{E}_{x}[p_{l}(x)-p_{l}(x_{\mathrm{cf}})]$도 본다. $R_{\mathrm{cf}}^{(l)}$가 $\tau_{R}$ 이상이고 $\Delta p^{(l)}$가 $\tau_{p}$ 이상인 layer를 sensitivity candidate set $\mathcal{L}_{\mathrm{sens}}$로 둔다.

**3단계: surface perturbation stability.** Comment removal, formatting normalization, pragma rewriting, variable renaming, function reordering 같은 behavior-preserving transformation $T$를 적용해 $x_{T}=T(x)$를 만든다. Representation similarity는 $I_{\mathrm{cos}}^{(l)}=\mathbb{E}[\cos(\overline{\mathbf{h}}_{l}(x),\overline{\mathbf{h}}_{l}(x_{T}))]$로 잰다. Prediction consistency는 $C^{(l)}=\mathbb{E}[\mathbb{I}[\widehat{y}_{l}(x)=\widehat{y}_{l}(x_{T})]]$이고, probability shift는 $S_{p}^{(l)}=\mathbb{E}[|p_{l}(x)-p_{l}(x_{T})|]$이다. 각각 “representation이 얼마나 비슷한가”, “예측 label이 얼마나 유지되는가”, “malicious 확률이 얼마나 흔들리는가”를 뜻한다. $I_{\mathrm{cos}}^{(l)}$가 $\tau_{I}$ 이상, $C^{(l)}$가 $\tau_{C}$ 이상, $S_{p}^{(l)}$가 $\tau_{S}$ 이하인 layer를 stability candidate set $\mathcal{L}_{\mathrm{stab}}$로 둔다. 최종 critical layer는 세 집합의 교집합 $\mathcal{L}_{\mathrm{critical}}=\mathcal{L}_{\mathrm{sep}}\cap\mathcal{L}_{\mathrm{sens}}\cap\mathcal{L}_{\mathrm{stab}}$이다. 논문의 실험 설정에서는 $\tau_{R}=1.50$, $\tau_{I}=0.925$, counterfactual probability drop threshold $0.02$, prediction consistency threshold $0.95$, maximum probability shift $0.04$를 사용한다.

**4단계: MCDU scoring.** Critical layer의 MLP module 안에서 non-padding token activation을 평균 내어 contract-level MLP activation vector $\mathbf{a}_{l}(x)\in\mathbb{R}^{d_{\mathrm{MLP}}}$를 만든다. $d_{\mathrm{MLP}}$는 MLP width이다. 그 위에 linear probe $q_{l}(x)=\sigma(\mathbf{v}_{l}^{\top}\mathbf{a}_{l}(x)+c_{l})$를 학습한다. $\mathbf{v}_{l}$은 MLP activation에 대한 probe weight vector, $c_{l}$은 bias이다. Neuron $k$의 activation contrast는 $\overline{a}_{l,k}^{\mathrm{contrast}}=\mathbb{E}_{x\sim\mathcal{D}_{\mathrm{mal}}}[a_{l,k}(x)]-\mathbb{E}_{x\sim\mathcal{D}_{\mathrm{ben}}}[a_{l,k}(x)]$이다. 이 값이 크면 malicious contract에서 그 neuron이 평균적으로 더 강하게 켜진다는 뜻이다. Probe weight $v_{l,k}$는 그 neuron이 decision boundary에 얼마나 기여하는지를 나타낸다. Malicious-logic specificity는 $r_{l,k}=\mathbb{E}_{x\sim\mathcal{D}_{\mathrm{mal}}}[|a_{l,k}(x)-a_{l,k}(x^{\mathrm{cf}})|]/(\mathbb{E}_{x,T}[|a_{l,k}(x)-a_{l,k}(x^{T})|]+\epsilon)$이다. 분자는 malicious logic 제거에 대한 반응, 분모는 surface edit에 대한 반응이다. 따라서 $r_{l,k}$가 크면 그 neuron은 겉모습보다 malicious semantics에 더 민감하다. 세 신호를 결합한 importance score는 $S_{l,k}=|\overline{a}_{l,k}^{\mathrm{contrast}}\cdot v_{l,k}|\cdot r_{l,k}$이다.

**5단계: MCDU 선택과 detection.** 모든 critical layer의 candidate neuron score를 모아 global min-max normalization을 한다. 식은 $\widetilde{S}_{l,k}=(S_{l,k}-S_{\min})/(S_{\max}-S_{\min}+\epsilon)$이다. 정규화된 score를 내림차순으로 정렬하고 Kneedle을 적용해 knee point $K^{\star}$를 찾는다. $K^{\star}$ 앞에 있는 neuron을 MCDU로 남긴다. 이때 고정된 개수를 쓰지 않고 score curve의 굴곡에서 cut-off를 정한다. 마지막으로 critical layer들에 걸친 MCDU activation을 concatenate해 하나의 compact feature vector를 만들고, logistic regression classifier를 학습한다. Pretrained LLM backbone은 처음부터 끝까지 frozen으로 유지된다.

## 왜 성립하는가
논문의 Appendix A는 critical layer localization과 MCDU selection이 왜 의미 있는지를 두 개의 정리로 설명한다. 먼저 normalized representation이 semantic 성분, surface 성분, residual 성분의 합으로 근사된다고 가정한다. 즉 $\bm{\phi}_{l}(x)=\mathbf{s}_{l}(m)+\mathbf{n}_{l}(u)+\bm{\varepsilon}_{l}$이고, $m$은 malicious logic 포함 여부 같은 behavioral semantics, $u$는 변수명이나 comment 같은 surface factor이다. Counterfactual은 $m$을 benign counterpart $m_{0}$로 바꾸고, matched control은 $m$을 유지한 채 $u$만 바꾼다. Theorem 1은 triangle inequality와 reverse triangle inequality를 사용해, $R_{\mathrm{cf}}^{(l)}=N_{l}/(B_{l}+\epsilon)\geq\tau_{R}$이면 residual이 bounded된 조건 아래에서 semantic response가 surface response보다 충분히 크다는 lower bound를 준다. 직관적으로 말하면, “비슷한 크기의 겉 수정보다 malicious logic 제거에서 representation이 더 크게 변했다”는 관찰이 곧 “그 layer가 겉모습보다 semantics를 본다”는 정량적 근거가 된다.

Theorem 2는 unit 수준을 설명한다. Probe logit을 $z_{l}(x)=\mathbf{v}_{l}^{\top}\mathbf{a}_{l}(x)+c_{l}$라고 하면, malicious와 benign의 class-mean logit gap은 $\Gamma_{l}=\sum_{k=1}^{d_{\mathrm{MLP}}}v_{l,k}\overline{a}_{l,k}^{\mathrm{contrast}}$로 정확히 분해된다. Bias $c_{l}$은 두 class 평균에서 상쇄되기 때문이다. 따라서 $|v_{l,k}\overline{a}_{l,k}^{\mathrm{contrast}}|$는 unit $k$가 class separation에 기여하는 크기로 해석할 수 있다. 여기에 malicious-logic specificity $r_{l,k}$를 곱한 것이 논문의 score이다. Masking에 대해서도 bound가 있다. Unit 집합 $\mathcal{F}$의 activation을 0으로 만들면 logit 변화는 $\Delta z_{l,\mathcal{F}}(x)=\sum_{k\in\mathcal{F}}v_{l,k}a_{l,k}(x)$이고, binary cross-entropy의 logit에 대한 미분 $\sigma(z)-y$의 절댓값이 1 이하이므로 loss 변화는 $|\Delta z_{l,\mathcal{F}}(x)|\leq\sum_{k\in\mathcal{F}}|v_{l,k}a_{l,k}(x)|$로 bound된다. 이는 “중요한 unit을 masking하면 loss가 더 크게 변할 수 있다”는 이론적 뼈대를 제공한다. 다만 논문도 인정하듯 이 bound는 masking을 많이 할수록 성능이 반드시 단조적으로 떨어진다는 뜻은 아니다. Correlated unit들이 서로 보상할 수 있기 때문에 Kneedle은 전역 최적 subset이라기보다 data-adaptive boundary로 사용된다. 실제로 Table 3의 masking 실험은 MCDU가 random neuron이나 activation-matched neuron보다 더 큰 성능 하락을 만든다는 기능적 증거를 보여준다.

## 구체적 예시
Table 3의 CodeGemma-2.5-7B 결과를 따라가 보자. 먼저 default 설정은 critical layer의 전체 MLP activation 위에 linear probe를 학습했을 때 accuracy $85.54\%$, AUROC $89.26\%$이다. 여기서 “Masked U0”는 critical layer에서 같은 개수의 neuron을 random으로 골라 activation을 0으로 만든 경우이고, accuracy $85.58\%$, AUROC $89.34\%$로 default와 거의 차이가 없다. 변화량은 각각 $+0.04\%$, $+0.08\%$인데, random masking이 성능을 거의 건드리지 못했다는 뜻이다. “Masked U1”은 MCDU가 아닌 neuron 중 activation magnitude가 비슷한 것을 masking한 경우이다. 결과는 accuracy $85.54\%$, AUROC $89.64\%$로 accuracy 변화는 $0.00\%$, AUROC는 $+0.38\%$이다. 즉 activation 크기만 비슷한 non-MCDU를 지워도 성능은 유지되거나 아주 조금 올라간다.

반면 “Masked MCDUs”는 논문이 찾은 MCDU를 masking한 경우로, accuracy $81.05\%$, AUROC $86.71\%$이다. Default 대비 accuracy는 $-4.49\%$, AUROC는 $-2.55\%$ 떨어진다. 이 숫자가 중요한 이유는 같은 layer에서 같은 개수의 neuron을 지웠는데도 MCDU를 지웠을 때만 뚜렷한 하락이 나타났기 때문이다. 만약 MCDU가 단순히 activation이 큰 neuron이거나 우연히 고른 neuron일 뿐이라면 U1과 비슷한 결과가 나와야 한다. 하지만 U1은 거의 변화가 없고 MCDU만 크게 떨어졌으므로, 이 neuron들의 activation에 detection에 필요한 신호가 실제로 담겨 있다고 해석할 수 있다. Qwen3-8B에서도 같은 pattern이 더 크게 나타난다. Default accuracy $91.52\%$, AUROC $95.02\%$에서 MCDU masking은 accuracy $83.04\%$, AUROC $94.17\%$로 각각 $-8.48\%$, $-0.85\%$가 된다. 반면 activation-matched U1은 accuracy $-0.25\%$, AUROC $+0.03\%$에 그친다. 정확한 수치는 고정된 dataset, probe, selected unit 조합에서 측정된 것이고 간단한 공식으로 계산되는 값은 아니지만, “MCDU를 지우면 성능이 더 크게 떨어진다”는 방향은 논문 주장과 일관된다.

## 실험과 결과
논문은 Binance Smart Chain에서 수집한 32,141개의 real-world smart contract를 사용한다. 이 중 21,166개가 하나 이상의 malicious intent를 가진 것으로 label되었고, 10,975개가 benign이다. 열 가지 intent는 fee, disable trading, blacklist, reflect, max transaction, mint, honeypot, reward, rebase, max sell이다. Critical layer localization을 위해서는 malicious contract 1,000개와 benign contract 1,000개로 balanced probing set을 만들고, 같은 creator나 같은 source code를 공유하는 contract를 group으로 묶어 train, validation, test split 사이의 data leakage를 막는다. 주요 metric은 AUROC, accuracy, F1-score이다. Backbone은 general-purpose LLM인 Qwen3-8B와 code-oriented LLM인 Qwen2.5-Coder-7B, CodeGemma-2.5-7B이다.

Table 1의 평균 성능을 보면 Qwen3-8B에서 ContractLens는 AUROC $95.48\%$, accuracy $91.21\%$를 기록한다. 가장 강한 비교 대상인 SmartIntentNN의 $94.25\%$, $87.82\%$보다 AUROC는 약 $1.23$ percentage point, accuracy는 약 $3.39$ percentage point 높다. Qwen2.5-Coder-7B에서는 $96.24\%$, $92.41\%$로 DBESN의 $95.81\%$, $91.90\%$를 각각 $0.43$ point, $0.51$ point 앞선다. CodeGemma-2.5-7B에서는 $95.24\%$, $90.94\%$이고, accuracy는 가장 높지만 AUROC는 DBESN의 $95.33\%$에 $0.09$ point 뒤진다. 따라서 “세 model 모두 average accuracy가 가장 높고, Qwen3와 Qwen2.5에서는 average AUROC도 가장 높다”는 논문의 표현이 정확하다. Qwen2.5와 CodeGemma에서는 AUROC 개선 폭이 크지 않으므로, 이 결과는 압도적 향상이라기보다 이미 강한 code-oriented baseline에 대해 일관된 accuracy 우위를 보인 것으로 읽는 편이 좋다.

Unseen malicious intent 일반화 실험은 leave-one-intent-out 방식이다. 특정 intent를 test에서만 쓰고, localization과 training에서는 그 intent를 완전히 제외한다. CodeGemma-2.5-7B에서 다섯 개 held-out intent에 대해 ContractLens는 average accuracy $73.50\%$, average F1 $73.51\%$를 기록한다. 이는 SCMDetector의 average accuracy $66.08\%$보다 $7.42$ point 높고, SmartIntentV2의 average F1 $62.69\%$보다 $10.82$ point 높다. 다만 in-distribution average accuracy $90.94\%$와 비교하면 unseen intent 성능은 크게 낮아진다. 이는 “새로운 공격 유형으로 갈수록 성능이 떨어진다”는 현실적 한계를 보여주며, 논문의 일반화 주장은 “완전히 새로운 공격도 모두 잡는다”가 아니라 “학습에 없던 intent에도 baseline보다는 의미 있게 transfer된다”는 수준으로 해석해야 한다.

Layer ablation은 critical layer가 정말 중간 깊이에 몰려 있는지를 보여준다. 각 model의 Transformer layer를 shallow, transition, critical, deep의 네 구간으로 나누고, 한 구간의 feature만으로 detector를 만들었을 때 CodeGemma-2.5-7B의 AUROC는 shallow $89.19\%$, critical $94.43\%$, deep $83.80\%$였다. Qwen3-8B에서는 critical 구간이 AUROC $96.48\%$, accuracy $89.53\%$로 shallow의 $93.19\%$, $86.02\%$보다 높다. Qwen2.5-Coder-7B에서도 critical 구간이 AUROC $95.54\%$, accuracy $90.77\%$로 가장 높다. 이는 malicious intent와 관련된 latent knowledge가 network 전체에 고르게 퍼져 있기보다 특정 중간 depth 구간에 집중되어 있다는 논문의 주장을 뒷받침한다.

Neuron specificity 실험도 있다. MCDU의 test AUROC는 CodeGemma-2.5-7B $94.4\%$, Qwen3-8B $96.4\%$, Qwen2.5-Coder-7B $94.9\%$이다. 같은 critical layer에서 random으로 neuron을 고른 Random-In은 각각 $88.0\%$, $93.1\%$, $92.8\%$이고, MCDU를 제외하고 random으로 고른 Random-Ex는 $88.6\%$, $93.3\%$, $92.2\%$이다. CodeGemma에서 특히 차이가 크게 나는데, 이는 critical layer 안에서도 아무 neuron이나 쓰면 안 되고 malicious logic에 특화된 sparse subset을 골라야 한다는 해석을 가능하게 한다. Few-shot 실험에서는 CodeGemma backbone을 frozen으로 두고 같은 MCDU를 유지한 채 logistic regression만 학습했을 때, label이 32개뿐인 contract로도 average AUROC $85.03\%$를 얻는다. Training set이 커지면서 $88.80\%$, $91.89\%$, $94.09\%$, $94.97\%$로 올라가고 전체 gain은 $9.94$ point이다. 256개를 넘으면 개선 폭이 줄어 saturation에 가까워진다. 새로 배포된 malicious smart contract temporal evaluation에서는 1,201개의 labelled token, 즉 898 scam과 303 benign으로 평가했고, ContractLens는 average accuracy $77.50\%$, AUROC $84.13\%$를 기록해 strongest competing result보다 accuracy $17.50$ point, AUROC $3.40$ point 높다. Honeypot에서는 accuracy $81.25\%$, AUROC $95.31\%$로 특히 강하다. 효율 측면에서도 Appendix C는 마지막 layer만 쓰는 conventional last-layer probe보다 AUROC $91\%$에서 $96\%$ 수준으로 높고 processing time은 더 낮다고 보고한다. 다만 temporal dataset은 규모가 작고 class imbalance가 있으므로 이 결과를 대규모 실전 배포의 절대적 성능으로 일반화하면 안 된다.

## 한계
저자들이 직접 인정한 가장 큰 한계는 ContractLens가 “임의의 미래 공격을 모두 잡는 universal detector”가 아니라는 점이다. 성능은 결국 pretrained backbone이 이미 가지고 있는 security knowledge에 의존한다. Backbone이 특정 취약 유형을 전혀 학습하지 않았다면 MCDU를 아무리 잘 찾아도 그 유형을 탐지하기 어렵다. 또한 논문의 malicious label은 on-chain exploit 확인이 아니라 code-level latent capability를 기준으로 한다. 따라서 실제 공격 성공 여부와 label이 완전히 일치하지 않을 수 있고, benign으로 label된 contract도 잠재적 위험을 가질 수 있다. 이는 성능 수치 해석에 중요한 label noise 가능성이다.

두 번째 약점은 localization procedure가 상당히 많은 hyperparameter와 code transformation에 의존한다는 점이다. Appendix B의 sensitivity analysis에서 $\tau_{R}$과 bootstrap 수는 비교적 안정적이지만, $\delta_{\mathrm{AUROC}}$를 바꾸면 selected neuron set의 Jaccard index가 $0.25$나 $0.33$까지 떨어지는 경우가 있다. 이는 critical layer 선택이 완전히 robust하지 않을 수 있음을 시사한다. Counterfactual $x_{\mathrm{cf}}$를 만들려면 “malicious logic만 제거”해야 하는데, 실제 contract에서는 logic이 여러 function과 state variable에 얽혀 있어 깔끔한 제거가 어려울 수 있다. 논문은 matched control로 이 효과를 줄이려 하지만, 제거 자체가 input structure를 바꾸는 confound를 완전히 없앴다고 보기는 어렵다. Surface perturbation도 comment, formatting, pragma, renaming, function reordering 등 정해진 변형에 한정되므로, 논문에 없는 새로운 종류의 겉바꾸기에는 취약할 수 있다.

세 번째로, interpretability의 수준은 “full circuit 해석”이라기보다 “중요 neuron localize와 masking”에 가깝다. MCDU가 기능적으로 중요하다는 증거는 있지만, 그 neuron들이 어떤 feature를 계산하는지, 서로 어떻게 상호작용하는지까지 완전히 밝히지는 않는다. Masking bound도 unit 간 correlation 때문에 단조적 성능 하락을 보장하지 않는다. 실험 범위도 BSC의 Solidity contract와 7B에서 8B 규모의 세 backbone에 제한된다. Unseen intent 평가는 CodeGemma의 다섯 intent에만 수행되었고, average accuracy $73.50\%$는 in-distribution 성능보다 훨씬 낮다. Temporal evaluation도 1,201개 label에 불과해 통계적 변동이 클 수 있다. 따라서 이 논문은 “frozen LLM 내부에 쓸 만한 security signal이 존재한다”는 강한 존재 증명이지, 모든 chain과 언어와 공격에 바로 적용 가능한 완성된 detector는 아니다.

## 왜 중요한가
이 논문의 가장 큰 의미는 malicious smart contract detection을 “prompt를 잘 쓰는 문제”나 “attack-specific fine-tuning 문제”에서 “pretrained model 내부 표현을 찾아 쓰는 문제”로 바꿔 놓았다는 점이다. 실무자 입장에서는 LLM을 처음부터 fine-tuning하지 않고도 backbone을 frozen으로 둔 채 compact feature와 가벼운 classifier만으로 detection할 수 있다는 가능성을 보여준다. 이는 label이 적은 상황에서 특히 중요하다. Few-shot 결과처럼 32개 label로도 average AUROC $85.03\%$를 얻고, 같은 MCDU를 유지하면 dataset이 늘어날수록 성능이 saturation에 가까워지는 pattern은 “한 번 localize한 security feature를 재사용할 수 있는가”라는 실무적 질문에 긍정적 근거를 준다.

또한 layer와 neuron 수준의 localization은 audit 설명 가능성에 기여할 수 있다. 기존 LLM auditing은 “이 contract는 malicious입니다”라는 출력은 줘도, model 내부에서 어떤 신호가 그 판단을 만들었는지 보여주기 어렵다. ContractLens는 critical layer와 MCDU라는 중간 단위를 제공하고, masking intervention으로 그 중요성을 검증한다. 이는 보안 분석가가 false positive를 디버깅하거나 model의 판단 근거를 점검하는 데 도움을 줄 수 있다. 물론 이것만으로 법적·재무적 audit를 대체할 수는 없고, symbolic execution이나 formal analysis와 결합하는 보조 신호로 쓰는 것이 현실적이다.

후속 연구 측면에서는 여러 방향이 열린다. 더 다양한 chain과 언어, 더 큰 LLM에서 critical layer pattern이 유지되는지 볼 수 있다. Counterfactual 생성을 자동화하거나 program analysis로 malicious logic slice를 정확히 떼어내는 연구도 가능하다. MCDU를 attention head나 circuit 수준으로 확장하거나, 새로운 공격 유형이 나올 때 MCDU를 어떻게 update할지 연구할 수도 있다. 실무적으로는 대규모 contract screening에서 빠른 1차 filter로 쓰고, 의심 contract만 정밀 분석으로 넘기는 구조가 적합하다. 결국 이 논문의 핵심 기여는 “frozen LLM 안의 latent security knowledge를 찾아 쓸 수 있다”는 것을 layer, neuron, masking이라는 구체적 실험으로 보여준 데 있다.

## 원문 초록

> Detecting malicious smart contracts is essential to safeguarding the Web3.0 ecosystem. However, existing auditing methods based on large language models (LLMs) largely rely on prompt engineering or attack-specific fine-tuning, while the internal representations that support malicious logic detection remain poorly characterized. To address this gap, we propose ContractLens, a framework that localizes and uses latent security knowledge in pretrained LLMs for interpretable malicious smart contract detection. Specifically, we first use layerwise linear probes to identify candidate layers that distinguish malicious from benign contracts, then select critical layers based on their sensitivity to malicious logic removal and stability under behaviour-preserving surface modifications. Next, within these critical layers, we combine activation contrast, malicious-logic specificity, and probe weights into a tri-factor importance score and adaptively select malicious contract-discriminative units (MCDUs) using the knee point of the ranked score curve. Finally, we concatenate the selected units' activations into a compact representation and train a lightweight classifier for detection, keeping the pretrained model frozen throughout. Neuron masking experiments show that masking MCDUs causes larger drops in detection performance than masking randomly selected neurons or neurons matched in activation magnitude. ContractLens achieves higher average detection accuracy than the evaluated methods on all three pretrained models. Further evaluations demonstrate generalization to unseen malicious intents and show that, with the identified MCDUs fixed, a classifier trained on few labelled samples can still achieve strong detection performance.
